## 1. 打擂台思想

### 核心概念

**打擂台**（擂台法）是找一组数中最大值或最小值的经典办法：**先让第一个数当擂主**，后面的数依次上来挑战，**赢了就换擂主**，全部挑战完，站在台上的就是答案。

- 需要一个**临时变量**保存"当前擂主"的值
- 只需要**一层循环**加一个 `if` 比较
- 比较方向决定找什么：擂主要"更大"就是找最大值，要"更小"就是找最小值

### 三个步骤

| 步骤 | 做法 | 说明 |
| ---- | ---- | ---- |
| 立擂 | 把第一个数放进临时变量 | 保证擂主一开始就有值 |
| 挑战 | 循环取出后面的每个数 | 从第二个数开始 |
| 换人 | 满足条件就更新临时变量 | `>` 找最大，`<` 找最小 |

### 语法格式

```cpp
int maxn = a[0];                     // 第一个数先当擂主
for (int i = 1; i < n; i++)          // 其余数字依次挑战
{
    if (a[i] > maxn) maxn = a[i];    // 挑战成功就换擂主
}
```

判断条件的两种等价写法：`y > maxn` 与 `maxn < y`；找最小值则是 `x < minn` 与 `minn > x`。

### 易错点

1. **循环从 `i = 0` 开始** —— 第一个数已经当擂主，重复比较不影响结果但多跑一次
2. **擂主变量忘了赋初值** —— 局部变量初值是垃圾值，比较结果完全不可信
3. **找最大值却写成 `<`** —— 方向反了，最后留下的是最小值
4. **在循环里 `cout`** —— 会输出每次比较的中间结果，答案应循环结束后输出

> **本节小结**：打擂台就是"第一个数当擂主，其余数依次挑战、赢了换人"，一层循环加一个比较就能求出最值。

## 2. 找最大值

### 核心概念

找最大值时，擂主要求"更大"：**只要新来的数比当前最大值大，就把它记为新的最大值**。

- 数组：`maxn` 初始化为 `a[0]`，从 `a[1]` 开始比较
- 边输入边比较：先读第一个数当擂主，再循环读入后面的数
- 需要知道最大值在哪个位置时，额外用一个 `pos` 记录下标

### 代码示例：边输入边打擂台

```cpp
#include <iostream>
using namespace std;

int main()
{
    int n, x;
    cin >> n;
    cin >> x;
    int maxn = x;                  // 第一个输入的数当擂主
    for (int i = 2; i <= n; i++)
    {
        cin >> x;
        if (x > maxn) maxn = x;    // 挑战成功就换擂主
    }
    cout << maxn;
    return 0;
}
```

### 现成的 `max()` 函数

`max()` 返回**两个数字中的较大值**，`min()` 返回**两个数字中的较小值**：

```cpp
int a = max(4, 1);      // 4
int b = min(2, 5);      // 2
```

它们只能比较两个数，多个数要配合循环反复调用；大量数据时自己写打擂台更直观。

### 易错点

1. **`maxn` 初始化为 0** —— 若全部是负数，答案是 0 而不是真正的最大值
2. **循环变量从 1 开始却读了两遍第一个数** —— 边输入边比较时要注意已经读过一次
3. **`if (x > maxn) ;` 多写分号** —— `if` 后面直接跟分号，更新语句永远不会执行
4. **`max(4, 1)` 写成 `max(4, 1, 2)`** —— `max()` 只接受两个参数
5. **把 `max()` 和 `min()` 记反** —— 一个取大、一个取小

> **本节小结**：找最大值就是把擂主初始化为第一个数，后面每个数用 `>` 挑战，赢了就更新；只有两个数比较时可以直接用 `max()`。

## 3. 找最小值

### 核心概念

找最小值与找最大值完全对称，只是挑战条件变成"**更小**"：`if (x < minn) minn = x;`。

**初值的选取是这一节最关键的地方**：

- 找**输入数字**中的最小值时，**第一个输入的数字**作为临时最小值
- 找**数组中**的最小值时，**数组第一个元素**作为临时最小值

这样初值一定来自数据本身，不会"凭空"造出一个不存在的答案。

### 代码示例：数组中的最小值

```cpp
#include <iostream>
using namespace std;

int main()
{
    int a[5] = {7, 3, 9, 1, 5};
    int minn = a[0];                    // 第一个元素当临时最小值
    for (int i = 1; i < 5; i++)
    {
        if (a[i] < minn) minn = a[i];   // 更小就换人
    }
    cout << minn;                       // 1
    return 0;
}
```

### 易错点

1. **`minn` 初始化为 0** —— 0 比所有正整数都小，答案会永远是 0
2. **`minn` 初始化为 100 之类的大数** —— 数据可能比它还大，结果就错了
3. **把 `min()` 写成 `max()`** —— 函数名一字之差，结果完全不同
4. **循环条件写成 `i <= 5`** —— 长度 5 的数组最大下标是 4，`a[5]` 已越界
5. **找最小值时用了 `>`** —— 方向写反，最后得到的是最大值

> **本节小结**：找最小值只需把挑战条件换成 `<`，但初值必须取第一个数（数组取 `a[0]`），绝不能图省事写 0。

## 4. 同时找最大最小

### 核心概念

最大值和最小值可以**在同一层循环里一起求**：

- 两个临时变量 `maxn`、`minn`，都初始化为第一个元素
- 循环里连续两个 `if`：一个挑战最大值，一个挑战最小值
- 只遍历一遍数组，效率比"跑两次循环"更高，也不容易漏改边界

### 代码示例

```cpp
#include <iostream>
using namespace std;

int main()
{
    int n;
    cin >> n;
    int a[105];
    for (int i = 0; i < n; i++) cin >> a[i];

    int maxn = a[0], minn = a[0];       // 两个擂主都是第一个元素
    for (int i = 1; i < n; i++)
    {
        if (a[i] > maxn) maxn = a[i];   // 挑战最大值
        if (a[i] < minn) minn = a[i];   // 挑战最小值
    }
    cout << "最大 " << maxn << "，最小 " << minn;
    return 0;
}
```

输入 `5` 和 `7 3 9 1 5`，输出 `最大 9，最小 1`。

如果还要知道最值所在的位置，可以再准备 `maxPos`、`minPos`，在更新最值时一起记录下标。

### 易错点

1. **两个 `if` 写成 `else if`** —— 一个数既可能是最大值也可能同时是最小值（如数组只有一个数），必须分别判断
2. **`minn` 初始化为 `maxn` 而不是第一个元素** —— 逻辑上等于，但直接都用 `a[0]` 更清楚
3. **数组长度开得刚好** —— 建议多开 5 个位置，避免输入比预期多时越界
4. **先输入后判断时下标错位** —— 读入循环从 0 开始，比较循环从 1 开始，两段边界要分清

> **本节小结**：一次遍历就能同时求出最大和最小，两个擂主都初始化为第一个元素，循环里用两个独立的 `if` 分别挑战。

## 知识框架梳理

### 核心概念总结

- **打擂台**：第一个数当擂主，其余数依次挑战，赢了就换人
- **找最大值**：`if (x > maxn) maxn = x;`，`maxn` 初始为第一个数
- **找最小值**：`if (x < minn) minn = x;`，`minn` 初始为第一个数
- **初值原则**：临时变量必须取自数据本身，不能写 0 或随便一个大数
- **`max()` / `min()`**：只能比较两个数，返回较大 / 较小者
- **同时求最值**：一组两个 `if`、一次遍历即可
- **记录位置**：额外用 `pos` 变量存下标

### 语法速查表

| 用途 | 写法 |
| ---- | ---- |
| 立擂 | `int maxn = a[0];` |
| 挑战最大值 | `if (a[i] > maxn) maxn = a[i];` |
| 挑战最小值 | `if (a[i] < minn) minn = a[i];` |
| 等价写法 | `if (maxn < a[i])`、`if (minn > a[i])` |
| 两个数取大 | `max(4, 1)` → 4 |
| 两个数取小 | `min(2, 5)` → 2 |
| 同时求最值 | 两个 `if` 写在同一层循环里 |
| 记录位置 | `if (a[i] > maxn) { maxn = a[i]; pos = i; }` |

### 易错点提醒

1. 擂主必须先赋初值，且初值取第一个数据，不能写 0
2. 找最大值用 `>`，找最小值用 `<`，方向别反
3. 循环从第二个元素（下标 1）开始挑战
4. `if` 后面别多写分号，否则更新语句永远不执行
5. `max()`、`min()` 只接受两个参数，多个数要配循环
6. 长度 n 的数组遍历条件是 `i < n`，不是 `i <= n`
7. 同时求最值时两个 `if` 不能写成 `else if`
8. 只有负数时初值写 0 会得到错误答案
9. 数组适当开大几个位置，防止越界
10. 答案在循环结束后输出，不要每次比较都输出

> **本节小结**：打擂台的核心是「先设擂主、再逐个挑战」，求最大时大者留下、求最小时反之，两者可以一趟同时求出。
