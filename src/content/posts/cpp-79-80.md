## 1. 函数的定义与调用

### 核心概念

**函数**（function）是把一段完成特定功能的代码**打包并命名**，之后可以反复调用：一处编写多处使用、`main` 更短、出错范围更小。函数必须定义在**所有函数的外面**，不能写在 `main` 里面。

- **无返回值函数**：开头写 `void`，只干活、不交回数据
- **有返回值函数**：开头写 `int`、`double` 等返回类型，并配一条 `return 结果;`
- 参数**可以有也可以没有**，函数体用大括号 `{}` 包起来

### 代码示例

```cpp
#include <iostream>
using namespace std;

void printLine()              // 无返回值：只干活
{
    cout << "--------" << endl;
}

int add(int a, int b)         // 有返回值：交回一个结果
{
    return a + b;             // 结果可以是常量、变量、表达式
}

int main()
{
    printLine();              // 单独一行，末尾加分号
    cout << add(3, 5);        // 8，结果可直接输出
    return 0;
}
```

### 易错点

1. 调用时**漏写括号** —— `printLine;` 是把函数当变量用
2. 调用时**带上返回类型** —— 应写 `add(3, 5)`，不是 `int add(3, 5)`
3. 把函数**定义在 `main` 里** —— C++ 不允许函数嵌套定义

> **本节小结**：函数就是把一段代码"命名打包"，定义写在 `main` 外面并说明返回类型与参数，调用只写"函数名(实参)"。

## 2. 参数与返回值

### 核心概念

参数把数据**送进去**，返回值把结果**交出来**。实参与形参的区别：

| 对比项 | 实参（argument） | 形参（parameter） |
| ------ | ---------------- | ----------------- |
| 出现位置 | **调用**函数里 | **定义**函数里 |
| 作用 | 向函数里**传递**数据 | **接收**数据 |
| 填写形式 | 数值、变量、表达式结果 | 变量 |

一一对应指三层：**个数相同、顺序相同、类型相符**。`return` 有**两个作用**——结束函数、返回数据；`void` 函数里 `return` 可写可不写，写的话后面**只填分号**。

### 代码示例：值传递

```cpp
#include <iostream>
using namespace std;

void change(int x)         // 形参拿到的是实参的副本
{
    x = 100;
}

int main()
{
    int a = 5;
    change(a);
    cout << a;             // 仍然输出 5
    return 0;
}
```

### 易错点

1. **参数个数对不上** —— 定义两个参数就必须传两个实参
2. **有返回类型却忘记 `return`** —— 函数会带回一个不确定的值
3. **`void` 函数里写 `return 结果;`** —— 只能写 `return;`
4. **以为改了形参外面也会变** —— 值传递只传副本

> **本节小结**：实参在调用处"给"、形参在定义处"收"，个数顺序类型一一对应；`return` 既结束函数又交回结果，值传递改不动实参。

## 3. 函数声明

### 核心概念

编译器**从上往下**读代码。若函数定义写在 `main` 之后，调用时编译器还没见过它，就会报"未声明"。

**函数声明**（declaration）就是只有函数头加一个分号、**不写函数体**的一句"预告"：`返回类型 函数名(参数类型, 参数类型);`。声明里只写参数类型即可，`int add(int, int);` 是合法声明。

### 代码示例

```cpp
#include <iostream>
using namespace std;

int add(int a, int b);      // 声明在前

int main()
{
    cout << add(2, 3);      // 声明过了，可以正常调用
    return 0;
}

int add(int a, int b)       // 定义放在 main 之后
{
    return a + b;
}
```

### 易错点

1. **声明末尾漏分号** —— 编译器会以为下面紧接函数体，报错很难懂
2. **声明与定义返回类型不一致** —— 同名却不同返回类型，直接冲突
3. **声明与定义参数类型不一致** —— 编译器会视为两个不同的函数
4. **把声明写进函数体里** —— 应写在 `#include` 之后、所有函数之前

> **本节小结**：函数声明就是"函数头 + 分号"；定义在前可省声明，定义在后必须先声明，且两者的返回类型、参数类型必须完全一致。

## 4. 全局变量与局部变量

### 核心概念

按**定义位置**分两类：

- **局部变量**（local variable）：在**函数里**定义，作用域**只在本函数内**
- **全局变量**（global variable）：在**函数外**定义，作用域**从定义位置开始，往后任何地方都能用**

两者同名时**优先使用局部变量**：局部的 `a` 会把全局的 `a` 遮住，这叫**遮蔽**，不报错但极易读错。

### 代码示例

```cpp
#include <iostream>
using namespace std;

int total = 0;          // 全局变量，所有函数都能用

void addTo(int x)
{
    int t = x * 2;      // 局部变量，只在 addTo 里有效
    total = total + t;  // 改的是全局变量，改动会保留
}

int main()
{
    addTo(3);
    addTo(4);
    cout << total << endl;   // 14
    // cout << t;            // 错误：t 在 main 里不存在
    return 0;
}
```

### 易错点

1. **在 `main` 里定义的变量别的函数用不了** —— 局部变量只在本函数有效
2. **全局变量在定义之前不能用** —— 作用域从定义位置才开始
3. **局部变量不初始化是垃圾值** —— 而全局变量不初始化默认为 0
4. **滥用全局变量** —— 谁都能改它，出错时很难定位

> **本节小结**：函数里定义的是局部变量、只管本函数，函数外定义的是全局变量、从定义处往后都能用；两者同名时局部优先。

## 5. 作用域与生命周期

### 核心概念

- **作用域**（scope）：变量**在哪些代码位置能被使用**，是"空间"概念
- **生命周期**（lifetime）：变量**从创建到销毁的时间段**，是"时间"概念

| 变量种类 | 作用域 | 创建 | 销毁 | 未初始化值 |
| -------- | ------ | ---- | ---- | ---------- |
| 全局变量 | 定义处到文件末尾 | 程序启动 | 程序结束 | 0 |
| 局部变量 | 本函数 | 执行到定义语句 | 离开函数 | 垃圾值 |
| 块局部变量 | 该代码块 | 同上 | 离开代码块 | 垃圾值 |

**块作用域**：`for` 括号里和 `{}` 里定义的变量，出了代码块就销毁。

### 代码示例

```cpp
#include <iostream>
using namespace std;

int g = 0;              // 程序启动时创建，结束时销毁

void f()
{
    int x = 0;          // 每次调用都重新创建
    x++;
    cout << x << " ";   // 每次都输出 1
    g++;
}

int main()
{
    f(); f(); f();
    cout << g << endl;  // 3，全局变量一直在累加
    return 0;
}
```

输出 `1 1 1 3`：局部变量每次调用都从 0 开始，全局变量一直活着。

### 易错点

1. **以为局部变量会保留上次的值** —— 每次调用都是全新的变量
2. **在循环外使用循环里定义的变量** —— 出了代码块就已经销毁
3. **把需要跨函数保留的数据写成局部变量** —— 该用全局变量或参数返回值

> **本节小结**：作用域管"在哪里能用"，生命周期管"活到什么时候"；局部变量随代码块生灭，全局变量随程序生灭。

## 知识框架梳理

### 核心概念总结

- **函数**：把功能代码命名打包，定义在 `main` 外，调用写 `函数名(实参)`
- **返回类型**：`void` 不返回数据，其他类型必须 `return 结果;`
- **形参与实参**：定义处接收、调用处传递，个数顺序类型**一一对应**
- **值传递**：形参拿到副本，改形参不影响实参
- **函数声明**：函数头加分号，解决"定义在后、调用在前"
- **局部变量**：随代码块生灭，初值不确定；**全局变量**反过来随程序生灭，初值为 0
- **作用域 / 生命周期**：一个管"能不能用"，一个管"活多久"

### 语法速查表

| 用途 | 写法 |
| ---- | ---- |
| 无返回值函数 | `void f(类型 参数) { ... }` |
| 有返回值函数 | `返回类型 f(类型 参数) { ... return 结果; }` |
| 调用函数 | 无返回值 `f(实参);`，有返回值 `int s = f(实参);` |
| 结束并返回 | `return 表达式;` |
| 仅结束函数 | `return;` |
| 函数声明 | `返回类型 f(参数类型, 参数类型);` |
| 全局变量 | 所有函数之外：`int g = 0;` |

### 易错点提醒

1. 函数定义不能写在 `main` 里，`main` 里只能调用
2. 调用时别写返回类型：是 `add(3, 5)`，不是 `int add(3, 5)`
3. 有返回类型就必须有 `return`，返回的数据类型要与返回类型相容
4. `void` 函数只能写 `return;`，不能带回数据
5. 声明末尾分号不能漏，声明与定义的类型必须一致
6. 值传递改不动实参，想改外面变量要靠返回值或全局变量
7. 同名时局部优先，想操作全局变量最好换名字

> **本节小结**：函数把一段逻辑打包成「名字 + 参数 + 返回值」，局部变量只在函数内有效，全局变量全程序可用但应少用。
