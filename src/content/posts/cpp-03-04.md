## 1. 算术运算符

C++ 用**运算符**（operator）描述运算，参与运算的数据叫**操作数**（operand），运算符与操作数组合成的整体叫**表达式**（expression）。例如 `3 + 4` 中，`+` 是运算符，`3` 和 `4` 是操作数，整个式子是一个表达式。

C++ 提供五种基本算术运算符。

### 核心概念

| 名称 | 符号 | 作用 | 示例 |
| ---- | ---- | ---- | ---- |
| 加 | `+` | 求两数之和 | `3 + 4` 得 `7` |
| 减 | `-` | 求两数之差 | `9 - 4` 得 `5` |
| 乘 | `*` | 求两数之积 | `4 * 5` 得 `20` |
| 除 | `/` | 求两数之商 | `20 / 4` 得 `5` |
| 取余 | `%` | 求两数相除的余数，只能用于整数 | `7 % 3` 得 `1` |

### 语法格式

```cpp
cout << 表达式;
```

- 表达式写在 `cout <<` 后面，**不加英文双引号**
- 程序会**先算出结果**，再把结果输出到控制台

### 代码示例

```cpp
#include <iostream>
using namespace std;

int main()
{
    cout << 123;              // 输出 123，是数字
    cout << 1 + 2;            // 输出 3
    cout << 1 + 2 + 3 + 4;    // 输出 10
    cout << 4 * 5 * 6 * 7;    // 输出 840
    return 0;
}
```

写成 `cout << "1 + 2";` 时，双引号里的内容被当作**字符串**（string）原样输出，屏幕上出现的是 `1 + 2` 这三个字符，而不是 `3`。

### 易错点

1. 把 `×`、`÷` 直接写进代码 —— 键盘上乘号必须用星号 `*`，除号必须用斜杠 `/`
2. 省略乘号 —— 数学里 `4×5` 可以写 `4 5`，C++ 里必须写 `4 * 5`
3. 给数字加引号 —— `"123"` 是字符串，`123` 是数字，输出看起来一样，但后者才能参与运算
4. 对小数用 `%` —— 取余运算符只接受整数，`7.5 % 2` 会编译报错

> **本节小结**：五种算术运算符 `+ - * / %` 与数学里的四则运算一一对应，只是乘除要写成 `*` 和 `/`。把表达式放进 `cout <<` 就能直接输出计算结果，一旦加上双引号就变成了原样输出的字符串。

## 2. 运算符优先级

一个表达式里有多个运算符时，先算谁由**优先级**（precedence）决定。C++ 的算术优先级只有三层，比数学课上的规则更简单。

### 核心概念

| 优先级 | 运算符 | 结合方向 | 说明 |
| ---- | ---- | ---- | ---- |
| 1（最高） | `( )` | 从左到右 | 括号内的先算 |
| 2 | `*` `/` `%` | 从左到右 | 乘、除、取余同级 |
| 3（最低） | `+` `-` | 从左到右 | 加、减同级 |

两条规则：

1. **先乘除取余，后加减** —— 优先级高的先算
2. **同级从左往右** —— 优先级相同时按书写顺序依次计算，这个方向叫**结合性**（associativity）

### 代码示例

```cpp
cout << 2 + 3 * 4;     // 先算 3*4=12，再算 2+12，输出 14
cout << 10 - 6 / 3;    // 先算 6/3=2，再算 10-2，输出 8
cout << 8 / 4 * 2;     // 同级从左往右：(8/4)*2=4，输出 4
cout << 2 * 3 % 4;     // 同级从左往右：(2*3)%4=6%4，输出 2
cout << 20 - 5 - 3;    // (20-5)-3=12，输出 12
```

注意 `8 / 4 * 2` 与 `8 / (4 * 2)` 的结果完全不同：前者是 `4`，后者是 `1`。

### 易错点

1. 误以为乘法一定比除法优先 —— `*`、`/`、`%` 三者**同级**，谁在前先算谁
2. 误以为减法从右往左结合 —— 减法同级运算从左往右，`20 - 5 - 3` 是 `12` 不是 `18`
3. 凭感觉猜顺序 —— 记不清优先级时直接加括号，永远不会错

> **本节小结**：算术优先级只有「括号 > 乘除取余 > 加减」三层，同级一律从左往右。拿不准顺序时加括号是最稳妥的做法。

## 3. 括号改变运算顺序

圆括号（parentheses）是唯一能强行改变默认顺序的手段，它可以把优先级低的运算提到最前面。

### 核心概念

- 括号的优先级最高，**括号里的内容先算完**，再用结果参与外面的运算
- 括号可以**嵌套**，多层嵌套时**由内向外**逐层计算
- 多余的括号不影响结果，只影响可读性，可以放心加

### 代码示例

```cpp
cout << (2 + 3) * 4;              // 先算 2+3=5，再算 5*4，输出 20
cout << 10 - (6 / 3);             // 输出 8，与不加括号结果相同，但意图更清楚
cout << (10 + 5) * 2;             // 先算 10+5=15，再算 15*2，输出 30
cout << ((2 + 3) * (4 - 1));      // 内层先算：5*3，输出 15
```

### 易错点

1. 括号不配对 —— 建议写完 `(` 立刻补 `)`，再往中间填内容
2. 使用中文括号 —— 全角的 `（）` 会让编译器报错，必须是英文半角 `()`
3. 括号位置写错 —— `(2 + 3 * 4)` 与 `(2 + 3) * 4` 只差一对括号，结果差 6

> **本节小结**：括号是改变运算顺序的唯一手段，且可以嵌套、由内向外计算。结果拿不准就加括号，顺手加上的括号还能让代码更容易读懂。

## 4. 混合运算与类型转换

当一次运算的两个操作数类型不同（一个是整数、一个是小数）时，C++ 会先做**类型转换**（type conversion），再执行运算。

### 核心概念

- 整数（integer）与整数运算，结果仍是整数
- 只要运算中**有一方是小数**，结果就是小数
- 这种自动发生的转换叫**隐式转换**（implicit conversion），方向永远是「窄类型 → 宽类型」，即 `int` 自动变成 `double`，反之不会

### 结果类型对照表

| 运算 | 结果类型 | 示例 |
| ---- | ---- | ---- |
| 整数 `+` 整数 | 整数 | `1 + 2` 得 `3` |
| 整数 `+` 小数 | 小数 | `1 + 2.5` 得 `3.5` |
| 小数 `*` 整数 | 小数 | `2.5 * 4` 得 `10` |
| 小数 `/` 小数 | 小数 | `7.5 / 2.5` 得 `3` |

加减乘除四则运算都遵循这条规律，取余 `%` 是例外，它只接受整数。

### 代码示例

```cpp
cout << 10 / 4;      // 两个整数，整数除法，输出 2
cout << 10 / 4.0;    // 一方是小数，输出 2.5
cout << 10.0 / 4;    // 一方是小数，输出 2.5
cout << 1 + 2.5;     // 输出 3.5
cout << 3 * 1.0;     // 输出 3
```

### 易错点

1. **整数除法先截断，再参与后面的运算** —— `10 / 4 * 2.0` 先算 `10 / 4` 得 `2`，再算 `2 * 2.0` 得 `4`，而不是 `5`
2. 以为写了小数变量就万事大吉 —— 表达式里两个操作数都是整数时，结果一定是整数，与最终赋给什么类型的变量无关
3. 把 `%` 和 `/` 混用 —— `10 % 3` 得 `1`，`10 / 3` 得 `3`，两者不能互相替代

> **本节小结**：运算结果的类型取决于**参与运算的两个操作数**，与接收结果的变量无关。有一方是小数结果就是小数，两边都是整数时除法会直接丢掉小数部分。

## 5. 整数与浮点混合计算

带小数点的数叫**浮点数**（floating-point number），C++ 中默认的浮点类型是 `double`。整数与浮点数混在一起算，是很常见的场景，也是最容易出错的地方。

### 核心概念

- 混算时，`int` 会先被临时转换成 `double`，再与浮点数运算，最终结果是 `double`
- 想让整数除法得到小数结果，必须**在除法发生之前**把某一方变成浮点数
- 常用三种写法，效果完全等价

### 让除法变成小数除法的三种写法

```cpp
int total = 275;   // 总分
int n = 3;         // 人数

cout << total / n;                        // 91，整数除法，小数被丢掉
cout << total / 3.0;                      // 91.6667，把 3 写成 3.0
cout << 1.0 * total / n;                  // 91.6667，先乘 1.0 整体提升为小数
cout << static_cast<double>(total) / n;   // 91.6667，显式强制转换
```

`static_cast<double>(total)` 是 C++ 的**显式类型转换**（explicit conversion），先把 `total` 转成 `double` 再去参与除法，语义最清楚。

### 完整示例

```cpp
#include <iostream>
using namespace std;

int main()
{
    int a = 7, b = 2;
    cout << a / b << endl;                 // 3
    cout << a / 2.0 << endl;               // 3.5
    cout << 1.0 * a / b << endl;           // 3.5

    double avg = (80 + 91 + 100) / 3.0;
    cout << avg << endl;                   // 90.3333
    return 0;
}
```

### 关于浮点误差

浮点数在内存中按二进制存储，很多十进制小数无法被精确表示，因此 `0.1 + 0.2` 的结果可能不是精确的 `0.3`。比较两个浮点数是否相等时不能直接写 `==`，而应判断两者差值是否足够小。这一点在本章后面的浮点类型课程中还会展开。

### 易错点

1. 写成 `double avg = (80 + 91 + 100) / 3;` —— 右边先按整数除法算出 `90`，再转成 `90.0` 存进变量，小数 `.3333` 早就丢了
2. 用 `total / n * 1.0` 想补救 —— 除法已经先算完并截断了，`1.0` 加在后面没有用
3. 直接用 `==` 比较两个浮点数 —— 二进制误差会让「看起来相等」的两个数判为不等

> **本节小结**：混合计算的关键是**在除法之前**把某一方变成浮点数，最稳的写法是乘 `1.0` 或用 `static_cast<double>` 转换。浮点数存在精度误差，不要用 `==` 直接判断相等。

## 知识框架梳理

### 核心概念总结

- **算术运算符**：`+` `-` `*` `/` `%`，其中 `%` 只接受整数
- **表达式**：运算符连接操作数构成的整体，放进 `cout <<` 会先算出结果再输出
- **优先级**：括号 > 乘除取余 > 加减，同级从左往右结合
- **括号**：唯一能改变运算顺序的手段，可嵌套、由内向外计算
- **类型转换**：混合运算时 `int` 自动转成 `double`，结果向「宽类型」看齐
- **整数除法**：两边都是整数时直接截断小数，不会四舍五入
- **浮点误差**：二进制无法精确表示所有小数，避免用 `==` 比较浮点数

### 语法速查表

| 用途 | 写法 | 示例 |
| ---- | ---- | ---- |
| 输出数字 | `cout << 数字;` | `cout << 123;` |
| 输出算式结果 | `cout << 表达式;` | `cout << 4 * 5;` 输出 `20` |
| 输出字符串 | `cout << "文本";` | `cout << "4*5";` 输出 `4*5` |
| 取余 | `a % b` | `7 % 3` 得 `1` |
| 改变优先级 | `( 表达式 )` | `(2 + 3) * 4` 得 `20` |
| 整数转小数除法 | `a / 3.0` | `7 / 2.0` 得 `3.5` |
| 乘法提升类型 | `1.0 * a / b` | `1.0 * 7 / 2` 得 `3.5` |
| 显式转换 | `static_cast<double>(a)` | `static_cast<double>(7) / 2` |
| 连续输出 | `cout << a << b;` | `cout << "结果：" << 3 + 4;` |

### 易错点提醒

1. **乘号除号写错**：代码里是 `*` 和 `/`，不是 `×` 和 `÷`
2. **给数字加引号**：`"123"` 是字符串，不能参与运算
3. **`%` 用在浮点数上**：取余只接受整数，`7.5 % 2` 直接编译失败
4. **同级运算方向**：`8 / 4 * 2` 是 `4` 而不是 `1`，同级从左往右
5. **括号用全角**：必须是英文半角 `()`，中文 `（）` 会报错
6. **整数除法截断**：`10 / 4` 得 `2`，不是 `2.5`
7. **提升类型的位置**：要小数结果必须让浮点数出现在**除法之前**，`a / b * 1.0` 已经来不及
8. **浮点数比较**：不要用 `==`，改用差值判断

> **本节小结**：算术运算按优先级和结合性求值，想改顺序就加括号；整数与浮点相遇时统一提升为浮点，结果类型由参与运算的类型决定。
