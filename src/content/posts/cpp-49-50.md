## 1. 循环中嵌 if

**循环**（loop）负责"把所有候选值走一遍"，**分支**（branch）负责"判断当前这个值要不要"。把 `if` 写进循环体，就得到课程里说的"循环和分支结合"——它是本阶段所有题目的通用骨架。

### 核心概念

- 外层结构是循环，`if` 写在循环体 `{}` **内部**
- 每循环一次，`if` 就被判断一次，一共判断 `n` 次
- `if` 的缩进要比循环体再进一层，否则逻辑容易写错
- 循环变量 `i` 就是 `if` 里被判断的对象

### 语法格式

```cpp
for (int i = 1; i <= n; i++) {
    if (条件) {
        // 满足条件时做的事
    }
}
```

### 代码示例：输出 1~n 中能被 7 整除的数

```cpp
#include <iostream>
using namespace std;

int main()
{
    int n;
    cin >> n;                     // 输入 50

    for (int i = 1; i <= n; i++) {
        if (i % 7 == 0) {         // 分支判断
            cout << i << " ";     // 7 14 21 28 35 42 49
        }
    }
    cout << endl;
    return 0;
}
```

### 说明

规律整齐时也可以用步长直接跳过，例如 `for (int i = 7; i <= n; i += 7)` 循环次数更少；但条件复杂时（如"数位和大于 10"）只能用上面的写法 A。

### 易错点

1. **`if` 写在循环外面** —— 只判断了循环结束后的 `i`，最多输出一个数
2. **循环体漏写花括号** —— `for` 只管住第一条语句，`if` 实际在循环外
3. **把 `if` 的条件写成 `i = 7`** —— 赋值而非比较，条件恒为真

> **本节小结**：循环嵌 `if` 就是"遍历 + 判断"，`if` 必须写在循环体内部，每轮判断一次 —— 这是后面筛选、计数、枚举类题目的统一骨架。

## 2. 筛选与计数

**筛选**（filtering）指用 `if` 从一堆数里挑出符合条件的；**计数**（counting）指统计这些数有多少个。两者常连着用：先筛出来，再数一数。

### 语法格式

```cpp
int cnt = 0, sum = 0;          // 循环前初始化
for (int i = 1; i <= n; i++) {
    if (条件) {
        cnt++;                 // 计数
        sum += i;              // 求和
    }
}
```

### 代码示例：统计并求和

```cpp
#include <iostream>
using namespace std;

int main()
{
    int n, cnt = 0, sum = 0;
    cin >> n;                          // 输入 100

    for (int i = 1; i <= n; i++) {
        if (i % 3 == 0) {              // 筛选 3 的倍数
            cnt++;
            sum += i;
        }
    }
    cout << "个数：" << cnt << endl;    // 33
    cout << "总和：" << sum << endl;    // 1683
    return 0;
}
```

### 找规律：先看相同、再看不同

课件里的"编程技巧"给了三步法：**① 找相同 ② 找不同 ③ 找规律**。以"1 只猪猪 1 张嘴，2 只猪猪 2 张嘴"为例：每句结构相同，都是"i 只猪猪 i 张嘴 2i 只耳朵"（找相同）；只有数字在变（找不同）；嘴数 = `i`、耳朵数 = `2 * i`（找规律）。于是代码就是把公式填进循环：

```cpp
for (int i = 1; i <= n; i++) {
    cout << i << "只猪猪" << i << "张嘴" << 2 * i << "只耳朵" << endl;
}
```

### 计数与求和的要点

| 变量 | 初值 | 循环内 | 位置 |
| ---- | ---- | ------ | ---- |
| `cnt` | 0 | `cnt++` | 循环**之前**定义，`if` **之内**更新 |
| `sum` | 0 | `sum += i` | 循环**之前**定义，`if` **之内**更新 |

### 易错点

1. **变量定义在循环里** —— 每轮被重置，结果永远是 0 或最后一个值
2. **`cnt++` 写在 `if` 外** —— 数的是全部数，不是筛选后的数
3. **`sum` 忘清 0** —— 未初始化变量是随机值，结果无意义
4. **求平均写 `sum / cnt`** —— 整数除法会丢小数，要写 `(double)sum / cnt`

> **本节小结**：筛选是"循环 + `if`"，计数与求和是在 `if` 里加 `cnt++` 和 `sum += i`，两个变量必须在循环外清零、在 `if` 内更新。

## 3. 水仙花数的数学原理

**水仙花数**（narcissistic number，也叫阿姆斯特朗数）指一个三位数，它的**各位数字的立方和等于它本身**。

### 核心概念

- 水仙花数一定是**三位数**，范围是 `100 ~ 999`
- 判断条件：`百位³ + 十位³ + 个位³ == 原数`
- 例：`153` 是水仙花数，因为 `1³ + 5³ + 3³ = 1 + 125 + 27 = 153`
- 全部水仙花数只有 4 个：`153`、`370`、`371`、`407`

### 三位数的数位分离

上一课学过 `% 10` 取个位、`/ 10` 去个位，对三位数 `n`：

| 位数 | 公式 | `n = 123` 时 |
| ---- | ---- | ------------ |
| 个位 | `n % 10` | 3 |
| 十位 | `n / 10 % 10` | 2 |
| 百位 | `n / 100` | 1 |

### 验证 153 与枚举范围

对 `153` 做分离：个位 `153 % 10 = 3`、十位 `153 / 10 % 10 = 5`、百位 `153 / 100 = 1`，于是 `1³ + 5³ + 3³ = 1 + 125 + 27 = 153`，正好等于原数，所以 153 是水仙花数。

为什么只枚举到 999？水仙花数的定义要求"原数 = 立方和"，而原数本身最多三位，所以只需在 100~999 中枚举即可。

### 易错点

1. **范围写成 1~999** —— 一位数、两位数不参与判断，应从 100 开始
2. **立方写成平方** —— `a * a` 是平方，立方要 `a * a * a`
3. **数位分离公式写错** —— 十位必须是 `n / 10 % 10`，只写 `n / 10` 得不到十位
4. **用 `^` 求立方** —— `a ^ 3` 是按位异或，必须用连乘或 `pow(a, 3)`

> **本节小结**：水仙花数是"三位数 + 各位立方和等于自身"，判断的关键是先用 `% 10`、`/ 10 % 10`、`/ 100` 分离出三位数字，再算立方和与原数比较。

## 4. 水仙花数实现

### 核心概念

水仙花数的实现是"**枚举**（enumeration）+ 判断"的典型：用循环把 100~999 全部走一遍，对每个数做一次水仙花判断，符合就输出。这正是第 1 节"循环嵌 `if`"骨架的直接应用。

### 代码示例

```cpp
#include <iostream>
using namespace std;

int main()
{
    for (int n = 100; n <= 999; n++) {      // 枚举所有三位数
        int ge   = n % 10;                  // 个位
        int shi  = n / 10 % 10;             // 十位
        int bai  = n / 100;                 // 百位

        if (ge * ge * ge + shi * shi * shi + bai * bai * bai == n) {
            cout << n << endl;              // 符合条件就输出
        }
    }
    return 0;
}
```

输出 `153`、`370`、`371`、`407` 四个数，每行一个。

### 变体：统计个数与求和

题目常要求"输出个数"或"输出总和"，只需把 `cout` 换成计数器与求和器：

```cpp
int cnt = 0, sum = 0;
for (int n = 100; n <= 999; n++) {
    int ge = n % 10, shi = n / 10 % 10, bai = n / 100;
    if (ge*ge*ge + shi*shi*shi + bai*bai*bai == n) {
        cnt++;
        sum += n;
    }
}
// cnt = 4，sum = 153 + 370 + 371 + 407 = 1301
```

### 举一反三

水仙花数的判断可以推广：四叶玫瑰数是四位、各位**四次方**和等于自身，五角星数是五位、各位**五次方**和等于自身。位数变多时，分离数位就不能再手写三行，应改用 `while (n > 0)` 循环分离。

### 易错点

1. **循环范围写 `n < 999`** —— 漏掉了 999，习惯上应写 `<=`
2. **判断用 `=`** —— `if (... = n)` 是赋值，编译报错或逻辑全错
3. **把 `n` 改掉了** —— 若在分离时写 `n = n / 10`，后面比较的就不是原数了，必须先备份
4. **输出格式不符** —— 题目要求空格分隔时不要用 `endl`，要求每行一个时不要用空格

> **本节小结**：水仙花数 = 枚举 100~999 + 分离三位数字 + 立方和判断，骨架就是"循环 + `if`"；把 `cout` 换成 `cnt++`、`sum += n` 就能顺手完成计数与求和。

## 知识框架梳理

### 核心概念总结

- **循环嵌 `if`**：循环遍历所有候选值，`if` 判断当前值要不要
- **筛选**：`if` 写在循环体内，每轮判断一次
- **计数与求和**：在 `if` 里写 `cnt++` 与 `sum += i`，变量在循环外清零
- **找规律三步法**：找相同、找不同、找规律
- **水仙花数**：三位数，各位立方和等于自身，共 153、370、371、407
- **枚举思想**：把可能范围全部试一遍，逐个判断

### 语法速查表

| 用途 | 写法 |
| ---- | ---- |
| 循环嵌 `if` | `for (...) { if (条件) { ... } }` |
| 筛出 3 的倍数 | `if (i % 3 == 0)` |
| 计数 | `cnt++;` |
| 求和 | `sum += i;` |
| 取个位 | `n % 10` |
| 取十位 | `n / 10 % 10` |
| 取百位 | `n / 100` |
| 枚举三位数 | `for (int n = 100; n <= 999; n++)` |

### 易错点提醒

1. **`if` 写在循环外**：只判断一次，结果基本都不对
2. **计数求和变量定义在循环内**：每轮重置，结果为 0
3. **`==` 写成 `=`**：赋值当比较，条件恒真
4. **枚举范围差一**：应从 100 开始到 999 结束
5. **立方写成平方**：`a * a` 是平方，立方要 `a * a * a`
6. **用 `^` 求幂**：`^` 是按位异或，不能当乘方

> **本节小结**：把"循环 + `if`"这套骨架套上枚举范围和水仙花判断条件，就得到完整的解法；换掉判断条件就能解决同类数字问题，这正是循环与分支结合的价值。
