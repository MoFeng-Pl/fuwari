## 1. 为什么需要循环

### 核心概念

**循环**（loop）是让同一段代码被重复执行多次的程序结构，它把「重复」这件枯燥的事交给计算机，人只需要写一次。

判断要不要用循环有一个简单的标准：代码里出现了**大量结构完全相同、只有个别数值不同的语句**，就该换成循环。

### 代码示例

不用循环输出 5 行：

```cpp
cout << "Hello" << endl;
cout << "Hello" << endl;
cout << "Hello" << endl;
cout << "Hello" << endl;
cout << "Hello" << endl;
```

用循环输出 5 行：

```cpp
for (int i = 1; i <= 5; i = i + 1)
{
    cout << "Hello" << endl;
}
```

### 对比

| 方面 | 手写重复语句 | 使用循环 |
| ---- | ------------ | -------- |
| 代码行数 | 与次数成正比 | 固定几行 |
| 修改次数 | 100 次就要改 100 处 | 只改条件一处 |
| 出错概率 | 容易漏改、错位 | 结构统一，不易出错 |
| 次数可变 | 写死，无法随输入变化 | 可用变量控制 |

> **本节小结**：循环用来消除「结构相同、次数固定」的重复代码，它的价值不只是少写几行，更在于循环次数可以交给变量和输入决定。

## 2. for 循环语法

### 语法格式

```cpp
for (循环变量初始化; 循环条件; 循环变量变化)
{
    循环体;
}
```

- **循环变量**（loop variable）：专门控制循环次数的变量，习惯命名为 `i`、`j`、`k`
- **循环变量初始化**：给循环变量一个起点，整条 `for` 只执行一次
- **循环条件**：一个关系表达式，结果为真时才继续循环
- **循环变量变化**：每轮循环体结束后执行，通常让 `i` 加 1
- **循环体**（loop body）：花括号里真正被重复执行的语句

三个部分之间用**分号** `;` 隔开，圆括号后面的花括号不能省。

### 代码示例

```cpp
for (int i = 1; i <= 3; i = i + 1)
{
    cout << "第" << i << "次" << endl;
}
```

输出三行：`第1次`、`第2次`、`第3次`。

### 易错点

1. 三个部分之间写成分号以外的符号（逗号、顿号）都会编译报错
2. 圆括号后面**不要**再加分号，`for (...);` 表示循环体是一条空语句
3. 循环体有多条语句时必须加花括号，否则只有第一条会被重复执行

> **本节小结**：`for` 把「起点、条件、步进」三件事写进圆括号，格式固定为「初始化; 条件; 变化」，三段之间只能是分号。

## 3. 循环三要素

### 核心概念

一个正确的 `for` 循环必须让三个要素互相配合，缺一不可：

| 要素 | 英文 | 写在 for 的位置 | 作用 | 示例 |
| ---- | ---- | --------------- | ---- | ---- |
| 初值 | initialization | 第一个分号前 | 决定从几开始 | `int i = 1` |
| 条件 | condition | 两个分号之间 | 决定何时停下 | `i <= 5` |
| 步进 | step | 第二个分号后 | 决定每次走多远 | `i = i + 1` |

三者合起来决定了循环次数：从初值出发，每轮按步进前进，直到条件不再成立。

### 代码示例

```cpp
// 输出 1 2 3 4 5
for (int i = 1; i <= 5; i = i + 1)
{
    cout << i << " ";
}

// 步进改为 2，输出 1 3 5
for (int i = 1; i <= 5; i = i + 2)
{
    cout << i << " ";
}
```

### 易错点

1. **三要素不配套**：初值写 `1`、条件写 `i < 5`，只会输出 4 个数
2. **步进方向与条件相反**：`i = i + 1` 配 `i >= 5`，条件一开始就不成立，一次也不执行
3. **把步进写成 `i + 1`**：`i + 1` 只是算出一个值，没有赋回 `i`，循环变量永远不变

> **本节小结**：初值、条件、步进要朝着同一个方向配套设计，任何一处写反都会导致少执行、多执行或死循环。

## 4. 执行流程拆解

### 核心概念

`for` 的执行顺序不是一个方向走到底，而是带一个回跳：

1. 执行**循环变量初始化**，只做一次
2. 判断**循环条件**
3. 条件成立，进入循环体
4. 执行**循环体**的全部语句
5. 执行**循环变量变化**
6. 回到第 2 步继续判断
7. 条件不成立，跳出循环，执行 `for` 后面的语句

### 代码示例

```cpp
for (int i = 1; i <= 3; i = i + 1)
{
    cout << i << " ";
}
cout << "结束";
```

逐轮追踪：

| 轮次 | 判断时 i | 条件 `i <= 3` | 执行循环体 | 输出 | 变化后 i |
| ---- | -------- | ------------- | ---------- | ---- | -------- |
| 1 | 1 | 真 | 是 | `1 ` | 2 |
| 2 | 2 | 真 | 是 | `2 ` | 3 |
| 3 | 3 | 真 | 是 | `3 ` | 4 |
| 4 | 4 | 假 | 否 | — | — |

最终输出 `1 2 3 结束`。

### 根据输入循环 n 次

```cpp
int n;
cin >> n;
for (int i = 1; i <= n; i = i + 1)
{
    // 循环体，共执行 n 次
}
```

### 易错点

循环正常结束后，循环变量的值是**条件第一次不成立时的值**（上例中是 4，不是 3）。

> **本节小结**：`for` 的执行顺序是「初始化一次 → 判断 → 循环体 → 变化 → 再判断」，记住这个闭环就能手工推出每一轮的变量值。

## 5. 常见错误

### 易错点

| 错误写法 | 后果 | 正确写法 |
| -------- | ---- | -------- |
| `for (int i = 1, i <= 5, i++)` | 编译报错 | 三段之间用 `;` |
| `for (int i = 1; i <= 5; i++);` | 循环体为空，什么也不做 | 去掉圆括号后的分号 |
| `for (int i = 1; i <= 5; i + 1)` | 死循环，i 永远是 1 | `i = i + 1` 或 `i++` |
| `for (int i = 1; i >= 5; i++)` | 一次也不执行 | 条件方向与步进一致 |
| 循环体两条语句不加 `{}` | 只有第一条被重复 | 补上花括号 |

### 核心概念

**死循环**（infinite loop）是条件永远为真的循环，程序会卡在循环里不再往下执行。初学阶段的死循环九成来自**步进写错或漏写**。

> **本节小结**：`for` 的报错集中在分号、花括号、步进三处，写完先读一遍圆括号里的三段是否「方向一致、能停下来」。

## 知识框架梳理

### 核心概念总结

- **循环**（loop）：让一段代码重复执行多次的结构，次数可以随输入变化
- **循环变量**（loop variable）：控制循环次数的变量，通常用 `i`
- **循环体**（loop body）：被重复执行的语句块
- **三要素**：初值（initialization）、条件（condition）、步进（step）
- **执行闭环**：初始化一次 → 判断 → 循环体 → 变化 → 再判断

### 语法速查表

| 用途 | 写法 |
| ---- | ---- |
| for 基本结构 | `for (初始化; 条件; 变化) { 循环体 }` |
| 循环 5 次 | `for (int i = 1; i <= 5; i = i + 1)` |
| 步进为 2 | `for (int i = 1; i <= 9; i = i + 2)` |
| 从 0 开始 | `for (int i = 0; i < n; i = i + 1)` |
| 按输入决定次数 | `cin >> n;` 后 `for (int i = 1; i <= n; i = i + 1)` |
| 递减循环 | `for (int i = 5; i >= 1; i = i - 1)` |

### 易错点提醒

1. **分号位置**：三段之间是分号，圆括号后不要多写分号
2. **花括号**：循环体超过一条语句必须加 `{}`
3. **步进必须赋值**：`i + 1` 不改变 `i`，要写 `i = i + 1` 或 `i++`
4. **条件方向**：递增配 `<=` 或 `<`，递减配 `>=` 或 `>`
5. **`<=` 与 `<`**：`i <= n` 会取到 n，`i < n` 只到 n-1
6. **作用域**：`for (int i ...)` 里的 `i` 出了循环就不能再用

> **本节小结**：写 `for` 只需回答三个问题——从几开始、到几停下、每次走几步；三问答完，循环就写对了。
