## 1. 嵌套循环的结构

### 核心概念

**嵌套循环**（nested loop）指一个循环的循环体里又写了另一个循环。外面那层叫**外层循环**（outer loop），里面那层叫**内层循环**（inner loop）。课程里用一句话概括：**一个循环里有另一个循环**。

### 语法格式

```cpp
for (外层变量初始化; 外层条件; 外层变量更新)
{
    for (内层变量初始化; 内层条件; 内层变量更新)
    {
        内层循环体;
    }
    外层循环体的其余语句;
}
```

- 内层循环**整体**（连同它自己的 `for` 行和一对大括号）都写在外层循环的大括号**内部**
- 两层要用**不同的循环变量**，习惯上外层用 `i`、内层用 `j`
- 内层大括号之后还可以继续写外层的语句，比如换行

### 代码示例

打印 3 行、每行 20 个加号：

```cpp
for (int i = 1; i <= 3; i++)        // 外层循环：决定行
{
    for (int j = 1; j <= 20; j++)   // 内层循环：决定列
    {
        cout << "+";
    }
    cout << endl;                   // 一行打满后换行
}
```

运行结果：

```
++++++++++++++++++++
++++++++++++++++++++
++++++++++++++++++++
```

`endl` 写在内层循环**外面**、外层循环**里面**，所以每打满 20 个加号才换一次行。

### 易错点

1. `endl` 写进内层循环 —— 每输出一个加号就换行，结果变成 60 行、每行 1 个加号
2. 两层用同一个变量名 `i` —— 内层会把外层的 `i` 改掉，外层循环次数全乱
3. 内层循环写在外层大括号**外面** —— 那就成了两个并列的单层循环，不是嵌套
4. 内层漏写大括号 —— 内层循环体只剩下紧随其后的第一条语句

> **本节小结**：嵌套循环就是「循环里再套一个循环」，内层整体写在外层的大括号内，两层使用不同循环变量，换行语句放在内层之外、外层之内。

## 2. 内层执行次数

### 核心概念

嵌套循环有一条铁律：**外层循环每走 1 次，内层循环就要从头到尾完整执行一遍**。内层不是在整段程序里只跑一次。

所以循环体的总执行次数为：

```
总次数 = 外层次数 × 内层次数
```

| 外层次数 | 内层次数 | 总执行次数 |
| -------- | -------- | ---------- |
| 3 | 20 | 60 |
| 3 | 2 | 6 |
| 5 | 5 | 25 |

### 执行过程

以「外层 `i` 从 1 到 3、内层 `j` 从 1 到 2」为例，控制台的走向是：

1. `i = 1`，判断 `i <= 3` 成立，进入外层循环体
2. `j = 1`，判断 `j <= 2` 成立，输出 1 个 `+`
3. `j++` 变成 2，仍成立，再输出 1 个 `+`
4. `j++` 变成 3，`j <= 2` 不成立，**内层结束**，执行 `cout << endl`
5. `i++` 变成 2，再次进入外层循环体，内层**重新从 `j = 1` 开始**
6. 重复第 2～4 步，直到 `i` 变成 4，外层条件不成立，整段循环结束

第 1 轮外层跑出 `++`，第 2 轮又是 `++`，第 3 轮还是 `++`，最终 3 行、每行 2 个加号。

### 易错点

1. 以为内层只执行一轮 —— 实际是「外层次数 × 内层次数」次
2. 把总次数算成「外层 + 内层」（3 + 2 = 5）—— 应当是乘法
3. 用 `while` 写内层时忘记**重新给内层变量赋初值** —— 第二轮内层的条件一开始就不成立，一行也打不出来

> **本节小结**：内层循环在外层每一轮里都会完整跑一遍，总执行次数是两层次数的乘积，理解这一点才能算准输出。

## 3. 外层变量控制行

### 核心概念

先看一个单层循环：

```cpp
for (int i = 1; i <= 3; i++)
{
    cout << "+++++" << endl;
}
```

输出 3 行、每行 5 个加号。这里的 `i` 从 1 走到 3，**每走一次就输出一整行**，所以循环次数直接等于行数。

把这个结论搬进嵌套循环：**外层循环的循环变量控制行**，外层跑几轮，就输出几行。

### 代码示例

```cpp
// 外层 i 走 1、2、3 —— 共 3 行
for (int i = 1; i <= 3; i++)
{
    for (int j = 1; j <= 2; j++)
    {
        cout << "+";
    }
    cout << endl;   // 每结束一行换行一次
}
```

`i` 取 1 时打完第 1 行，取 2 时打完第 2 行，取 3 时打完第 3 行。想改成 5 行，只改外层条件 `i <= 5` 即可。

### 易错点

1. 外层条件写成 `i < 3` —— 只得到 2 行，想要 3 行必须写 `i <= 3`
2. 换行语句被搬到内层，行数就由内层决定了，外层不再单独控制行
3. 在外层循环体里乱改 `i` —— 循环次数不可控

> **本节小结**：外层循环变量决定「打几行」，外层条件就是行数，改行数只改外层的判断条件。

## 4. 内层变量控制列

### 核心概念

**内层循环的循环变量控制列**。内层每转一次就往当前行里多放一个字符，内层转几轮，这一行就有几列。

```cpp
for (int j = 1; j <= 2; j++)   // 每行 2 列
{
    cout << "+";
}
```

`j` 取 1 输出第 1 个 `+`，取 2 输出第 2 个 `+`；`j` 变成 3 时条件不成立，内层结束，接着换行。所以 3 行 2 列的输出是：

```
++
++
++
```

| 改动位置 | 效果 |
| -------- | ---- |
| 外层条件 `i <= 3` | 3 行 |
| 内层条件 `j <= 2` | 每行 2 列 |
| 内层输出内容 `"+"` | 每列显示什么字符 |

### 易错点

1. 内层条件写 `j <= 0` 或初值写错 —— 一行里一个字符都不输出，只剩空行
2. 内层输出用了 `endl` —— 列变成行
3. 只记「行看外层、列看内层」却把两者条件写反 —— 想打 3 行 2 列却打成了 2 行 3 列

> **本节小结**：内层循环变量决定「一行打几列」，内层条件就是列数；行看外层、列看内层，这是嵌套循环画图的总口诀。

## 5. 嵌套循环的常见写法

### 核心概念

嵌套循环的书写有固定套路：**先定行、再定列、最后换行**。三段各就各位，图形就不会画歪。

```cpp
for (int i = 1; i <= 行数; i++)        // 第一步：定行
{
    for (int j = 1; j <= 列数; j++)    // 第二步：定列
    {
        cout << 要重复的字符;
    }
    cout << endl;                      // 第三步：换行
}
```

### 两种常见变体

**列数随行变化**：内层条件用外层变量当上界，第 `i` 行就打 `i` 个字符。

```cpp
for (int i = 1; i <= 4; i++) {
    for (int j = 1; j <= i; j++) {    // 上界是外层变量 i
        cout << "*";
    }
    cout << endl;
}
```

第 1 行 1 个 `*`、第 2 行 2 个……最后得到 4 行直角三角形。

**行列由输入决定**：把行数、列数交给变量，程序更通用。

```cpp
int row, col;   cin >> row >> col;
for (int i = 1; i <= row; i++) {
    for (int j = 1; j <= col; j++) cout << "#";
    cout << endl;
}
```

### 易错点

1. 缩进不规范 —— 内层要明显缩进一层，否则大括号配错也看不出来
2. 忘记换行 —— 所有行列挤成一行

> **本节小结**：嵌套循环按「外层定行 → 内层定列 → 内层后换行」三步写，行列可以是常量、外层变量或键盘输入，套用这个模板就能画出各种字符图形。

## 知识框架梳理

### 核心概念总结

- **嵌套循环**：一个循环里再套一个循环，外层管行、内层管列
- **执行规律**：外层走 1 次，内层完整跑一遍；总次数 = 外层次数 × 内层次数
- **外层变量**：控制行数，外层条件就是行数
- **内层变量**：控制每行的列数，内层条件就是列数
- **书写套路**：外层定行 → 内层定列 → 内层结束后换行

### 语法速查表

| 用途 | 写法 |
| ---- | ---- |
| 嵌套循环骨架 | `for (i...) { for (j...) { ... } ... }` |
| 打印 3 行 20 列加号 | `for (int i=1;i<=3;i++){ for (int j=1;j<=20;j++) cout<<"+"; cout<<endl; }` |
| 每行 i 个字符 | `for (int j = 1; j <= i; j++)` |
| 行列由输入决定 | `cin >> row >> col;` 再用 `i<=row`、`j<=col` |
| 行末换行 | 内层大括号之后写 `cout << endl;` |

### 易错点提醒

1. **`endl` 位置**：必须写在内层循环外、外层循环内，写进内层就变成一列一行
2. **循环变量重名**：外层 `i`、内层 `j`，不能都用 `i`
3. **次数算成加法**：总次数是两层相乘，不是相加
4. **漏写内层初值重置**：用 `while` 写内层时，每轮都要重新给内层变量赋值
5. **`<` 与 `<=`**：从 1 数到 3 要写 `i <= 3`，写成 `i < 3` 会少一行

> **本节小结**：嵌套循环是「外层走一行、内层走完这一行」，总次数为两层相乘，外层变量定行、内层变量定列。
