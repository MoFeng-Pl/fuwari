## 1. 内层 break 的作用范围

### 核心概念

**`break`** 的作用是**立即结束当前所在的这一层循环**，程序接着执行循环后面的语句。

放进嵌套循环里，规则就更具体了：**在内层循环中使用 `break`，只会结束内层循环**。外层循环不受影响，仍然会继续下一轮。

### 语法格式

```cpp
for (int i = 1; i <= 3; i++)          // 外层：3 轮，break 管不到
{
    for (int j = 1; j <= 5; j++)      // 内层：5 轮
    {
        break;                        // 只跳出这一层内层循环
        cout << j << " ";             // 永远执行不到
    }
    cout << "*" << endl;              // 内层结束后照常执行
}
```

### 代码示例

```cpp
for (int i = 1; i <= 3; i++)
{
    for (int j = 1; j <= 5; j++)
    {
        break;                 // 第 1 轮就跳出内层
        cout << j << " ";
    }
    cout << "*" << endl;       // 每轮外层仍输出一个 *
}
```

输出：

```
*
*
*
```

三行都只有一个 `*`。原因是：每进入一次内层，`break` 立刻结束内层，`cout << j` 一次都没执行；而外层三轮一轮不少，所以还是 3 行。

### 易错点

1. 以为 `break` 能跳出两层 —— 它只管自己所在的一层
2. `break` 写在循环体第一行 —— 内层等于「一次都不干活」，后面的语句成了死代码
3. 以为内层 `break` 会让外层也停下来 —— 外层照旧跑完全部轮数

> **本节小结**：`break` 的作用范围只有它所在的那一层循环，内层 `break` 结束内层、外层继续，所以输出行数不变、每行内容变少。

## 2. 如何跳出多层循环

### 核心概念

C++ 的 `break` 天生只能跳一层。想让程序**一次退出所有循环**（例如在矩阵里找到目标后立刻收工），需要借助别的写法。常用有四种：

| 写法 | 思路 | 推荐度 |
| ---- | ---- | ------ |
| 标志变量 | 内层 `break` 前先把标志置位，外层再根据标志 `break` | ★★★ 最常用 |
| 封装成函数 | 用 `return` 直接结束整个函数 | ★★★ 最清晰 |
| `goto` 标号 | 直接跳到循环外的标号处 | ★ 可读性差，少用 |

### 写法一：标志变量

用一个 `bool` 变量记录「是否已经找到」，内层跳出后由外层检查它：

```cpp
bool found = false;
for (int i = 0; i < 3; i++)
{
    for (int j = 0; j < 3; j++)
    {
        if (a[i][j] == target)
        {
            found = true;
            break;          // 先跳出内层
        }
    }
    if (found) break;       // 再由外层检查标志，跳出外层
}
```

也可以把标志直接塞进外层的判断条件，省掉外层那句 `break`：`for (int i = 0; i < 3 && !found; i++)`。

### 写法二：封装成函数

把双层循环放进函数，命中时直接 `return`，一句话结束全部循环：

```cpp
bool findTarget(int a[3][3], int target)
{
    for (int i = 0; i < 3; i++)
        for (int j = 0; j < 3; j++)
            if (a[i][j] == target) return true;
    return false;
}
```

### 易错点

1. 只写内层 `break` 就以为跳出了全部循环 —— 外层还在跑
2. 标志变量忘记初始化 —— 判断结果随机
3. 标志置位后忘了在外层补 `if (found) break;`

> **本节小结**：`break` 只跳一层，跳出多层要靠「标志变量 + 外层判断」或「封装成函数用 `return`」，`goto` 能用但不建议。

## 3. 嵌套中的 continue

### 核心概念

**`continue`** 的作用是**结束本次循环，直接进入下一次循环**——不跳出循环，只是跳过本轮剩下的语句。

放进嵌套循环里：**在内层循环中使用 `continue`，只会跳过内层的这一次**，内层接着下一轮，外层完全不受影响。

和 `break` 的差别可以这样记：

| 语句 | 作用范围 | 对当前层的影响 | 对外层的影响 |
| ---- | -------- | -------------- | ------------ |
| `break` | 所在那一层 | 整层结束 | 无 |
| `continue` | 所在那一层 | 只跳过这一轮 | 无 |

### 代码示例

```cpp
for (int i = 1; i <= 3; i++)          // 外层：3 行
{
    for (int j = 1; j <= 5; j++)      // 内层：5 轮
    {
        continue;                     // 每轮都跳过后面那句
        cout << j << " ";
    }
    cout << "+" << endl;              // 内层结束后照常换行
}
```

输出：

```
+
+
+
```

内层的 `cout << j` 被 `continue` 跳过 5 次，一行里什么都没打；但内层仍然转满了 5 轮才结束，所以外层照常输出 3 个 `+`。

### 有筛选条件的例子

`continue` 真正的用处是「挑着跳过」：

```cpp
for (int i = 1; i <= 2; i++)
{
    for (int j = 1; j <= 5; j++)
    {
        if (j == 3) continue;         // 只跳过第 3 列
        cout << j << " ";
    }
    cout << endl;
}
```

输出：

```
1 2 4 5
1 2 4 5
```

第 3 列被跳过，其余列照常输出，行数一行不少。

### 易错点

1. 把 `continue` 当成「结束整个循环」——它只是跳过本轮
2. `continue` 写在所有输出语句之前 —— 内层等于空转，一行里什么都不输出
3. `continue` 之后的语句成了死代码，写了也没用

> **本节小结**：`continue` 只跳过本层的这一轮，内层 `continue` 不影响外层；它适合「挑着跳过某些列」，而 `break` 是整层收工。

## 4. 常见错误

### 错误一：以为 break 能跳出两层

```cpp
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 3; j++) {
        if (j == 2) break;      // 只结束内层
    }
}
// 外层仍然执行了 3 轮
```

想要全部退出，必须加上标志变量或封装函数。

### 错误二：break 写在 if 之外

`for (int j = 1; j <= 5; j++) { break; cout << j; }` 这种写法里 `break` 无条件执行，循环只转 1 轮。`break` 一定要放进 `if` 里，由条件控制，否则循环第一轮就结束了。

### 错误三：把 continue 用在 while 的变量更新之前

```cpp
int j = 1;
while (j <= 5) {
    if (j == 3) continue;       // j 永远停在 3，死循环
    j++;
}
```

`for` 循环的 `j++` 写在括号里，`continue` 不会跳过它；`while` 的更新语句写在循环体里，`continue` 会跳过，于是变量不再变化。用 `while` 时要把更新语句放在 `continue` 之前。

### 错误四：把 break 当成 return

`break` 只离开循环，循环后面的语句**仍会执行**；只有 `return` 才会结束整个函数。想「找到就彻底收工」，用 `return` 更直接。

> **本节小结**：这些错误都源于「没数清 `break` / `continue` 到底在哪一层」——写嵌套循环时先确认语句所在的大括号层级，再判断它的作用范围。

## 知识框架梳理

### 核心概念总结

- **`break`**：结束**当前所在这一层**循环，外层不受影响
- **`continue`**：结束**当前这一轮**，同一层的下一轮照常开始
- **内层 break**：内层提前收工，外层继续跑完全部轮数
- **跳出多层**：标志变量 + 外层判断、合并循环条件、封装成函数用 `return`
- **内层 continue**：只跳过内层的某几轮，行数不变、内容变少

### 语法速查表

| 用途 | 写法 |
| ---- | ---- |
| 结束当前层循环 | `break;` |
| 跳过本轮剩余语句 | `continue;` |
| 条件跳出内层 | `if (条件) break;` |
| 跳过某一列 | `if (j == 3) continue;` |
| 跳出两层（标志法） | 内层 `found = true; break;`，外层 `if (found) break;` |
| 跳出两层（条件法） | `for (int i = 0; i < n && !found; i++)` |
| 跳出全部（函数法） | 命中时 `return true;` |

### 易错点提醒

1. **`break` 只跳一层**：想退出两层必须另想办法
2. **`break` 要配 `if`**：无条件 `break` 让循环只转一轮
3. **`continue` 不是结束循环**：它只跳过本轮，循环还会继续
4. **`continue` 后面的语句是死代码**：写了也执行不到
5. **`while` + `continue` 容易死循环**：变量更新要放在 `continue` 之前
6. **`switch` 的 `break` 只结束分支**：和循环的 `break` 不是一回事

> **本节小结**：break 只跳出当前这一层，continue 只跳过当前这一轮；想跳出多层就得加标记或改用条件控制。
