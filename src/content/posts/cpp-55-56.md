## 1. 批量读入并存储

数组最常见的用法，是把一串数据**按下标顺序存进去**，再统一处理。

### 核心写法

```cpp
int n;
cin >> n;                       // 先读入数据个数

int a[105];                     // 长度按上限多开几个
for (int i = 0; i < n; i++)
{
    cin >> a[i];                // 第 i 个数据存进 a[i]
}
```

### 三条约定

1. **个数先行**：先读 `n`，循环次数由 `n` 决定，数组长度要 ≥ n
2. **下标即序号**：第 1 个数据存 `a[0]`，第 i 个存 `a[i-1]`
3. **长度留余量**：题目上限 100 就开 105，避免数据超一点就爆界

### 数组该定义在哪里

同样的读入代码，数组位置不同，行为不同：

| 定义位置 | 初始化情况 | 容量 | 建议 |
| -------- | ---------- | ---- | ---- |
| 主函数内 | 值不定（垃圾值） | 小（栈空间有限） | 小数组 |
| 主函数外 | 全是 0 | 大 | 长度 10 万以上必须放这里 |

### 易错点

- 主函数内定义 `int a[1000000];` 可能直接崩溃，应移到主函数外
- 主函数内 `int a[10];` 未初始化就输出，得到的是随机值

> **本节小结**：批量存储的骨架是"读 n → 循环 `cin >> a[i]`"，同时要选对数组位置：主函数外自动清零且能开大。

## 2. 数组元素移动

"移动"本质是**把某个元素的值搬到另一个下标位置**。

### 语法格式

```cpp
a[目标下标] = a[源下标];
```

```cpp
int a[5] = {10, 20, 30, 40, 50};

a[2] = a[1];      // 把 a[1] 的值搬到 a[2] → {10,20,20,40,50}
```

### 关键特性：源元素不变

`a[2] = a[1];` 之后，`a[1]` 仍然是 20。赋值只是**复制**，并没有把原位置清空。

### 交换两个元素要借助临时变量

```cpp
int t = a[0];     // 先备份
a[0] = a[4];
a[4] = t;         // 再写回，否则原值已被覆盖
```

如果直接写 `a[0] = a[4]; a[4] = a[0];`，两个元素都会变成原 `a[4]` 的值。

> **本节小结**：移动就是下标间赋值，赋值是复制而非搬运；要交换或覆盖前先备份到临时变量。

## 3. 整体平移

把所有元素**统一向左或向右挪若干个位置**，才叫整体平移（shift）。

### 左移一位

把 `a[i+1]` 搬到 `a[i]`，**从左往右**遍历：

```cpp
int a[6] = {1, 2, 3, 4, 5, 6};

for (int i = 0; i < 5; i++)      // i 从 0 到 4
{
    a[i] = a[i + 1];
}
// 结果：{2,3,4,5,6,6}，首元素 1 被覆盖丢失
```

### 右移一位

把 `a[i]` 搬到 `a[i+1]`，必须**从右往左**遍历（即逆序遍历）：

```cpp
int a[6] = {1, 2, 3, 4, 5, 0};

for (int i = 4; i >= 0; i--)     // i 从 4 递减到 0
{
    a[i + 1] = a[i];
}
// 结果：{1,1,2,3,4,5}
```

### 为什么方向不能反

| 平移方向 | 必须先处理的一端 | 遍历顺序 | 原因 |
| -------- | ---------------- | -------- | ---- |
| 左移 | 左侧 | 从左往右 `i++` | 否则右侧值先被覆盖丢失 |
| 右移 | 右侧 | 从右往左 `i--` | 否则左侧值先被覆盖丢失 |

判断口诀：**先搬"将要被覆盖"的那一端**。右移时 `a[i+1]` 会被写，所以先写最右边的 `a[n-1]`。

> **本节小结**：平移的方向决定遍历的方向——左移正序、右移逆序，写反了就会把还没搬走的数据覆盖掉。

## 4. 移动的边界处理

### 三类边界

1. **上界**：右移时 `a[i+1]` 最大到 `a[n-1]`，所以 `i` 最大取 `n-2`；若 `i` 取到 `n-1`，`a[n]` 就越界
2. **下界**：左移时 `a[i]` 最小是 `a[0]`，`i` 不能为负
3. **数据丢失**：左移会丢掉 `a[0]`，右移会覆盖 `a[n-1]`，被挤出的那个元素要提前备份

```cpp
int a[6] = {1, 2, 3, 4, 5, 6};

int first = a[0];                // 左移前备份要丢的元素

for (int i = 0; i < 5; i++)
{
    a[i] = a[i + 1];
}
a[5] = first;                    // 需要时再补回末尾（循环左移）
```

### 平移 k 位的写法

```cpp
for (int k = 0; k < 3; k++)      // 重复 3 次单步左移 = 左移 3 位
{
    int first = a[0];
    for (int i = 0; i < n - 1; i++) { a[i] = a[i + 1]; }
    a[n - 1] = first;
}
```

### 易错点

- 循环条件写成 `i <= n - 1` 做左移，最后一次会读 `a[n]`，越界
- 忘记备份首尾元素，平移后数据凭空少一个
- 平移次数和单步方向不匹配，结果与预期相反

> **本节小结**：边界处理盯三件事——`i` 的范围别越界、被挤出的元素先备份、多位平移用"重复单步"最不容易出错。

## 知识框架梳理

### 核心概念总结

- **批量存储**：读入个数 n，循环 `cin >> a[i]`，长度按上限多开 5 个
- **存储位置**：主函数内小数组值不定，主函数外大数组全为 0，10 万以上放外面
- **元素移动**：`a[目标] = a[源];` 是复制，源不变；交换需临时变量
- **整体平移**：左移正序遍历，右移逆序遍历，方向必须"先搬被覆盖的一端"
- **边界**：`i` 不越界、挤出元素先备份、多位平移重复单步

### 语法速查表

| 用途 | 写法 |
| ---- | ---- |
| 批量读入 | `for (int i = 0; i < n; i++) cin >> a[i];` |
| 单个元素搬家 | `a[2] = a[1];` |
| 交换两元素 | `t = a[0]; a[0] = a[4]; a[4] = t;` |
| 左移一位 | `for (int i = 0; i < n-1; i++) a[i] = a[i+1];` |
| 右移一位 | `for (int i = n-2; i >= 0; i--) a[i+1] = a[i];` |
| 备份首元素 | `int first = a[0];` |
| 补回末尾 | `a[n-1] = first;` |
| 全局大数组 | 把 `int a[100005];` 写在 `main` 外 |

### 易错点提醒

1. **主函数内开超大数组**：栈空间不足会崩溃，大数组放主函数外
2. **忘记初始化**：主函数内数组元素值不定，直接遍历输出是垃圾值
3. **赋值当搬运**：`a[2] = a[1];` 后 `a[1]` 依然存在
4. **交换不备份**：两个元素会变成同一个值
5. **右移用正序**：`a[i+1]` 先被覆盖，后面的值全错
6. **左移用逆序**：同样会覆盖未搬走的数据
7. **`i` 范围写宽**：左移 `i <= n-1` 会读 `a[n]`，越界
8. **挤出元素没备份**：平移后首（尾）元素丢失

> **本节小结**：先批量存、再按位移，移动的关键是方向与边界——从前往后还是从后往前，决定了会不会覆盖还没用到的数据。
