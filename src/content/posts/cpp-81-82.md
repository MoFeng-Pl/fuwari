## 1. 素数的定义

### 核心概念

**素数**（prime number，也叫质数）是**大于 1 的正整数**中，**只有 1 和它本身两个因数**的数；不满足这个条件的正整数据叫**合数**（composite number）。

- 3 只有 1 和 3 两个因数，是素数
- 6 有 1、2、3、6 四个因数，是合数
- **1 既不是素数也不是合数**，因为它只有 1 个因数

### 先分清因数与倍数

整除关系里有两个名字：设 `被除数 ÷ 除数 = 商 …… 余数`，当**余数为 0** 时，**被除数是除数的倍数**，**除数是 被除数的因数**（也叫约数）。

**找因数的方法**：一个整数，除以从 1 到它本身的每一个整数，能整除的除数就是它的因数；一个数的因数**最小是 1，最大是它自身**。

| 数 | 因数 | 因数个数 | 结论 |
| -- | ---- | -------- | ---- |
| 1 | 1 | 1 | 既不是素数也不是合数 |
| 3 | 1, 3 | 2 | 素数 |
| 6 | 1, 2, 3, 6 | 4 | 合数 |
| 9 | 1, 3, 9 | 3 | 合数 |

### 代码示例：输出一个数的所有因数

```cpp
#include <iostream>
using namespace std;

int main()
{
    int n = 12;
    for (int i = 1; i <= n; i++)
    {
        if (n % i == 0)          // 能被整除，i 就是因数
        {
            cout << i << " ";    // 1 2 3 4 6 12
        }
    }
    return 0;
}
```

### 易错点

1. **把 1 当成素数** —— 1 只有一个因数，既不是素数也不是合数
2. **把 2 漏掉** —— 2 是最小的素数，也是唯一的偶素数
3. **判断条件写成 `n != 0`** —— 素数要求**大于 1**，0 和负数都不算
4. **`n % i` 写成 `i % n`** —— 判断的是"n 能不能被 i 整除"，被除数必须是 n

> **本节小结**：素数就是"大于 1 且只有 1 和它本身两个因数"的数，合数反之，1 两者都不算；找因数就是用 1 到它本身逐个去试除。

## 2. 判断素数的算法

### 核心概念

素数的定义本身就是算法：**数一数因数有几个，恰好 2 个就是素数**。

- 准备一个计数器 `cnt`，初始为 0
- 让 `i` 从 1 走到 `n`，每次用 `n % i` 检查能否整除
- 能整除就让 `cnt` 加 1，循环结束后看 `cnt` 是否等于 2

### 代码示例

```cpp
#include <iostream>
using namespace std;

int main()
{
    int n;
    cin >> n;
    int cnt = 0;                     // 因数个数
    for (int i = 1; i <= n; i++)
    {
        if (n % i == 0) cnt++;       // 找到一个因数
    }
    if (cnt == 2) cout << "是素数";
    else cout << "不是素数";
    return 0;
}
```

### 易错点

1. **`cnt` 忘记清零或初始化** —— 局部变量不初始化就是垃圾值
2. **循环从 0 开始** —— `n % 0` 会直接让程序崩溃，除数必须从 1 开始
3. **判断写成 `cnt = 2`** —— 这是赋值，条件里必须是 `==`
4. **`cnt > 2` 与 `cnt == 2` 混用** —— 素数要求"恰好两个"，两者在 `n = 1` 时结果不同
5. **循环边界写成 `i < n`** —— 漏掉了 n 自身这个因数，素数会被全部判错

> **本节小结**：判断素数最直接的算法是"统计因数个数"，用 `cnt` 数出 1 到 n 之间能整除 n 的个数，等于 2 就是素数。

## 3. 用 `sqrt` 优化

### 核心概念

试除到 `n` 太慢。观察因数：它们总是**成对出现**的——若 `d` 是 `n` 的因数，那么 `n / d` 也是，两个因数中**必有一个不超过 `sqrt(n)`**（平方根，square root）。

所以只需让 `i` 试除到 `sqrt(n)`：只要在这个范围内找不到因数，`n` 就是素数。

- 优点：循环次数从 `n` 次降到约 `sqrt(n)` 次，`n` 很大时快得多
- 两种写法：`i <= sqrt(n)`（需要 `#include <cmath>`）或 `i * i <= n`（纯整数，推荐）

### 代码示例

```cpp
#include <iostream>
using namespace std;

int main()
{
    int n;
    cin >> n;
    bool flag = true;                // 先假设是素数
    for (int i = 2; i * i <= n; i++) // 只试除到 sqrt(n)
    {
        if (n % i == 0)
        {
            flag = false;            // 找到因数，不是素数
            break;                   // 一个就够，不必再找
        }
    }
    if (n < 2) flag = false;         // 0、1 和负数都不是素数
    if (flag) cout << "是素数";
    else cout << "不是素数";
    return 0;
}
```

### 易错点

1. **从 1 开始试除** —— 1 能整除任何数，必须在循环前就从 2 开始
2. **漏掉 `n < 2` 的特判** —— 0、1 会因为没有因数被误判成素数
3. **写 `i <= sqrt(n)` 却忘了 `#include <cmath>`** —— 编译时报"未声明"
4. **`i * i <= n` 写成 `i * i < n`** —— 平方数（如 9、25）会被误判为素数
5. **找到因数后不 `break`** —— 结果不错，但白白多跑很多轮

> **本节小结**：因数成对出现，所以只需试除到 `sqrt(n)`；用 `i * i <= n` 的整数写法最稳，配合一个布尔标记和 `break` 就能快速判定素数。

## 4. 统计区间内的素数

### 核心概念

统计 `[L, R]` 区间内有多少个素数（或把它们都输出），最清晰的做法是**把判断封装成函数**，再在主函数里循环调用：

- 写一个 `bool isPrime(int n)`，是素数返回 `true`，否则返回 `false`
- 主函数里 `for` 枚举 `L` 到 `R`，是素数就计数并输出
- 布尔函数里**发现因数就可以直接 `return false;`**，不用标记变量

### `break` 与 `return 0` 的区别

| 写法 | 作用范围 | 后续语句 |
| ---- | -------- | -------- |
| `break` | 只结束**当前这一层循环** | 循环之后的语句**继续执行** |
| `return 0`（在主函数里） | 直接结束**整个主函数** | 后面的语句**都不再执行** |

```cpp
for (int i = 1; i <= 10; i++)
{
    cout << i << " ";
    if (i == 5) break;      // 换成 return 0，则 "over" 不会输出
}
cout << "over";
```

`break` 输出 `1 2 3 4 5 over`；`return 0` 只输出 `1 2 3 4 5`。

### 代码示例

```cpp
#include <iostream>
using namespace std;

bool isPrime(int n)                  // 是素数返回 true
{
    if (n < 2) return false;
    for (int i = 2; i * i <= n; i++)
    {
        if (n % i == 0) return false; // 有因数立刻结束函数
    }
    return true;
}

int main()
{
    int l, r, cnt = 0;
    cin >> l >> r;
    for (int i = l; i <= r; i++)
    {
        if (isPrime(i))
        {
            cout << i << " ";
            cnt++;
        }
    }
    cout << endl << "共 " << cnt << " 个";
    return 0;
}
```

### 易错点

1. **在 `isPrime` 里用 `return 0` / `return 1`** —— 布尔函数应返回 `true` / `false`
2. **`return true` 写在循环里面** —— 第一次没找到因数就返回，会把合数判成素数
3. **区间循环条件写成 `i < r`** —— 漏掉了右端点 R
4. **在主函数里用 `return 0` 提前结束** —— 后面的统计和输出都不会执行
5. **忘了初始化 `cnt`** —— 计数从 0 开始

> **本节小结**：统计素数就是"循环枚举 + 函数判断 + 计数器累加"；判断写成 `bool isPrime(int n)` 复用最方便，同时要分清 `break` 只跳出循环、`return` 直接结束函数。

## 知识框架梳理

### 核心概念总结

- **因数与倍数**：`n % i == 0` 时，i 是 n 的因数，n 是 i 的倍数
- **素数**：大于 1 且只有 1 和它本身两个因数；合数反之；1 两者都不是
- **暴力判断**：统计 1 到 n 的因数个数，等于 2 即素数
- **优化判断**：因数成对出现，只需试除到 `sqrt(n)`，用 `i * i <= n`
- **布尔标记**：先假设是素数，找到因数再改标记并 `break`
- **统计区间**：封装 `bool isPrime(int n)`，主函数循环调用并计数
- **`break` 与 `return`**：`break` 只跳出当前循环，`return` 直接结束函数

### 语法速查表

| 用途 | 写法 |
| ---- | ---- |
| 判断整除 | `n % i == 0` |
| 枚举因数 | `for (int i = 1; i <= n; i++)` |
| 统计因数个数 | `if (n % i == 0) cnt++;` |
| 判断素数 | `if (cnt == 2)` |
| 试除到平方根 | `for (int i = 2; i * i <= n; i++)` |
| 平方根写法 | `i <= sqrt(n)`（需 `<cmath>`） |
| 布尔标记 | `bool flag = true;` |
| 提前跳出循环 | `break;` |
| 素数函数 | `bool isPrime(int n) { ... }` |

### 易错点提醒

1. 1 既不是素数也不是合数，判断时先排除 `n < 2`
2. 试除必须从 2 开始，`n % 0` 会崩、`n % 1` 恒为 0
3. 循环边界是 `i * i <= n`，不是 `<`
4. 条件判断用 `==`，别写成赋值 `=`
5. `cnt` 要初始化为 0，且注意它是局部变量
6. 布尔函数里 `return true` 不能写在循环内部
7. 想在循环里"提前收工"用 `break`，想"整个程序收工"才用 `return 0`
8. 统计区间时左闭右闭，条件写 `i <= r`
9. 平方根优化只改变试除次数，不改变"素数只有 1 和自身两个因数"的本质

> **本节小结**：判断素数只需试到 √n，统计素数则是在判断外面再套一层循环与计数器。
