## 1. `<algorithm>` 头文件

### 核心概念

`sort` 是 C++ 标准库提供的**排序函数**，它不属于语言关键字，而是放在**算法库头文件** `<algorithm>`（algorithm，算法）里。要用它，代码开头必须先引入头文件。

两种引入方式：

| 写法 | 说明 |
| ---- | ---- |
| `#include <algorithm>` | 只引入算法库，规范、推荐 |
| `#include <bits/stdc++.h>` | 万能头文件，一次引入几乎所有标准库，方便但编译稍慢 |

`sort` 的效率很高（内部是优化过的快排），比手写冒泡、选择排序快得多，写题时**优先直接用**。

### 语法格式

```cpp
#include <algorithm>       // 放在最上方，与 <iostream> 并列

int main()
{
    // 之后才能调用 sort
}
```

### 易错点

1. **漏写 `#include <algorithm>`** —— 编译报错 `sort was not declared`
2. **写成 `<algorithms>`** —— 头文件名没有复数 s
3. **以为 `sort` 是关键字** —— 它是标准库函数，必须引头文件
4. **头文件写在 `main` 里面** —— `#include` 必须写在文件最上方

> **本节小结**：`sort` 来自 `<algorithm>`，用前先 `#include`（或引万能头 `<bits/stdc++.h>`），它是标准库现成的高效排序，不用自己手写。

## 2. `sort` 基本用法

### 核心概念

调用格式是 `sort(开始地址, 结束地址 + 1)`，默认按**从小到大**排序。

理解它要先理解**数组地址**：

- **开始地址**就是**数组名**本身，如 `a`
- **任意元素的地址**是**数组名 + 元素下标**，如 `a+0`、`a+1`、`a+2`……

所以长度 5 的数组 `a`，首元素地址是 `a+0`，末元素地址是 `a+4`，而 `sort` 的第二个参数要写**结束地址再加 1**，即 `a+5`。

### 代码示例

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

int main()
{
    int a[5] = {182, 179, 176, 180, 170};

    sort(a, a + 5);        // 从 a+0 排到 a+4（第二个参数是结束地址 +1）

    for (int i = 0; i < 5; i++) cout << a[i] << " ";
    // 输出 170 176 179 180 182
    return 0;
}
```

### 易错点

1. **第二个参数写 `a + 4`** —— 最后一个元素排不进去，漏掉最大值
2. **第二个参数写 `a + 6`** —— 越界访问，属于未定义行为
3. **以为 `sort` 返回值是数组** —— `sort` 直接原地修改，没有返回值
4. **对 `sort` 的结果再赋值** —— `a = sort(a, a+5);` 是错的，直接调用即可

> **本节小结**：`sort(开始地址, 结束地址 + 1)`，开始地址是数组名、结束地址是末元素地址，加 1 是因为区间**左闭右开**；默认从小到大排序，且直接改原数组。

## 3. 指定排序区间

### 核心概念

`sort` 的区间是**左闭右开**的：包含开始地址指向的元素，**不包含**第二个参数指向的元素。

因此：

- 排整个数组：`sort(a, a + n)`
- 只排下标 `[l, r]`：`sort(a + l, a + r + 1)`
- 只排前 k 个：`sort(a, a + k)`

### 代码示例

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

int main()
{
    int a[6] = {5, 3, 9, 1, 7, 2};

    sort(a + 1, a + 4);    // 只排 a[1] ~ a[3]，其余不动

    for (int i = 0; i < 6; i++) cout << a[i] << " ";
    // 输出 5 1 3 9 7 2
    return 0;
}
```

原数组 `5 3 9 1 7 2` 中，`a[1] a[2] a[3]` 是 `3 9 1`，排好变成 `1 3 9`，其他位置不变。

### 易错点

1. **想排 `a[l] ~ a[r]` 却写 `sort(a + l, a + r)`** —— 右端点被排除，少排一个
2. **写成 `sort(a + l, a + r - 1)`** —— 右端点排不到，越减越少
3. **区间跨越数组边界** —— `a + r + 1` 超过 `a + n` 就是越界
4. **下标与地址混淆** —— `a + l` 是地址，不是"第 l 个元素的值"

> **本节小结**：区间是左闭右开，排 `a[l] ~ a[r]` 要写 `sort(a + l, a + r + 1)`，第二个参数永远是"最后一个要排的元素地址再加 1"。

## 4. 降序与自定义比较

### 核心概念

想按别的规则排序，就给 `sort` 传**第三个参数——比较函数**（comparator）：

```cpp
sort(开始地址, 结束地址 + 1, cmp);
```

`cmp` 是一个返回 `bool` 的函数，含义是：**当 `a` 应该排在 `b` 前面时返回 `true`**。

- 写成 `return a > b;` → 大的在前，即**从大到小**
- 写成 `return a < b;` → 小的在前，与默认的从小到大相同

也可以直接用标准库现成的 `greater<int>()` 表示降序。

### 代码示例

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

bool cmp(int x, int y)     // 返回 true 表示 x 应排在 y 前面
{
    return x > y;          // 大的在前 → 降序
}

int main()
{
    int a[5] = {3, 1, 4, 5, 2};

    sort(a, a + 5, cmp);                       // 自定义比较：降序

    for (int i = 0; i < 5; i++) cout << a[i] << " ";
    // 输出 5 4 3 2 1
    return 0;
}
```

等价的简写：`sort(a, a + 5, greater<int>());`。

### 易错点

1. **`cmp` 里写 `>=`** —— 相等时也返回 `true`，会破坏排序所需的严格顺序，可能运行错误
2. **`cmp` 返回类型写成 `int`** —— 应写 `bool`
3. **`cmp` 参数类型与数组元素类型不一致** —— 数组是 `int` 就写 `int`，是 `double` 就写 `double`
4. **把 `cmp` 写成 `cmp()`** —— 传函数名，不要加括号调用
5. **`cmp` 里交换了参数含义** —— 参数顺序是"前一个、后一个"，写反会得到相反的顺序
6. **比较函数写在 `main` 里面** —— 和普通函数一样，要定义在所有函数外面

> **本节小结**：第三个参数是"比较函数"，返回 `true` 表示前者应排在前面；`return a > b;` 得到降序，`return a < b;` 得到升序，也可以用 `greater<int>()` 简写。

## 知识框架梳理

### 核心概念总结

- **头文件**：`sort` 来自 `<algorithm>`，或用万能头 `<bits/stdc++.h>`
- **基本格式**：`sort(开始地址, 结束地址 + 1)`，默认从小到大
- **数组地址**：数组名是首地址，`a + i` 是第 i 个元素的地址
- **左闭右开**：区间包含起始元素，不包含第二个参数指向的元素
- **整段排序**：`sort(a, a + n)`；部分排序：`sort(a + l, a + r + 1)`
- **降序**：`sort(a, a + n, cmp)`，`cmp` 返回 `a > b`
- **`greater<int>()`**：标准库现成的降序比较器

### 语法速查表

| 用途 | 写法 |
| ---- | ---- |
| 引入算法库 | `#include <algorithm>` |
| 万能头文件 | `#include <bits/stdc++.h>` |
| 升序排整个数组 | `sort(a, a + n);` |
| 排 `a[l] ~ a[r]` | `sort(a + l, a + r + 1);` |
| 降序（自定义） | `sort(a, a + n, cmp);` |
| 降序（简写） | `sort(a, a + n, greater<int>());` |
| 比较函数 | `bool cmp(int x, int y) { return x > y; }` |
| 取首元素地址 | `a` 或 `a + 0` |
| 取末元素地址 | `a + n - 1` |

### 易错点提醒

1. 漏引 `<algorithm>`，编译器不认识 `sort`
2. 第二个参数不是"末元素地址"，而是"末元素地址 + 1"
3. 排 `a[l] ~ a[r]` 时右端点也要 +1，否则少排一个
4. 第二个参数超过 `a + n` 会越界
5. `sort` 原地修改数组，不要写成 `a = sort(...)`
6. 比较函数必须返回 `bool`，不能返回 `int`
7. 比较函数里用 `>` 而不是 `>=`，相等时返回 `true` 会出问题
8. 传比较函数时写函数名，不带括号
9. 比较函数定义在 `main` 外面
10. `greater<int>()` 后面的括号不能漏

> **本节小结**：sort(begin, end) 默认升序且左闭右开，要降序就传 greater<int>() 或自定义比较函数。
