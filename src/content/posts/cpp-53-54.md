## 1. 什么是遍历

**遍历**（traversal）是指把数组中的元素**全部、一个不落地查看一遍**。

### 核心概念

- 数组一次存了很多数据，但同一时刻我们只能用一个下标取出一个元素
- 想把每个元素都处理一次，就必须让下标从第一个走到最后一个
- 这个"按下标逐个走过所有元素"的过程，就是遍历

```cpp
int a[3] = {5, 8, 2};
// 遍历就是依次访问 a[0]、a[1]、a[2]，一个都不漏
```

### 为什么必须用循环

手写三行 `cout` 只能应付长度 3 的数组；长度变成 1000，就必须靠循环让下标自动递增。**遍历 = 循环 + 下标**。

> **本节小结**：遍历是"按下标把数组元素全部走一遍"，它是数组所有批量操作（输出、求和、找最值）的共同骨架。

## 2. for 遍历数组

### 两种等价写法

```cpp
for (int i = 0; i < 数组长度; i++) { ... }    // 比长度小
for (int i = 0; i <= 最大下标; i++) { ... }    // 比最大下标大
```

因为最大下标 = 长度 - 1，所以 `i < 长度` 与 `i <= 最大下标` 完全等价。

```cpp
int a[5] = {10, 20, 30, 40, 50};

for (int i = 0; i < 5; i++)      // 用长度
{
    cout << a[i] << " ";
}

for (int i = 0; i <= 4; i++)     // 用最大下标
{
    cout << a[i] << " ";
}
// 两种写法都输出：10 20 30 40 50
```

### 易错点

1. 写成 `i <= 5` 会访问 `a[5]`，**越界**
2. 循环变量 `i` 从 1 开始，会漏掉 `a[0]`
3. 循环体内用了别的下标，如 `a[i-1]`，要另算边界

> **本节小结**：遍历的循环头只有两种正确形态——`i < 长度` 或 `i <= 最大下标`，两者等价，其余写法都在边界上冒险。

## 3. 遍历中求和与计数

遍历的真正价值在于：**在走过每个元素时顺手做统计**。

### 求和

先准备一个累加器（accumulator）`sum = 0`，遍历时把每个元素加进去：

```cpp
int a[5] = {10, 20, 30, 40, 50};
int sum = 0;

for (int i = 0; i < 5; i++)
{
    sum = sum + a[i];      // 等价于 sum += a[i];
}

cout << sum;               // 150
```

### 计数

先准备一个计数器（counter）`cnt = 0`，满足条件就加 1：

```cpp
int a[5] = {10, 25, 30, 47, 50};
int cnt = 0;

for (int i = 0; i < 5; i++)
{
    if (a[i] % 2 == 1)     // 统计奇数的个数
    {
        cnt++;
    }
}

cout << cnt;               // 2
```

### 易错点

累加器必须初始化为 0。`int sum;` 不赋值，`sum` 里是随机值，加出来的结果全错。

> **本节小结**：求和的套路是"清零累加器 → 遍历累加"，计数的套路是"清零计数器 → 遍历判断再加一"，两者只是循环体里那一句不同。

## 4. 逆序遍历

把循环变量**从最大下标开始递减到 0**，就能倒着访问数组。

### 语法格式

```cpp
for (int i = 最大下标; i >= 0; i--)
{
    cout << a[i] << " ";
}
```

```cpp
int a[5] = {1, 2, 3, 4, 5};

for (int i = 4; i >= 0; i--)
{
    cout << a[i] << " ";     // 输出：5 4 3 2 1
}
```

### 三处关键改动

| 位置 | 正序 | 逆序 |
| ---- | ---- | ---- |
| 初值 | `i = 0` | `i = 最大下标` |
| 条件 | `i < 长度` | `i >= 0` |
| 步进 | `i++` | `i--` |

### 易错点

条件写成 `i > 0` 会漏掉下标 0；写成 `i >= 0` 且 `i` 是无符号类型时还会死循环，所以循环变量用 `int`。

> **本节小结**：逆序遍历只是把"起点、条件、步进"三件套反过来写，条件必须是 `i >= 0`，否则第一个元素读不到。

## 5. 遍历的应用

### 循环输入与循环输出

遍历既能"往数组里灌数据"，也能"从数组里读数据"：

```cpp
int a[10];

for (int i = 0; i < 10; i++) { cin >> a[i]; }    // 批量输入
for (int i = 0; i < 10; i++) { cout << a[i] << " "; }  // 批量输出
```

### 求最大值

```cpp
int a[5] = {3, 9, 2, 7, 5};
int maxV = a[0];                 // 先假设第一个最大

for (int i = 1; i < 5; i++)      // 从第二个开始比
{
    if (a[i] > maxV) { maxV = a[i]; }
}
cout << maxV;                    // 9
```

### 数组的存储限制

同样的遍历代码，数组定义位置不同，结果可能不同：

- **主函数内，小数组，值不定**：未初始化的元素是随机值，遍历输出会得到垃圾数据
- **主函数外，大数组，都是 0**：全局数组自动清零，可以直接使用
- **建议**：长度 10 万以上的数组放在主函数外，避免栈空间不足

### 越界预防

定义时把长度比实际需要**多开 5 个**，遍历的上界仍按真实个数控制，就不会因为多输入几个数据而踩到界外。

> **本节小结**：遍历是输入、输出、求和、计数、找最值的通用外壳；数组放主函数外会自动清零且容量更大，大数组尤其要这样做。

## 知识框架梳理

### 核心概念总结

- **遍历**：按下标把数组元素全部访问一遍，实现方式是"循环 + 下标"
- **循环头**：`i < 长度` 或 `i <= 最大下标`，两种写法等价
- **求和**：累加器清零后遍历累加
- **计数**：计数器清零后遍历判断再自增
- **逆序**：初值为最大下标，条件 `i >= 0`，步进 `i--`
- **应用**：批量输入输出、求最值、统计；主函数外的全局数组自动为 0

### 语法速查表

| 用途 | 写法 |
| ---- | ---- |
| 正序遍历 | `for (int i = 0; i < n; i++)` |
| 按下标上界遍历 | `for (int i = 0; i <= n-1; i++)` |
| 逆序遍历 | `for (int i = n-1; i >= 0; i--)` |
| 遍历求和 | `sum += a[i];` |
| 遍历计数 | `if (条件) cnt++;` |
| 遍历输入 | `cin >> a[i];` |
| 遍历输出 | `cout << a[i] << " ";` |
| 求最大值 | `if (a[i] > maxV) maxV = a[i];` |

### 易错点提醒

1. **上界写成 `i <= n`**：直接越界，应为 `i < n`
2. **初值写成 1**：漏掉 `a[0]`
3. **逆序条件写 `i > 0`**：漏掉下标 0
4. **累加器没清零**：`int sum;` 未初始化，结果随机
5. **求最大值从 `i = 0` 开始比**：`maxV` 初值取 `a[0]`，从 `i = 1` 开始更清晰
6. **主函数内大数组**：容易爆栈，10 万以上放主函数外
7. **主函数内未初始化就遍历**：元素值不定，输出无意义

> **本节小结**：遍历就是用循环把下标从 0 走到 n-1，求和、计数、逆序都只是在循环体里换一句话。
