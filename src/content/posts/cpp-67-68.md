## 1. 二维数组的定义

### 核心概念

**二维数组**（two-dimensional array）是**把一维数组作为元素的数组**，通常用来存储具有**行、列结构**的数据，比如成绩表、矩阵、棋盘。

- **行数**：二维数组内一维数组的**个数**
- **列数**：二维数组内一维数组的**长度**——`int a[3][4]` 就是「3 个一维数组，每个长 4」

### 语法格式

```cpp
类型 数组名[行数][列数];
```

行数、列数都可以是整型常量（`10`）、字符常量（`'a'`，按 ASCII 码值为 97）、常量表达式（`1+5`，即 6）。

```cpp
int a[3][4];        // 3 行 4 列，共 12 个元素
char grid[2][3];    // 2 行 3 列的字符表
int b['a'][1 + 5];  // 等价于 b[97][6]
```

命名规则和一维数组一样：由字母、数字、下划线组成，不能以数字开头，不能是 C++ 关键字，严格区分大小写。

另外，在**主函数外**定义可以定义更大的二维数组，元素**默认都是 0**；在**主函数内**定义又不初始化时，元素的值**不确定**，用之前必须赋值。

### 易错点

1. 把 `int a[3][4]` 说成「3 列 4 行」—— 方括号顺序是**先行后列**
2. 行列数写成变量 —— 静态数组的行列数必须是编译时确定的常量
3. 写成 `int a[3,4]` —— 逗号不是二维写法，必须写两个方括号

> **本节小结**：二维数组是「元素为一维数组」的数组，语法为 `类型 数组名[行数][列数];`，行数是内层一维数组的个数、列数是它的长度。

## 2. 二维数组的初始化

### 核心概念

初始化用**嵌套的大括号**：外层大括号代表整个数组，每个内层大括号代表一行。

```cpp
int a[2][3] = {{1, 2, 3}, {3, 4, 5}};   // 完全初始化
```

```
1 2 3
3 4 5
```

### 部分初始化与特殊初始化

**部分初始化**：只给一部分元素赋值，主函数里定义时**其余元素自动为 0**。

```cpp
int a[2][3] = {{1, 2, 3}};          // 第 2 行全为 0
int a[2][3] = {{1, 2, 3}, {3}};     // 第 2 行后两个为 0
int a[2][3] = {{1, 2}, {3, 4, 5}};  // 第 1 行第 3 个为 0
```

**特殊初始化**：一次把全部元素清零。

```cpp
int a[2][3] = {0, 0};   // 所有元素都为 0
int a[2][3] = {};       // 所有元素都为 0（推荐）
```

### 省略行列数

```cpp
int a[ ][3] = {1, 2, 3, 4, 5, 6, 7, 8, 9};   // 不写行数：不报错
int a[3][ ] = {1, 2, 3, 4, 5, 6, 7, 8, 9};   // 不写列数：报错
```

- 省略行数时，编译器按「总个数 ÷ 列数」自动推算（9 ÷ 3 = 3 行）
- 省略列数时编译器无法切分每一行，直接编译错误
- 口诀：**行可选，列必填，建议行列都写全**

| 方式 | 写法 | 结果 |
| ---- | ---- | ---- |
| 完全初始化 | `{{1,2,3},{3,4,5}}` | 每个元素都有指定值 |
| 部分初始化 | `{{1,2,3},{3}}` | 未指定的元素补 0 |
| 特殊初始化 | `{}` 或 `{0,0}` | 全部为 0 |

### 易错点

1. 只写一层大括号 `{1,2,3,4,5,6}` —— 合法但按顺序平铺，看不出行列
2. 内层大括号里给的数超过列数 —— 编译报错
3. 在主函数内定义又不初始化 —— 元素是随机值，不是 0

> **本节小结**：初始化用嵌套大括号按行赋值，少给的元素自动补 0；行数可以省略由编译器推算，列数必须写。

## 3. 下标访问

### 核心概念

二维数组用**两个下标**定位元素：`数组名[i][j]`，`i` 是**行下标**，取值 `0 ～ 行数 - 1`；`j` 是**列下标**，取值 `0 ～ 列数 - 1`。两者都**从 0 开始**。

`int a[2][3]` 的合法组合是 `a[0][0]` 到 `a[1][2]`，一共 6 个元素。

### 读取、修改与输入

```cpp
int a[2][3] = {{1, 2, 3}, {4, 5, 6}};
cout << a[0][2];    // 3：第 1 行第 3 列
cout << a[1][1];    // 5：第 2 行第 2 列

b[0][2] = 81;       // 修改：数组名[行下标][列下标] = 数值;
cin >> b[0][2];     // 输入：cin >> 数组名[行下标][列下标];
```

### 易错点

1. 以为 `a[1][2]` 是第 1 行第 2 列 —— 下标从 0 起，它其实是第 2 行第 3 列
2. 行下标写到 `a[行数][...]` —— 越界，最大只能到「行数 - 1」
3. 写成 `a[0,2]` —— 逗号表达式只取最后一个值，不是二维访问
4. 想整体读写 —— 数组不能整体赋值，只能逐个元素处理

> **本节小结**：`数组名[i][j]` 用先行后列两个下标定位元素，两下标都从 0 开始，最大分别是「行数 - 1」和「列数 - 1」。

## 4. 双重循环遍历

### 核心概念

二维数组的元素按行列排布，正好对应双重循环：**外层循环走行，内层循环走列**，逐个访问 `a[i][j]`。这就是**遍历**（traversal）。

```cpp
for (int i = 0; i < 行数; i++)          // 外层：行
{
    for (int j = 0; j < 列数; j++)      // 内层：列
    {
        处理 数组名[i][j];
    }
}
```

- 循环变量从 **0** 开始，条件是 `< 行数`、`< 列数`，**不是 `<=`**
- 遍历顺序是**行优先**：先把一行从左到右走完，再走下一行

### 循环输入与输出

```cpp
for (int i = 0; i < 2; i++)
    for (int j = 0; j < 3; j++)
        cin >> a[i][j];               // 依次读入 6 个数

for (int i = 0; i < 2; i++)
{
    for (int j = 0; j < 3; j++)
        cout << a[i][j] << " ";       // 同一行的元素用空格隔开
    cout << endl;                     // 一行结束再换行
}
```

`endl` 必须写在内层循环**外面**，输出才是一行一行；写进内层就成了一列。

### 遍历求和

把 `sum += a[i][j];` 放进内层循环，遍历结束后 `sum` 就是全部元素之和。

### 易错点

1. 条件写成 `i <= 2` —— 越界访问，多跑一行
2. 换行写进内层 —— 输出变成一列而不是一张表
3. 内层也用变量 `i` —— 行下标被破坏，输出错乱
4. 行列数写死成 3 和 4 却与实际定义不符 —— 遍历范围出错

> **本节小结**：双重循环遍历二维数组，外层 `i` 走行、内层 `j` 走列，下标从 0 到「长度 - 1」，换行放在内层之外就能还原成表格。

## 5. 二维数组的应用

### 核心概念

只要数据天然带有「行、列」两维结构，就可以用二维数组来存。常见三类场景：**表格数据**、**矩阵运算**、**棋盘地图**。

### 表格：按行求和

```cpp
int score[3][2] = {{90, 85}, {78, 92}, {88, 76}};   // 3 名学生、2 门科目
for (int i = 0; i < 3; i++)
{
    int sum = 0;
    for (int j = 0; j < 2; j++)
        sum += score[i][j];
    cout << "第" << i + 1 << "名学生的总分：" << sum << endl;
}
```

外层 `i` 是学生编号，内层 `j` 是科目编号，按行求和就得到每个人的总分。

### 矩阵：转置

把第 `i` 行第 `j` 列的元素放到第 `j` 行第 `i` 列：

```cpp
int a[2][3] = {{1, 2, 3}, {4, 5, 6}};
int b[3][2];
for (int i = 0; i < 2; i++)
    for (int j = 0; j < 3; j++)
        b[j][i] = a[i][j];      // 行列下标互换
```

`b` 的行列数正好与 `a` 相反：`a` 是 2 行 3 列，`b` 就是 3 行 2 列。

### 棋盘：字符二维数组

字符二维数组适合表示井字棋、迷宫地图、扫雷面板这类「格子」结构，例如 `char board[3][3]` 表示 3×3 的棋盘，用 `board[1][1] = 'X';` 就能在正中间落一子。

### 易错点

1. 转置时忘了新数组的行列数要互换 —— 越界
2. 用 `char` 数组存字符却忘了元素要加单引号
3. 行列含义搞反（把学生当列、科目当行）—— 统计结果全错

> **本节小结**：二维数组用来存行列结构的数据，按行求和做统计、行列互换做转置、字符二维数组做棋盘，用之前先想清楚「谁是行、谁是列」。

## 知识框架梳理

### 核心概念总结

- **二维数组**：把一维数组作为元素的数组，存储行列结构的数据
- **定义语法**：`类型 数组名[行数][列数];`，行数是内层一维数组的个数、列数是它的长度
- **初始化**：嵌套大括号按行赋值，少给的元素补 0；行数可省、列数必填
- **下标访问**：`数组名[i][j]`，先行后列，两个下标都从 0 开始
- **双重循环遍历**：外层走行、内层走列，行优先

### 语法速查表

| 用途 | 写法 |
| ---- | ---- |
| 定义二维数组 | `int a[3][4];` |
| 完全初始化 | `int a[2][3] = {{1,2,3},{4,5,6}};` |
| 全部清零 | `int a[2][3] = {};` |
| 省略行数 | `int a[][3] = {1,2,3,4,5,6};` |
| 访问元素 | `cout << a[i][j];` |
| 修改元素 | `b[0][2] = 81;` |
| 输入元素 | `cin >> b[0][2];` |
| 循环输入 | `for(i) for(j) cin >> a[i][j];` |
| 循环输出 | `for(i){ for(j) cout<<a[i][j]<<" "; cout<<endl; }` |

### 易错点提醒

1. **行列顺序**：`a[行][列]`，先说行再说列，别写反
2. **下标从 0 起**：行下标最大是「行数 - 1」，写 `a[行数][...]` 就越界
3. **列数必填**：`int a[3][];` 编译报错，只有行数可以省略
4. **不初始化就是随机值**：主函数内定义的二维数组必须赋值后再用
5. **换行位置**：输出表格时 `endl` 要写在内层循环之外

> **本节小结**：二维数组是「数组的数组」，a[i][j] 先定行再定列，双重循环遍历时 i 管行、j 管列最自然。
