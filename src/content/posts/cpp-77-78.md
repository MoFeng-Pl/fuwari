## 1. 其余常用成员函数

除了拼接、查找、截取、增删改，`string` 还有一组「查状态、取首尾、尾部增删」的函数。

### 判空与清空

| 函数 | 作用 | 说明 |
| ---- | ---- | ---- |
| `s.empty()` | 判断是否为空串 | 为空返回 `true`，否则 `false` |
| `s.clear()` | 清空全部字符 | 执行后 `s.size()` 变为 0 |

- `s.empty()` 等价于 `s.size() == 0`，但语义更直接
- `clear()` 只清内容，不销毁变量，之后仍可继续赋值使用

### 取首尾字符

| 函数 | 作用 | 等价写法 |
| ---- | ---- | -------- |
| `s.front()` | 取第一个字符 | `s[0]` |
| `s.back()` | 取最后一个字符 | `s[s.size() - 1]` |

```cpp
string s = "hello";
cout << s.front();    // h
cout << s.back();     // o
```

- 对**空串**调用 `front()` / `back()` 是未定义行为，先判空

### 尾部增删

| 函数 | 作用 |
| ---- | ---- |
| `s.push_back('x')` | 在末尾追加一个字符 |
| `s.pop_back()` | 删除末尾一个字符 |

```cpp
string s;
for (int i = 1; i <= 5; i++) {
    s.push_back('0' + i);    // '0' + 1 得到字符 '1'
}
cout << s;                   // 12345
```

- 这两个函数只处理**单个字符**，追加字符串仍用 `+=` 或 `append`
- `push_back` 常用来「边读边攒」字符串，比如把数字逐位拼成字符

### 带检查的访问 `at()`

```cpp
string s = "hello";
cout << s.at(1);      // e
cout << s.at(99);     // 越界，抛出 out_of_range 异常
```

- `s[i]` **不做边界检查**，越界是未定义行为
- `s.at(i)` 会检查，越界时抛出异常，调试期更安全

### 易错点

1. **空串取 `front()` / `back()`**：先 `if (!s.empty())`
2. **`push_back("ab")`**：参数必须是单个字符
3. **`pop_back()` 用在空串上**：未定义行为

> **本节小结**：`empty` 判空、`clear` 清空、`front`/`back` 取首尾、`push_back`/`pop_back` 尾部增删、`at` 带检查访问——它们让 `string` 更像一个可以随手增删的容器。

## 2. string 与字符数组互转

有些函数只认字符数组，有些场景更适合 `string`，所以要会互相转换。

### 字符数组 → string：直接赋值

```cpp
char a[105] = "hello";
string s = a;          // 直接赋值即可
cout << s.size();      // 5
```

- `string` 能吃下 `char` 数组，赋值、初始化都行
- 转换时以 `\0` 为界，只保留有效字符

### string → 字符数组：`c_str()` + `strcpy`

```cpp
#include <cstring>

string s = "hello";
char a[105];
strcpy(a, s.c_str());     // 先转成 const char*，再复制
```

- `s.c_str()` 返回指向内部字符序列的 `const char*`，末尾自带 `\0`
- 不能写 `a = s;`，数组不能整体赋值
- 也不能通过 `c_str()` 修改内容，它是只读的

### 转换关系一览

| 方向 | 写法 | 注意事项 |
| ---- | ---- | -------- |
| 字符数组 → `string` | `string s = a;` | 以 `\0` 为界 |
| `string` → 字符数组 | `strcpy(a, s.c_str());` | 目标数组要够大 |
| 取只读指针 | `s.c_str()` | 类型为 `const char*` |

- 常见场景：用 `cin.getline(buf, 100)` 读入字符数组后，写 `string s = buf;` 就能继续用 `find`、`substr`

### 易错点

1. **`strcpy(a, s)` 直接传 string**：必须写 `s.c_str()`
2. **目标数组太小**：长度要按 `s.size() + 1` 准备

> **本节小结**：字符数组转 `string` 直接赋值；`string` 转字符数组要先 `c_str()` 再 `strcpy`，目标数组要留足 `size() + 1` 的空间。

## 3. 字符串综合应用

单个函数会用了，真正的难点是**把它们组合起来**解决一道完整题目。

### 应用一：统计单词个数

```cpp
string s;
getline(cin, s);          // 读入一整行，可能含多个空格

int cnt = 0;
bool inWord = false;
for (int i = 0; i < (int)s.size(); i++) {
    if (s[i] != ' ') {
        if (!inWord) { cnt++; inWord = true; }   // 进入新单词
    } else {
        inWord = false;                          // 遇到空格，单词结束
    }
}
cout << cnt;
```

- 关键是 `inWord` 标记：**只在「从空格进入字母」的那一刻**计数
- 这样连续多个空格也不会重复统计

### 应用二：字符串反转

```cpp
string s = "hello";

for (int i = 0, j = (int)s.size() - 1; i < j; i++, j--) {
    swap(s[i], s[j]);        // 首尾交换，原串上完成
}
```

也可以用「倒序拼一个新串」：`for (int i = s.size() - 1; i >= 0; i--) t += s[i];`，写法更好理解。

### 应用三：删除所有指定字符

`erase` 方案要处理下标回退（上一课已练过），这里推荐**只保留需要的字符**：

```cpp
string s = "a-b-c-d", t;
for (int i = 0; i < (int)s.size(); i++) {
    if (s[i] != '-') t += s[i];   // 只要不是 '-' 就留下
}
s = t;                            // abcd
```

- 重建新串的思路**不会漏字符**，也不用 `i--`
- 代价是多用一个 `string` 的存储空间

### 应用四：解析「键:值」格式

```cpp
string line = "name:Tom;age:18;";
int start = 0;
while (true) {
    int colon = line.find(':', start);
    int semi  = line.find(';', start);
    if (colon == string::npos || semi == string::npos) break;
    string key = line.substr(start, colon - start);        // name
    string val = line.substr(colon + 1, semi - colon - 1); // Tom
    cout << key << " = " << val << endl;
    start = semi + 1;                                      // 从下一段继续
}
```

`find` 负责定位分隔符、`substr` 负责切出内容，是解析字符串的标准套路。

> **本节小结**：综合题的核心是「`find` 定位 + `substr` 切分 + 循环遍历」；删除字符推荐重建新串，比 `erase` 回退下标更不容易出错。

## 4. 常见易错点

### 下标与长度

1. **下标从 0 开始，末尾是 `size() - 1`**：循环写 `i < s.size()`，绝不写 `<=`
2. **`substr(pos, len)` 的 `len` 是长度**，不是结束下标
3. **`erase` 后下标要回退**：`i--`，否则会漏删连续字符
4. **`pos` 超范围**：`substr`、`insert`、`replace`、`erase` 都要求 `pos <= s.size()`

### 输入输出

1. **`cin >> s` 读不到空格后的内容**：需要整行就用 `getline(cin, s)`
2. **`cin >>` 之后 `getline` 读到空串**：先用 `cin.ignore()` 吃掉换行

### 运算符与语义

| 错误写法 | 问题 | 正确写法 |
| -------- | ---- | -------- |
| `s = +"abc"` | 把 `+=` 写成 `=+` | `s += "abc";` |
| `if (s = "abc")` | 把 `==` 写成 `=` | `if (s == "abc")` |
| 以为 `s1 + s2` 改了 `s1` | `+` 返回新串 | `s1 = s1 + s2;` |
| `s.append(3, "x")` | 第二个参数应为字符 | `s.append(3, 'x')` |

### 字符串与字符数组混用

1. **`string` 不需要 `strlen`、`strcpy`、`strcmp`**，直接 `size()`、`=`、`==`
2. **`strcpy(a, s)` 编译不过**：要写 `s.c_str()`
3. **`char a[] = s;` 非法**：数组不能整体赋值

> **本节小结**：字符串的坑集中在三处——无符号长度、下标与长度的含义、`cin` 与 `getline` 的缓冲区；先判空、用 `npos` 判断查找结果、删除后调整下标，基本可以避开绝大多数错误。

## 知识框架梳理

### 核心概念总结

- **状态类函数**：`empty()` 判空、`clear()` 清空、`size()` 取长度
- **首尾操作**：`front()`/`back()` 取字符，`push_back()`/`pop_back()` 尾部增删
- **安全访问**：`at(i)` 带边界检查，越界抛异常
- **互转**：字符数组 → `string` 直接赋值；`string` → 字符数组用 `c_str()` + `strcpy`
- **综合套路**：`find` 定位 + `substr` 切分 + 循环遍历
- **删除字符**：重建新串更稳，`erase` 则要回退下标

### 语法速查表

| 用途 | 写法 |
| ---- | ---- |
| 判空 | `s.empty()` |
| 清空 | `s.clear();` |
| 首字符 / 末字符 | `s.front()` / `s.back()` |
| 尾部加字符 | `s.push_back('x');` |
| 尾部删字符 | `s.pop_back();` |
| 带检查访问 | `s.at(i)` |
| 数组转 string | `string s = a;` |
| string 转数组 | `strcpy(a, s.c_str());` |
| 取只读 C 字符串 | `s.c_str()` |

### 易错点提醒

1. **无符号下溢**：`s.size() - 1` 先赋给 `int`
2. **`find` 结果必须与 `npos` 比较**，不能直接当下标
3. **`substr` / `replace` 的参数是「起点 + 长度」**
4. **`erase` 后下标回退**：循环删除时写 `i--`
5. **空串不要取首尾、不要 `pop_back`**
6. **`cin >>` 与 `getline` 混用**：中间补 `cin.ignore()`

> **本节小结**：本章补齐了 `string` 的状态查询、首尾操作与类型互转，并给出「`find` + `substr`」的通用解析套路；记牢无符号长度、下标含义、缓冲区残留这三个高频坑，字符串题目就基本不会翻车。
