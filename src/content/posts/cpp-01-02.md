## 1. 程序基本框架

任何 C++ 程序都由三部分组成：**头文件**、**命名空间**、**主函数**。缺一不可。

### 头文件

```cpp
#include <iostream>
```

- `#include` 是**预处理指令**，在编译之前把尖括号里的文件内容插入到这一行
- `iostream` 是标准输入输出流库（input/output stream），`cout`、`cin`、`endl` 都来自它
- 尖括号 `<>` 表示去编译器自带的系统目录里找

### 命名空间

```cpp
using namespace std;
```

- `std` 是 C++ 标准库的命名空间（standard），`cout`、`cin`、`endl` 的实际全名是 `std::cout`、`std::cin`、`std::endl`
- 加上这一行后，就可以直接写 `cout` 而不用每次都写 `std::` 前缀
- **注意**：这条语句末尾必须带分号 `;`

### 主函数

```cpp
int main()
{
    // 程序逻辑代码
    return 0;
}
```

- 程序**从 `main` 开始执行**，有且只有一个 `main` 函数
- 函数体用大括号 `{}` 包裹，括号必须成对出现
- `int` 表示函数返回一个整数，最后一行必须是 `return 0;`
- `return 0;` 表示程序正常结束；返回非 0 通常表示出错

### 完整骨架

```cpp
#include <iostream>
using namespace std;

int main()
{
    // 这里写程序逻辑
    return 0;
}
```

### 易错点

1. 漏掉最后的分号 —— `using namespace std` 后面、`return 0` 后面都要有 `;`
2. 大括号不配对 —— 建议写完 `{` 立刻补 `}`
3. 写成 `Main`、`mian` —— C++ **区分大小写**，函数名必须是 `main`
4. 把 `return 0;` 写在程序逻辑中间 —— 它必须是 `main` 的最后一句

> **本节小结**：C++ 程序的固定骨架是「引头文件 → 用命名空间 → 写 main 函数」。记住三处必须写分号、大括号必须配对、`return 0;` 放在最后，就可以开始写任何程序了。

## 2. 注释

### 什么是注释

为了让程序更容易被看懂，程序员会在关键位置添加解释说明，这些说明就是**注释**。

注释是**给人和自己看的**，编译器会完全忽略它，既不会编译进程序，也不影响运行速度。

### 单行注释

```cpp
// 同一行双斜线右侧的所有内容都是注释
int a = 10;  // 也可以写在语句后面
```

- 语法：以 `//` 开头
- 范围：从 `//` 到**本行结束**
- 适用：简短说明

### 多行注释

```cpp
/*
   这中间的所有内容都是注释
   可以跨越多行
*/
```

- 语法：以 `/*` 开头，以 `*/` 结束
- 范围：从 `/*` 到 `*/` 之间的全部内容
- 适用：较长的说明，或临时注释掉一整段代码

### 实际用法

```cpp
// 头文件
#include <iostream>
using namespace std;  // 命名空间

/*
  一个 C++ 基础框架：
  头文件 + 命名空间 + 主函数
*/

int main()
{
    // 这里是主函数体
    return 0;
}
```

### 写注释的建议

1. **解释意图，而不是复述代码** —— `i++;  // i 加 1` 没有价值，`i++;  // 移动到下一个元素` 才有
2. **避免过度注释** —— 一眼能看懂的代码不用注释
3. **代码改了要同步改注释** —— 过时的注释比没有注释更有害
4. 单行注释用于短说明，多行注释用于大段说明

> **本节小结**：`//` 注释到行尾，`/* */` 注释到结束标记，两者都只给人看、不影响运行。好的注释解释「为什么这么做」，而不是「这行做了什么」。

## 3. 输出语句 cout

```cpp
cout << "Hello World";
```

### 语法拆解

| 部分 | 含义 |
| ---- | ---- |
| `cout` | 标准输出流对象，默认输出到**控制台**（屏幕） |
| `<<` | 流插入运算符，把右边的数据「送」给左边 |
| `"Hello World"` | 要输出的内容，双引号包裹的是**字符串** |

### 连续输出

```cpp
cout << "姓名：" << "MoFeng" << "  年龄：" << 18;
```

- `<<` 可以连续使用，把多个内容**拼接**后一次输出
- 字符串用双引号，数字直接写（不要加引号）

### 输出变量的值

```cpp
int score = 95;
cout << score;            // 输出 95
cout << "分数：" << score;  // 输出 分数：95
```

> **本节小结**：`cout << 内容;` 是 C++ 最基本的输出方式，`<<` 可以连用拼接多段内容。字符串加双引号，变量名直接写——加了引号就会输出名字本身而不是变量的值。

## 4. 换行：`\n` 与 `endl`

程序不会自动换行，所有输出默认挤在同一行。C++ 提供两种换行方式。

### 方式一：转义字符 `\n`

```cpp
cout << "第一行\n第二行\n第三行";
```

- `\n` 是**转义字符**，代表一个换行符
- 必须写在**双引号内部**，作为字符串的一部分
- `\` 和 `n` 必须紧挨着，**中间不能有空格**
- 反斜杠方向不能写反（是 `\` 不是 `/`）

### 方式二：流操作符 `endl`

```cpp
cout << "第一行" << endl;
cout << "第二行" << endl;
```

- `endl` 是标准库定义的**流操作符**（end line）
- 写在**双引号外部**，通过 `<<` 连接
- 除了换行，还会**刷新输出缓冲区**

### 两种方式对比

| 特性 | `\n` | `endl` |
| ---- | ---- | ------ |
| 书写位置 | 双引号内部 | 双引号外部，用 `<<` 连接 |
| 功能 | 仅换行 | 换行 + 刷新缓冲区 |
| 效率 | 较高 | 略低（每次都要刷新） |
| 适用场景 | 一般批量输出 | 需要立即看到输出的场景 |

### 选择建议

- 循环里大量输出用 `\n`，速度快
- 调试时想立刻看到结果、或程序可能中途崩溃，用 `endl`
- 同一个项目里保持风格统一

```cpp
// 推荐：一次输出多行
cout << "标题\n";
cout << "内容一\n内容二\n";

// 等价写法
cout << "标题" << endl;
cout << "内容一" << endl << "内容二" << endl;
```

> **本节小结**：换行有两条路——`\n` 写进字符串里，轻量高效；`endl` 挂在 `<<` 上，附带刷新缓冲区。日常输出优先 `\n`，需要立即看到结果时用 `endl`。

## 知识框架梳理

### 核心概念总结

- **程序骨架**：`#include <iostream>` → `using namespace std;` → `int main() { ... return 0; }`
- **注释**：`//` 行注释，`/* */` 块注释，编译器完全忽略
- **输出**：`cout << 内容;`，`<<` 可连续拼接
- **换行**：`\n` 在字符串内、效率高；`endl` 在字符串外、会刷新缓冲区

### 语法速查表

| 用途 | 写法 |
| ---- | ---- |
| 引入输入输出库 | `#include <iostream>` |
| 使用标准命名空间 | `using namespace std;` |
| 主函数 | `int main() { ... return 0; }` |
| 单行注释 | `// 注释内容` |
| 多行注释 | `/* 注释内容 */` |
| 输出字符串 | `cout << "文本";` |
| 输出变量 | `cout << 变量名;` |
| 连续输出 | `cout << a << b << c;` |
| 转义换行 | `cout << "第一行\n第二行";` |
| 流换行 | `cout << 内容 << endl;` |

### 易错点提醒

1. **分号**：`using namespace std`、`return 0`、每条语句结尾都要有 `;`，`#include` 却**不要**加分号
2. **大小写**：`main`、`cout`、`endl` 全部小写，写成 `Main`、`Cout` 会直接编译报错
3. **引号**：字符串必须用双引号 `"..."`，字符才用单引号
4. **`\n` 的位置**：写在双引号**里面**；`endl` 写在双引号**外面**
5. **`\` 方向**：是反斜杠 `\n`，不是正斜杠 `/n`
6. **`return 0;` 的位置**：必须是 `main` 的最后一句，不能提前 return
7. **输出到控制台不是文件**：`cout` 默认输出到屏幕，控制台窗口里的内容不会自动保存

> **本节小结**：「头文件 + 命名空间 + 主函数」这套骨架，加上 cout 输出与 \n / endl 换行，就构成了写任何 C++ 程序的地基。
