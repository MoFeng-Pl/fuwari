## 1. `<cmath>` 头文件

**数学库函数**（math library function）是 C++ 标准库预先写好的一批数学计算函数 —— 开平方、乘方、取绝对值、取整。它们不在语言本身里，而放在头文件 `<cmath>`（C 语言中叫 `math.h`）中，用之前**代码开头必须 `#include <cmath>`**。

### 语法格式

```cpp
#include <iostream>
#include <cmath>       // 和 <iostream> 并列，写在文件最上方

int main()
{
    // 之后才能使用 sqrt、pow、abs、ceil、floor
}
```

调用格式统一为 `函数名(参数)`，多个参数之间用**英文逗号**分隔。

### 常用函数一览

| 函数 | 作用 | 示例 |
| ---- | ---- | ---- |
| `sqrt(x)` | 平方根 | `sqrt(16)` → 4 |
| `pow(a, b)` | a 的 b 次方 | `pow(2, 4)` → 16 |
| `abs(x)` | 绝对值 | `abs(-123)` → 123 |
| `ceil(x)` | 向上取整 | `ceil(12.56)` → 13 |
| `floor(x)` | 向下取整 | `floor(12.56)` → 12 |
| `round(x)` | 四舍五入 | `round(12.56)` → 13 |

### 易错点

1. **漏写 `#include <cmath>`** —— 编译报错"函数未声明"
2. **写成 `math.h`** —— C++ 中推荐 `<cmath>`，`<math.h>` 虽可用但不是标准写法
3. **头文件写在 `main` 里面** —— `#include` 必须写在文件最上方
4. **函数名大写** —— C++ 区分大小写，`Sqrt` 不等于 `sqrt`

> **本节小结**：数学库函数全部来自 `<cmath>` 头文件，用之前先在代码开头 `#include <cmath>`，调用格式统一是"函数名(参数)"，参数用英文逗号分隔。

## 2. 平方根与乘方

**平方根**（square root）`sqrt(x)` 求"谁的平方等于 x"，`sqrt(16)` 得 4；**乘方**（power）`pow(a, b)` 求 a 的 b 次方，`n` 个相同的 `a` 相乘记作 `aⁿ`。

### 乘方的数学基础

`2 * 2 * 2 * 2` 就是 4 个 2 相乘，记作 `2⁴`，结果是 16。

**2 次方**通常称为**平方**，**3 次方**称为**立方**；任何数的 1 次方都等于它自身（`a¹ = a`，如 `6¹ = 6`），任何正整数的 0 次方都等于 1（`a⁰ = 1`，如 `6⁰ = 1`）。所以 `pow(6, 1)` 得 6、`pow(6, 0)` 得 1，不需要特判。

### 代码示例

```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main()
{
    cout << sqrt(16) << endl;      // 4
    cout << sqrt(2) << endl;       // 1.41421
    cout << pow(2, 4) << endl;     // 16
    cout << pow(3, 3) << endl;     // 27
    return 0;
}
```

`pow` 的两个参数必须用英文逗号分隔，**不能写成 `2^4`** —— `^` 在 C++ 里是**按位异或**（bitwise XOR），不是乘方。`sqrt` 常用于素数判断优化：若 `n = a × b`，`a` 和 `b` 中必有一个不超过 `sqrt(n)`，所以试除到 `sqrt(n)` 就够。

### 易错点

1. **用 `^` 表示乘方** —— `2 ^ 4` 是异或运算，结果是 6 而不是 16
2. **`pow` 参数顺序写反** —— `pow(2, 3)` 是 8，`pow(3, 2)` 是 9，完全不同
3. **`sqrt` 传负数** —— 数学上无意义，会得到非数（NaN）
4. **`pow` 结果直接赋给 `int`** —— 浮点转整数会截断，大数还可能溢出

> **本节小结**：`sqrt(x)` 求平方根、`pow(a, b)` 求 a 的 b 次方，两者都依赖 `<cmath>`；`^` 不是乘方运算符，乘方必须用 `pow`。

## 3. 绝对值

**绝对值**（absolute value）表示一个数在数轴上到 0 的距离，所以永远非负：正数和 0 的绝对值是它本身，负数的绝对值是去掉负号后的数字部分。数轴上 `-10` 与 `10` 到 0 的距离都是 10，故 `|-10| = |10| = 10`。

### 代码示例

```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main()
{
    cout << abs(66) << endl;       // 66
    cout << abs(-123) << endl;     // 123
    cout << abs(4.6) << endl;      // 4.6
    cout << abs(-5.2) << endl;     // 5.2
    return 0;
}
```

`abs` 对整数和浮点数都有效：整数进去得整数，浮点数进去得浮点数。常见用途是求两点距离 `abs(a - b)`、判断"接近" `abs(x - y) < 0.001`、以及处理负数取余前的符号问题。

### 易错点

1. **对负数取余前忘了取绝对值** —— `-7 % 2` 得 `-1`，加上 `abs` 后才好处理
2. **以为 `abs` 会改变原变量** —— 它只**返回**结果，不修改参数本身
3. **对浮点数在旧编译器上用 `abs`** —— 某些环境需用 `fabs`，C++ 的 `<cmath>` 中 `abs` 已重载
4. **写成 `ABS` 或 `absolute`** —— 函数名必须小写且拼写准确

> **本节小结**：`abs(x)` 返回 x 的绝对值，整数浮点都适用，常用于求两点距离、误差比较，以及处理负数取余前的符号问题。

## 4. 取整与四舍五入

取整分两个方向，另有四舍五入，三者结果常常不同：

| 函数 | 名称 | 规则 | `12.56` | `15` |
| ---- | ---- | ---- | ------- | ---- |
| `ceil(x)` | 向上取整（ceiling） | 大于或等于 x 的**最小整数** | 13 | 15 |
| `floor(x)` | 向下取整（floor） | 小于或等于 x 的**最大整数** | 12 | 15 |
| `round(x)` | 四舍五入（round） | 按小数部分进位 | 13 | 15 |

对整数本身（如 15、6）取整，结果就是它自己，不会改变。

### 代码示例

```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main()
{
    cout << ceil(12.56) << endl;     // 13
    cout << ceil(123.456) << endl;   // 124
    cout << floor(12.56) << endl;    // 12
    cout << floor(6) << endl;        // 6
    cout << round(12.56) << endl;    // 13
    return 0;
}
```

### 返回值类型

`ceil`、`floor`、`round` 返回的是**浮点数类型**，不是整数。直接 `cout` 通常只显示整数部分，赋给 `int` 变量时才真正转成整数：`int a = ceil(12.56);` 得到 13。

负数时"向上"指数值变大（向 0 靠）、"向下"指数值变小：`ceil(-12.4) = -12`、`floor(-12.4) = -13`，不要按"向左向右"理解。

### 易错点

1. **以为 `ceil` 会修改原变量** —— 它只返回结果，`ceil(x);` 单独一行等于白写
2. **用 `floor` 代替整数除法** —— 正整数时 `n / m` 本来就是向下取整，无需 `floor`
3. **忘记返回浮点** —— 输出带 `.0` 或参与运算时结果带小数，需要时转 `int`
4. **`round` 与 `floor(x + 0.5)` 混用** —— 负数时两者结果不同

> **本节小结**：`ceil` 向上、`floor` 向下、`round` 四舍五入，三者返回浮点数；对整数取整结果不变，负数方向按数值大小而不是左右理解。

## 5. 常见误区

数学库函数用起来简单，但初学阶段的错误高度集中。整理成清单，写代码前对照一遍，能省下大量调试时间。

### 误区一：漏写头文件或位置错

`#include <cmath>` 必须放在文件最上方。少了它，`sqrt`、`pow` 全部"未声明"，编译直接失败；写在 `main` 里面同样无效。

### 误区二：把 `^` 当乘方、误用中文标点

```cpp
cout << (2 ^ 4);          // ❌ 输出 6（按位异或），不是 16
cout << pow(2, 4);        // ✅ 输出 16
pow(2，4);                // ❌ 中文逗号，编译报错
```

### 误区三：类型不匹配

| 写法 | 问题 | 建议 |
| ---- | ---- | ---- |
| `int a = sqrt(2);` | 1.414 被截断为 1 | 需要小数就用 `double` |
| `int b = pow(2, 31);` | 超出 `int` 范围，结果异常 | 用 `long long` 或手写累乘 |
| `if (sqrt(2) == 1.414)` | 浮点比较不可靠 | 用 `abs(a - b) < 1e-6` |

浮点数在计算机中是近似存储的，**永远不要用 `==` 直接比较两个浮点结果**，应比较它们的差值是否足够小。

### 误区四：以为函数会修改参数

```cpp
int x = -5;
abs(x);              // ❌ 单独一行，结果被丢弃
cout << x;           // 仍输出 -5
x = abs(x);          // ✅ 用变量接住返回值
```

### 易错点

1. **只写函数调用不接返回值** —— 计算结果直接丢失，变量毫无变化
2. **浮点用 `==` 比较** —— 精度误差导致判断失败，应比较差值
3. **整数溢出** —— `pow` 结果赋给 `int` 前先估一下数量级
4. **混用 `<cmath>` 与 `<math.h>`** —— 同一项目统一用 `<cmath>`

> **本节小结**：数学库函数的错误集中在"头文件、`^` 误用、中文标点、类型转换、浮点比较"五处，记住"写头文件、用 `pow`、接返回值、别用 `==` 比浮点"就能避开绝大部分坑。

## 知识框架梳理

### 核心概念总结

- **头文件**：所有数学函数都来自 `#include <cmath>`
- **平方根**：`sqrt(x)`，常用于素数判断优化
- **乘方**：`pow(a, b)` 求 a 的 b 次方，`a¹ = a`、`a⁰ = 1`
- **绝对值**：`abs(x)` 返回非负值，整数浮点都适用
- **取整**：`ceil` 向上、`floor` 向下、`round` 四舍五入，均返回浮点
- **返回值**：函数只返回结果，不会修改传入的变量

### 语法速查表

| 用途 | 写法 | 示例结果 |
| ---- | ---- | -------- |
| 引入数学库 | `#include <cmath>` | —— |
| 平方根 | `sqrt(x)` | `sqrt(16)` → 4 |
| 乘方 | `pow(a, b)` | `pow(2, 4)` → 16 |
| 绝对值 | `abs(x)` | `abs(-123)` → 123 |
| 向上取整 | `ceil(x)` | `ceil(12.56)` → 13 |
| 向下取整 | `floor(x)` | `floor(12.56)` → 12 |
| 四舍五入 | `round(x)` | `round(12.56)` → 13 |
| 转成整数 | `int n = (int)ceil(x);` | 截断小数部分 |

### 易错点提醒

1. **漏 `#include <cmath>`**：函数未声明，编译直接失败
2. **`^` 当乘方**：它是按位异或，`2 ^ 4` 得 6，乘方要用 `pow`
3. **中文逗号**：`pow(2，4)` 编译报错，参数分隔必须是英文逗号
4. **负数取整方向**：`ceil` 使数值变大、`floor` 使数值变小，不是"左右"
5. **返回浮点被截断**：`int a = sqrt(2);` 会丢掉小数部分
6. **浮点用 `==`**：应改为 `abs(a - b) < 1e-6`
7. **只用不接**：`abs(x);` 单独一行等于什么都没做

> **本节小结**：本组把 `<cmath>` 里最常用的函数一次讲清 —— `sqrt` 开方、`pow` 乘方、`abs` 绝对值、`ceil`/`floor`/`round` 取整，用之前记得引头文件、用英文逗号、接住返回值。
