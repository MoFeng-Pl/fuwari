## 1. 尾部插入

数组末尾追加一个元素，是最简单的插入：新元素放到**当前有效长度的下一个位置**。

### 语法格式

```cpp
a[n] = 新元素;
n++;              // 有效长度加 1
```

```cpp
int a[10] = {65, 66, 67};
int n = 3;               // 已有 3 个元素

a[n] = 68;               // 放到 a[3]
n++;                     // 有效长度变成 4
// 数组有效内容：{65, 66, 67, 68}
```

### 两个前提

1. **有空间**：`n` 必须小于数组容量，否则 `a[n]` 就越界
2. **长度单独记**：`n` 是"实际用了几格"，不等于方括号里的容量

### 易错点

`a[10]` 的数组最多装 10 个元素，当 `n == 10` 时再写 `a[10] = 68;` 就越界了。

> **本节小结**：尾部插入就是"往 `a[n]` 写值再把 `n` 加一"，前提是容量还没用满。

## 2. 指定位置插入

把新元素 k 插入到下标 x 的位置，含义是：**k 占据 x，原来 x 及其后的元素整体后移一位**。

### 两个步骤

```cpp
// 下标 0 1 2 3 4
// 原数组：65 66 67 68 69，要在 x = 2 插入 k

// 第 1 步：把 a[x] 及其后的元素右移一位，腾出位置
// 结果：65 66 __ 67 68 69

// 第 2 步：把 k 写进 a[x]
// 结果：65 66 k 67 68 69
```

### 开头插入是特例

x = 0 时，就是"在数组开头插入新元素"：

```cpp
int a[8] = {88, 99, 50};
int n = 3;

for (int i = n - 1; i >= 0; i--) { a[i + 1] = a[i]; }   // 全体右移
a[0] = 14;                                              // 新元素占下标 0
n++;
// 结果：{14, 88, 99, 50}
```

### 易错点

插入不是"覆盖"：写 `a[x] = k;` 会把原来的 `a[x]` 直接冲掉，必须先腾位。

> **本节小结**：指定位置插入固定两步——先腾位（后移），再落子（写 k），顺序颠倒就丢数据。

## 3. 后移腾位

腾位的循环是插入的核心，**必须从右往左**遍历。

### 语法格式

```cpp
for (int i = n - 1; i >= x; i--)
{
    a[i + 1] = a[i];
}
```

```cpp
int a[10] = {65, 66, 67, 68, 69};
int n = 5;
int x = 2, k = 100;

for (int i = n - 1; i >= x; i--) { a[i + 1] = a[i]; }
a[x] = k;
n++;
// 结果：{65, 66, 100, 67, 68, 69}，长度 6
```

### 为什么必须逆序

| 遍历方向 | 过程 | 结果 |
| -------- | ---- | ---- |
| 从右往左 `i--` | 先搬 `a[n-1]`，再搬前面的 | 正确 |
| 从左往右 `i++` | `a[x+1]` 先被覆盖，`a[x]` 的值污染后面全部 | 全错 |

原因：后移是"把左边的值写到右边"，目标格在被写之前必须先空出来，所以要从最右端开始搬。

### 循环边界

- `i` 的初值是 `n-1`（最后一个有效元素）
- `i` 的终值是 `x`（要腾出的位置）
- 循环体只写 `a[i+1] = a[i]`，最大写到 `a[n]`，正是不越界的临界位置

> **本节小结**：腾位循环"从 `n-1` 递减到 `x`"，方向错了数据会连锁覆盖，边界错了就越界。

## 4. 长度维护

数组的**容量**是固定的，**有效长度**靠一个变量自己记账。

### 容量与长度

| 名称 | 含义 | 谁决定 |
| ---- | ---- | ------ |
| 容量（capacity） | 方括号里的数字，最多能装几个 | 定义时确定，不能改 |
| 有效长度（effective length） | 实际存了几个有用元素 | 变量 `n`，插入加 1、删除减 1 |

### 插入后的维护清单

```cpp
if (n < 容量)                     // 1. 先判断有没有空间
{
    for (int i = n - 1; i >= x; i--) { a[i + 1] = a[i]; }   // 2. 腾位
    a[x] = k;                     // 3. 落子
    n++;                          // 4. 长度加一
}
```

### 边界检查

- `x` 的合法范围是 `0 ~ n`（`x == n` 时等价于尾部插入）
- `x > n` 或 `x < 0` 都是非法位置
- `n == 容量` 时不允许再插入

### 易错点

只写 `a[x] = k;` 却忘了 `n++`，后续遍历仍按旧长度走，新元素永远读不到。

> **本节小结**：容量定死、长度自记；插入的完整流程是"判空间 → 腾位 → 写入 → `n++`"，四步缺一不可。

## 知识框架梳理

### 核心概念总结

- **尾部插入**：`a[n] = k; n++;`，前提 `n < 容量`
- **指定位置插入**：k 占 x，原 x 及其后元素整体后移一位
- **后移腾位**：`for (int i = n-1; i >= x; i--) a[i+1] = a[i];` 必须逆序
- **长度维护**：容量固定，有效长度用变量 `n` 记账，插入后 `n++`

### 语法速查表

| 用途 | 写法 |
| ---- | ---- |
| 尾部插入 | `a[n] = k; n++;` |
| 开头插入 | 全体右移后 `a[0] = k; n++;` |
| 指定位置腾位 | `for (int i = n-1; i >= x; i--) a[i+1] = a[i];` |
| 写入新元素 | `a[x] = k;` |
| 长度加一 | `n++;` |
| 空间检查 | `if (n < 容量)` |
| 位置检查 | `if (x >= 0 && x <= n)` |

### 易错点提醒

1. **直接覆盖**：先写 `a[x] = k;` 再移动，原 `a[x]` 已丢失
2. **腾位用正序**：从左往右搬会连锁覆盖，必须 `i--`
3. **循环漏掉 `i = x`**：`i > x` 时 `a[x]` 没被移到 `a[x+1]`
4. **忘记 `n++`**：新元素写进去了，但长度没变，等于没插
5. **容量用满还插**：`n == 容量` 时 `a[n]` 越界
6. **`x` 超范围**：合法范围是 `0 ~ n`，`x > n` 非法
7. **把容量当长度**：遍历时用容量代替 `n`，会读到没赋值的垃圾数据
8. **插入顺序颠倒**：正确顺序永远是"先腾位，后落子"

> **本节小结**：插入的本质是「腾位置」：从末尾往前依次后移，再把新值写进空出的下标，最后长度加一。
