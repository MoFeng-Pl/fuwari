## 1. 循环中读入数据

### 核心概念

`cin >> 变量` 一次只读一个数据。要让程序读入一批数据，就把 `cin` 放进循环体里，让每一轮读取一个新的值。

循环输入最常见的结构是「先读个数，再循环读数据」：先用一个变量记住一共有几个数，再让循环执行那么多次。

### 代码示例

读入 n 个数并求和：

```cpp
#include <iostream>
using namespace std;

int main()
{
    int n;
    cin >> n;                  // 先读入数据个数

    int sum = 0;
    for (int i = 0; i < n; i = i + 1)
    {
        int x;
        cin >> x;              // 每一轮读入一个数据
        sum = sum + x;
    }

    cout << sum;
    return 0;
}
```

输入 `5`，再输入 `1 2 3 4 5`，输出 `15`。

### 易错点

1. 只写一次 `cin` 却没有循环，永远只读到第一个数据
2. 循环次数与数据个数不一致：读 n 个数却写 `i <= n` 且起点为 0，会多读一次
3. `cin` 会自动跳过空格和换行，所以数据之间用哪种分隔都可以
4. 把 `int x;` 写在循环外也可以，但它每轮都会被新值覆盖，不能用来保存历史数据

> **本节小结**：循环输入 = 先读入「有几个数据」，再用循环执行那么多次 `cin`，读一个处理一个。

## 2. 不定长数据的读入

### 核心概念

有些题目不告诉你有几个数据，`for` 循环定不出次数，这时只能描述「什么时候停」。常见的三种处理方式：

| 情形 | 判断方式 | 循环写法 |
| ---- | -------- | -------- |
| 先给个数 n | 数据个数已知 | `for (int i = 0; i < n; i++)` |
| 以特殊值结尾 | 读到 0 或 -1 停止 | `while (cin >> x && x != 0)` |
| 读到文件结束 | 一直读到末尾 | `while (cin >> x)` |

### 代码示例

读到文件结束为止，边读边累加：

```cpp
int x;
int sum = 0;
while (cin >> x)
{
    sum = sum + x;
}
cout << sum;
```

`while (cin >> x)` 的含义是：**读取成功就继续，读不到数据就结束**。输入结束时 `cin` 进入失败状态，条件为假，循环自动退出。手动触发结束的方式是 Windows 下按 `Ctrl + Z` 再回车、Linux 下按 `Ctrl + D`。

以 0 作为结束标志：

```cpp
int x;
cin >> x;
while (x != 0)
{
    cout << x << " ";
    cin >> x;          // 必须有这一句，否则永远读同一个数
}
```

### 易错点

1. 用 `while (cin >> x)` 时又在循环体里写一次 `cin >> x`，会一次读走两个数据
2. 以特殊值结束时忘记在循环体末尾再读一次，条件永远不变，变成死循环
3. 不要用 `while (!cin.eof())` 判断结束，这种写法容易多处理一次末尾数据

> **本节小结**：个数已知用 `for`，个数未知用 `while`；`while (cin >> x)` 是最省事的「读到没有为止」写法。

## 3. printf 基本用法

### 核心概念

`printf` 是 C 语言留下的格式化输出函数，在 C++ 里同样可用。它按「格式串 + 参数」的方式工作：格式串里的**占位符**（placeholder）被后面参数的值依次替换。

它和 `cout` 最直观的区别是：`printf` **不会自动换行**，要换行必须在格式串里自己写 `\n`。

### 语法格式

```cpp
printf("输出内容\n");
printf("格式串", 参数1, 参数2, ...);
```

- 需要包含头文件 `#include <cstdio>`
- 格式串必须用双引号，参数之间用**逗号**隔开，不是 `<<`
- 语句末尾要有分号

### 代码示例

```cpp
#include <cstdio>

int main()
{
    printf("Hello World\n");

    int score = 95;
    printf("分数：%d\n", score);   // 分数：95
    return 0;
}
```

### 易错点

1. 漏写 `\n`，多行输出会全部挤在一行
2. 用 `<<` 连接参数，`printf("分数：%d" << score);` 是错的
3. 忘记 `#include <cstdio>`，编译器提示 `printf` 未声明
4. 占位符个数与参数个数不一致，多出的占位符会输出随机值

> **本节小结**：`printf("格式串", 参数...)` 用占位符占位、用逗号传参，换行要靠自己写 `\n`，这是它和 `cout` 最直观的两点差别。

## 4. 格式控制符

### 核心概念

**格式控制符**（format specifier，也常叫占位符）决定一个值以什么形式打印出来。常用的有五个：

| 占位符 | 表示类型 |
| ------ | -------- |
| `%d` | 十进制整数（`int`） |
| `%lld` | `long long` |
| `%f` | `float` |
| `%lf` | `double` |
| `%c` | `char` |

在 `printf` 里 `%f` 和 `%lf` 都能打印 `double`（`float` 传参时会自动提升）；但在 `scanf` 里两者不能混用，`%f` 对应 `float`，`%lf` 才对应 `double`。

### 混合使用

一条 `printf` 里可以同时出现多个不同的占位符，后面的参数按**从左到右**的顺序依次填入：

```cpp
printf("总分：%d分，等级：%c", 750, 'A');
```

输出 `总分：750分，等级：A`：`%d` 拿到第一个参数 `750`，`%c` 拿到第二个参数 `'A'`，位置一一对应。

### 控制小数位数

在 `%f` 中间插入 `.n` 可以指定保留几位小数，`%.2f` 表示保留两位：

```cpp
double pi = 3.1415926;
printf("%f\n", pi);      // 3.141593，默认六位小数
printf("%.2f\n", pi);    // 3.14，保留两位
```

### 易错点

1. 类型与占位符不匹配，例如用 `%d` 打印 `double`，输出会变成乱码或 0
2. 占位符顺序与参数顺序不一致，数值会整体错位
3. 把 `%.2f` 写成 `%2f`，含义从「两位小数」变成「最小宽度 2」
4. 参数个数少于占位符个数，缺少的那个会输出不可预期的值

> **本节小结**：占位符是「类型 + 格式」的说明书，`%d` 配整数、`%c` 配字符、`%.2f` 配两位小数，占位符与参数的个数、类型、顺序必须三对齐。

## 5. cout 与 printf 的取舍

### 核心概念

两种输出方式都能把结果送到屏幕，区别在写法风格与格式控制能力上。

| 方面 | `cout` | `printf` |
| ---- | ------ | -------- |
| 头文件 | `<iostream>` | `<cstdio>` |
| 连接方式 | `<<` 连续拼接 | 逗号分隔参数 |
| 类型检查 | 自动识别类型，不会错配 | 需手写占位符，可能错配 |
| 格式控制 | 需配合 `<iomanip>` | `%.2f` 等一步到位 |
| 书写长度 | 较长 | 较短，适合密集输出 |

### 代码示例

```cpp
double avg = 87.6666;

cout << "平均分：" << avg << endl;        // 平均分：87.6666
printf("平均分：%.2f\n", avg);            // 平均分：87.67
```

### 选择建议

- 初学和日常练习优先用 `cout`，不必记占位符，出错少
- 需要**固定小数位数**、对齐输出或一次输出很多行时，`printf` 更顺手
- 输出 `long long` 时用 `cout` 更省心，不必记 `%lld`
- 两种混用不会报错，但同一份代码里风格最好统一

> **本节小结**：`cout` 胜在类型安全、写起来不容易错，`printf` 胜在格式控制精确、代码紧凑；按题目对格式的要求选，不必强求一种。

## 知识框架梳理

### 核心概念总结

- **循环输入**：先读个数，再在循环里反复 `cin`，读一个处理一个
- **不定长读入**：个数未知时用 `while (cin >> x)` 读到输入结束
- **`printf`**：按格式串输出，占位符由逗号后的参数依次替换，换行要自己写 `\n`
- **格式控制符**（format specifier）：`%d`、`%lld`、`%f`、`%lf`、`%c`，用 `%.2f` 控制小数位数

### 语法速查表

| 用途 | 写法 |
| ---- | ---- |
| 引入 printf | `#include <cstdio>` |
| 输出文字 | `printf("Hello\n");` |
| 输出整数 | `printf("%d", a);` |
| 输出长整数 | `printf("%lld", b);` |
| 保留两位小数 | `printf("%.2f", x);` |
| 输出字符 | `printf("%c", ch);` |
| 混合输出 | `printf("总分：%d分，等级：%c", 750, 'A');` |
| 循环读 n 个数 | `for (int i = 0; i < n; i++) { cin >> x; }` |
| 读到结束 | `while (cin >> x) { ... }` |

### 易错点提醒

1. **`printf` 不自动换行**：不加 `\n`，所有输出会连成一行
2. **参数用逗号**：`printf` 的参数是逗号分隔，不是 `<<`
3. **占位符对齐**：个数、类型、顺序三处都要与参数一致
4. **`%d` 不能打印小数**：小数用 `%f` 或 `%lf`
5. **`%.2f` 不是 `%2f`**：小数点前的点不能丢
6. **不定长输入**：以特殊值结束时，循环体末尾必须再读一次
7. **`while (cin >> x)` 里不要再读**：循环条件本身已经在读了

> **本节小结**：循环负责「读多少个」，`printf` 负责「打成什么样子」；把读入次数与格式串两处对齐，输入输出就不会出错。
