# C++程序的基本框架

## 1. 头文件
```cpp
#include <iostream>
```
- 用于引入标准输入输出流库

## 2. 命名空间
```cpp
using namespace std;
```
- 注意：语句必须以 ; 结束
- 目的是简化代码，避免每次使用std命名空间下的内容时都要加std::前缀

## 3. 主函数
```cpp
int main()
{
    // 函数体
    return 0;
}
```

### 主函数要点
- 函数名为`main`
- 函数体用大括号`{}`包裹
- 最后一行必须是`return 0;`

## C++程序的基本结构总结
```cpp
#include <iostream>
using namespace std;

int main()
{
    // 程序逻辑代码
    return 0;
}
```

## 注意事项
1. 每一行语句结束必须有分号`;`
2. `return 0;`必须是main函数的最后一句
3. 使用`using namespace std;`可以简化代码编写
4. 大括号必须配对使用，用于表示代码块的开始和结束

# C++ 注释

## 注释的定义与作用
为使程序更容易被理解，会在代码的关键位置添加一些解释说明，这些说明就被称为**注释**。

注释是给程序员看的，编译器会忽略注释内容，不会将其编译成机器代码。

## 注释的分类

### 1. 单行注释
```cpp
// 同一行双斜线右侧的所有内容都是注释
```

- **语法**：以双斜线 `//` 开头
- **作用范围**：从 `//` 开始到该行结束的所有内容
- **适用场景**：简短的说明或解释

### 2. 多行注释
```cpp
/* 
   这之间的所有内容都是注释
   可以跨越多行
*/
```

- **语法**：以 `/*` 开头，以 `*/` 结束
- **作用范围**：从 `/*` 开始到 `*/` 结束的所有内容
- **适用场景**：需要较长说明或注释掉多行代码时使用

## 注释的实际应用示例

```cpp
//头文件
#include <iostream>
using namespace std;  //命名空间

/*
一个C++基础框架:
头文件
命名空间
主函数
*/

int main()
{
    // 这里是主函数体
    return 0;
}
```

## 注释的使用建议

1. **保持简洁明了**：注释应该简洁地表达代码的目的和逻辑，避免冗余
2. **及时更新**：代码修改时，相关注释也要同步更新
3. **避免过度注释**：不要对显而易见的代码添加注释
4. **使用有意义的注释**：解释代码的意图，而不仅仅是代码本身的功能
5. **单行注释适合简短说明**，多行注释适合复杂逻辑或大段代码的注释

## 注意事项
- 编译器会完全忽略注释内容
- 注释不会影响程序的运行效率
- 适当的注释可以提高代码的可读性和可维护性
  
# C++ 换行符

在C++程序中，常用的换行方式主要有两种：转义字符 `\n` 和流操作符 `endl`。

## 1. 转义字符 `\n`

### 基本概念
- `\n` 是一个转义字符，表示换行操作
- **注意**：`\` 和 `n` 必须连在一起使用，中间**不能有空格**

### 使用方法
- **位置**：将 `\n` 放在双引号里面
- **语法**：作为字符串的一部分使用

### 代码示例
```cpp
// 在字符串中使用\n实现换行
cout << "HHH\n";  // 输出HHH后换行
cout << "HHH";    // 输出HHH后不换行
```

## 2. 流操作符 `endl`

### 基本概念
- `endl` 是C++标准库中定义的一个流操作符
- 它不仅能实现换行，还会刷新输出缓冲区

### 使用方法
- **位置**：在原语句和英文分号 `;` 之间
- **语法**：通过输出流操作符 `<<` 连接 `endl`

### 代码示例
```cpp
// 使用endl实现换行
cout << "HHH" << endl;  // 输出HHH后换行
cout << "HHH";         // 输出HHH后不换行
```

## 两种换行方式的对比

| 特性 | `\n` | `endl` |
|------|------|--------|
| **使用位置** | 双引号内部 | 双引号外部，通过`<<`连接 |
| **实现功能** | 仅换行 | 换行 + 刷新缓冲区 |
| **使用效率** | 较高 | 相对较低（因为有刷新操作） |
| **适用场景** | 一般文本输出 | 需要立即显示输出内容的场景 |

## 实际应用示例

### 场景1：连续输出多行文本
```cpp
// 使用\n的方式
cout << "第一行\n第二行\n第三行";  // 一次输出多行文本

// 使用endl的方式
cout << "第一行" << endl;  // 每行单独输出
cout << "第二行" << endl;
cout << "第三行" << endl;
```

### 场景2：在字符串中间插入换行
```cpp
// 只使用\n的情况
cout << "标题\n内容第一行\n内容第二行";  // 在字符串任意位置插入换行

// 结合使用的情况
cout << "标题" << endl << "内容第一行\n内容第二行";  // 灵活组合使用
```

## 注意事项

1. **关于 `\n` 的正确使用**：
   - 确保反斜杠方向正确（`\` 而不是 `/`）
   - `\` 和 `n` 必须紧密相连，不能有空格
   - 可以在一个字符串中多次使用，实现多处换行

2. **关于 `endl` 的使用**：
   - 使用前必须包含头文件 `<iostream>`
   - 每次使用都需要配合 `<<` 操作符
   - 频繁使用可能会影响程序性能（因为每次都会刷新缓冲区）

3. **编程风格建议**：
   - 在同一个项目中保持一致的换行风格
   - 对于普通输出，`\n` 通常已经足够
   - 在需要确保输出立即显示时（如调试或实时显示）使用 `endl`

## 总结

C++提供了两种常用的换行方式，各有特点：
- `\n` 作为转义字符，使用灵活，效率较高
- `endl` 作为流操作符，功能更全面，包含刷新缓冲区的操作
