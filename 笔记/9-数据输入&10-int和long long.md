# 9-数据输入&10-int 和 long long

## 数据输入

### cin语句

cin语句是C++中用于从标准输入（通常是键盘）读取数据的基本输入语句。

#### 语法结构
```cpp
cin >> 变量名;
```

#### 使用方法
- `cin` 是C++标准库中的输入流对象
- `>>` 是提取运算符，用于从输入流中提取数据并赋值给右侧的变量
- 变量名必须是已经定义的变量

#### 注意事项
- 输入时，数据会自动根据变量类型进行转换
- 输入完成后，需要按下回车键确认输入
- 输入的数据类型必须与变量类型匹配，否则可能导致错误或不可预期的结果

#### 示例代码
```cpp
#include <iostream>
using namespace std;

int main() {
    int num;
    cout << "请输入一个整数：";
    cin >> num;
    cout << "您输入的整数是：" << num << endl;
    return 0;
}
```

### 多项输入

多项输入允许在一条cin语句中同时读取多个变量的值。

#### 实现方式
```cpp
cin >> 变量1 >> 变量2 >> 变量3;
```

#### 输入格式规则
- 以空格或换行来断开输入的多个数据
- 输入完成后，要按下回车键进入下一行语句的执行

#### 不同数据类型的输入处理
多项输入支持同时输入不同数据类型的变量：

```cpp
#include <iostream>
using namespace std;

int main() {
    int age;
    double height;
    char gender;
    
    cout << "请输入年龄、身高和性别（用空格分隔）：";
    cin >> age >> height >> gender;
    
    cout << "年龄：" << age << endl;
    cout << "身高：" << height << endl;
    cout << "性别：" << gender << endl;
    
    return 0;
}
```

#### 常见问题及解决方案
- **问题**：输入数据类型不匹配
  **解决方案**：确保输入的数据类型与变量定义的类型一致

- **问题**：输入的数据数量不足
  **解决方案**：程序会等待用户继续输入，直到满足所有变量的需求

- **问题**：输入的数据数量过多
  **解决方案**：多余的数据会留在输入缓冲区中，可能影响后续的输入操作

## int 和 long long

### 数据溢出

数据溢出是指当变量存储的值超出其数据类型所能表示的范围时发生的现象。

#### 概念
当一个数据类型的变量存储的值超过其最大值时，会发生上溢；当存储的值小于其最小值时，会发生下溢。

#### 产生原因
- 数据类型的取值范围有限
- 运算结果超出了变量类型的表示范围

#### 识别方法
- int最大值+1 = int最小值
- int最小值-1 = int最大值

这种现象可以用一个圆环来形象地表示：当数值达到最大值后继续增加，会从最小值重新开始；当数值达到最小值后继续减少，会从最大值重新开始。

#### 避免策略
- 选择合适的数据类型
- 对可能的溢出进行检查
- 使用更大范围的数据类型（如long long）

#### 示例
```cpp
#include <iostream>
#include <climits> // 包含INT_MAX和INT_MIN的定义
using namespace std;

int main() {
    int max_int = INT_MAX;
    int min_int = INT_MIN;
    
    cout << "int最大值：" << max_int << endl;
    cout << "int最大值+1：" << max_int + 1 << endl; // 溢出，结果为INT_MIN
    
    cout << "int最小值：" << min_int << endl;
    cout << "int最小值-1：" << min_int - 1 << endl; // 溢出，结果为INT_MAX
    
    return 0;
}
```

### long long 类型

long long是C++中的一种整数数据类型，提供了比int更大的取值范围。

#### 定义
```cpp
long long 变量名;
```

#### 特性
- 是一种有符号整数类型
- 占用更多的内存空间
- 支持与int相同的算术和逻辑运算

#### 适用场景
- 需要处理非常大的整数时
- 避免数据溢出问题
- 存储超过int取值范围的数值

#### 声明方式
```cpp
// 单独声明
long long large_num;

// 声明并初始化
long long large_num = 123456789012345LL;

// 多个变量声明
long long a, b, c;

// 多个变量声明并初始化
long long x = 100LL, y = 200LL, z = 300LL;
```

### 数据大小

#### 字节数对比
| 数据类型 | 占字节数 |
|---------|---------|
| int     | 4       |
| long long | 8     |

#### 取值范围对比
| 数据类型 | 取值范围 | 最大位数 |
|---------|---------|---------|
| int     | -2147483648 ~ 2147483647 | 10 |
| long long | -9223372036854775808 ~ 9223372036854775807 | 19 |

#### 对比分析
- long long的字节数是int的2倍（8字节 vs 4字节）
- long long的取值范围远大于int，可以表示更大的整数
- long long可以存储最多19位数字，而int最多只能存储10位数字
- 使用long long会占用更多的内存空间，但能有效避免数据溢出问题
