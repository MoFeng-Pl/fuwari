# C++ 运算符与输出运算结果

## 第一部分：算术运算符

### 1. C++中的基本运算符号

C++提供了五种基本的算术运算符，用于进行数值计算：

| 运算符名称 | 符号 | 作用 |
|---------|-----|------|
| 加号     | +   | 加法运算 |
| 减号     | -   | 减法运算 |
| 乘号     | *   | 乘法运算 |
| 除号     | /   | 除法运算 |
| 取余符号  | %   | 取余数运算（仅适用于整数） |

### 2. 在C++中输出纯数字

**重要规则**：输出纯数字时，`cout <<` 后面的数字不加英文双引号。

```cpp
// 正确示例
cout << 123;  // 输出数字 123

// 错误示例（会被当作字符串处理）
cout << "123";  // 输出字符串 "123"
```

### 3. 输出算式的计算结果

C++可以直接在`cout <<`后输出算术表达式，程序会自动计算并输出结果：

```cpp
cout << 1 + 2;       // 输出：3
cout << 1 + 2 + 3 + 4;  // 输出：10
cout << 4 * 5;       // 输出：20
cout << 4 * 5 * 6 * 7;  // 输出：840
```

## 第二部分：混合运算

### 1. 运算顺序规则

C++中的算术运算遵循以下优先级规则：

1. **有括号，先算括号里的**
   - 括号可以改变运算的优先级
   - 括号内的表达式会先被计算

2. **没有括号，先乘除后加减**
   - 乘法(`*`)、除法(`/`)、取余(`%`)的优先级高于加法(`+`)和减法(`-`)

3. **同级运算，从左往右依次计算**
   - 优先级相同的运算符，按照从左到右的顺序计算

### 2. 运算顺序示例

```cpp
// 示例1：先乘除后加减
cout << 2 + 3 * 4;    // 先计算3*4=12，再计算2+12=14，输出：14
cout << 10 - 6 / 3;   // 先计算6/3=2，再计算10-2=8，输出：8

// 示例2：括号改变优先级
cout << (2 + 3) * 4;  // 先计算括号内的2+3=5，再计算5*4=20，输出：20
cout << 10 - (6 / 3); // 虽然括号可以省略，但使用括号增强可读性，输出：8

// 示例3：同级运算从左到右
cout << 10 - 3 + 2;   // 先计算10-3=7，再计算7+2=9，输出：9
cout << 8 / 4 * 2;    // 先计算8/4=2，再计算2*2=4，输出：4
```

### 3. cout输出多个内容

在C++中，可以使用连续的`<<`操作符在一条语句中输出多个内容：

**语法格式**：
```cpp
cout << 内容1 << 内容2 << ... << 内容n;
```

**重要规则**：
- 多个内容之间用`<<`连接
- 记得在语句末尾添加英文分号`;`

**输出规则**：
1. **算式会被计算后输出结果**
   ```cpp
   cout << 2 * 3;  // 输出：6
   ```

2. **加英文双引号的内容会原样输出**
   ```cpp
   cout << "2*3";  // 输出：2*3
   ```

### 4. 混合输出示例

```cpp
// 示例1：输出文本和计算结果
cout << "计算结果是：" << 100 / 4;  // 输出：计算结果是：25

// 示例2：多个计算表达式
cout << 2 + 3 << ", " << 4 * 5;   // 输出：5, 20

// 示例3：带有括号的复杂表达式
cout << "(10 + 5) * 2 = " << (10 + 5) * 2;  // 输出：(10 + 5) * 2 = 30
```

## 注意事项

1. **整数除法注意事项**：
   - 当两个整数相除时，结果会自动向下取整（截断小数部分）
   - 例如：`cout << 5 / 2;` 会输出：2，而不是2.5

2. **输出内容的区分**：
   - 带双引号的内容会被当作字符串原样输出
   - 不带双引号的数字和表达式会被计算后输出结果

3. **运算符优先级**：
   - 忘记优先级规则时，使用括号是最安全的做法
   - 合理使用括号可以使代码更加清晰易读

4. **取余运算**：
   - 取余运算符`%`只能用于整数运算
   - 例如：`cout << 7 % 3;` 输出：1，`cout << 7 % 2;` 输出：1

## 总结

1. C++提供了五种基本算术运算符：`+`（加）、`-`（减）、`*`（乘）、`/`（除）、`%`（取余）

2. 输出纯数字时不加双引号，输出字符串时需要加双引号

3. 运算顺序遵循：括号优先 > 乘除取余 > 加减 > 从左到右

4. 可以使用多个`<<`操作符连续输出不同类型的内容

5. 程序会自动计算表达式并输出结果，而字符串会原样输出","
