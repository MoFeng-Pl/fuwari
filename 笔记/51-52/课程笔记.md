# C++一维数组学习笔记

## 1. 数组定义

数组是**存储同一种数据类型的多个数据的集合**。

### 核心概念

- **同一数据类型**：数组中的所有元素必须是相同的数据类型（如全部是int、全部是char等）
- **多个数据**：数组可以存储多个值，而不是单个值，这些值在内存中连续存放
- **集合**：数组是一个整体，通过统一的名称和下标来访问其中的各个元素

> **本节小结**：数组是一种基本的数据结构，用于高效地存储和管理一组相同类型的数据。理解"同类型"和"多个数据"这两个关键特征，是掌握数组概念的基础。

---

## 2. 数组命名规则

数组命名需要遵循以下4条规则：

### 命名规则

1. **只能包含字母、数字、下划线**
   - 合法：`score`、`student_age`、`arr1`、`_data`
   - 非法：`my-array`（含减号）、`arr@1`（含特殊符号）

2. **不能以数字开头**
   - 合法：`arr1`、`num2`
   - 非法：`1arr`、`2nd_item`

3. **不能是C++关键字**
   - 非法：`int`、`for`、`while`、`class`、`return`
   - 这些是C++保留的关键字，不能用作标识符

4. **区分大小写**
   - `arr` 和 `Arr` 是两个不同的名称
   - `Score` 和 `score` 也是不同的

### 示例对比

| 命名 | 是否合法 | 原因 |
|------|----------|------|
| `student_score` | ✅ 合法 | 符合所有规则 |
| `arr1` | ✅ 合法 | 符合所有规则 |
| `1arr` | ❌ 非法 | 数字开头 |
| `my-array` | ❌ 非法 | 含非法字符 |
| `int` | ❌ 非法 | 是关键字 |

> **本节小结**：命名规范是编程的基础，良好的命名习惯能提高代码可读性，避免编译错误。记住"三能一不能"：能用字母、数字、下划线，不能数字开头，同时避开关键字。

## 3. 定义一维数组

### 语法格式

```cpp
类型 数组名[长度];
```

- **类型**：数据类型，如 `int`、`char`、`float`、`double` 等
- **数组名**：遵循命名规则的标识符
- **长度**：数组元素的个数，必须是**常量**（编译时确定）

### 长度的三种形式

长度可以是以下三种形式之一：

1. **字符常量**
   - 例如：`'a'`（ASCII码值为97）
   - 编译器会将其转换为对应的整数值

2. **整型常量**
   - 例如：`10`、`5`、`100`
   - 最常用的形式

3. **常量表达式**
   - 例如：`1+5`（结果为6）、`2*3`（结果为6）
   - 表达式在编译时计算

### 示例

```cpp
int arr[10];        // 定义一个包含10个整数的数组
char str[26];       // 定义一个包含26个字符的数组
double data[5+5];   // 定义一个包含10个双精度浮点数的数组
```

> **本节小结**：定义数组需要指定三要素：类型、名称、长度。长度必须是编译时常量，不能是变量。这是C++静态数组的重要特点。

## 4. 一维数组的初始化

初始化是指在定义数组时同时给元素赋初值。

### 完全初始化

给数组的**所有元素**都赋初始值。

```cpp
int a[5] = {1, 2, 3, 4, 5};
```

结果：`a[0]=1, a[1]=2, a[2]=3, a[3]=4, a[4]=5`

### 部分初始化

只给数组的**部分元素**赋初始值，**剩余元素自动初始化为0**。

```cpp
int a[5] = {1, 2, 3};
```

结果：`a[0]=1, a[1]=2, a[2]=3, a[3]=0, a[4]=0`

### 重要规则

**初始化值的个数 ≤ 数组长度**

- 如果初始化值个数等于数组长度，为完全初始化
- 如果初始化值个数小于数组长度，为部分初始化
- 如果初始化值个数大于数组长度，编译错误

> **本节小结**：初始化分为完全初始化和部分初始化两种方式。部分初始化时，未指定的元素会自动设为0，这是C++的一个重要特性，可用于快速清零数组。

---

## 5. 特殊初始化 - 全部初始化为0

当需要将数组的所有元素初始化为0时，有两种简便写法。

### 写法一：显式指定0

```cpp
int a[5] = {0};
```

原理：第一个元素显式设为0，剩余元素根据部分初始化规则自动设为0。

### 写法二：空初始化列表

```cpp
int a[5] = {};
```

原理：所有元素都进行值初始化，对于整型来说就是0。

### 两种写法的对比

| 写法 | 示例 | 结果 | 适用范围 |
|------|------|------|----------|
| `{0}` | `int a[5] = {0};` | 全部为0 | C/C++通用 |
| `{}` | `int a[5] = {};` | 全部为0 | C++（C23也支持） |

> **本节小结**：两种写法效果相同，都能快速将数组所有元素初始化为0。推荐使用 `{0}` 写法，因为它的兼容性更好，适用于C和C++。

---

## 6. 特殊初始化 - 省略长度

在初始化时，可以省略数组长度，编译器会根据初始化值的个数自动确定长度。

### 语法格式

```cpp
类型 数组名[] = {值1, 值2, 值3, ...};
```

### 示例

```cpp
int a[] = {1, 2, 3};
```

此时，数组 `a` 的长度自动确定为 **3**（因为提供了3个初始值）。

### 适用场景

- 元素个数已知，且不需要后续修改
- 避免手动计算元素个数，减少出错
- 常用于定义常量数组或配置数组

### 注意事项

- 省略长度**必须**同时进行初始化
- 单独声明 `int a[];` 是错误的（编译器无法确定大小）

> **本节小结**：省略长度是一种便捷的数组定义方式，编译器会根据初始值个数自动推断长度。这避免了手动计数的麻烦，但前提是必须提供初始化列表。

## 7. 数组下标

### 下标的特性

- **从0开始**：数组的第一个元素下标为0，不是1
- **逐一增加**：下标依次为0、1、2、3...

### 下标范围

对于长度为 `n` 的数组，有效下标范围是：`0` 到 `n-1`

| 数组长度 | 有效下标 | 元素个数 |
|----------|----------|----------|
| 5 | 0, 1, 2, 3, 4 | 5个 |
| 10 | 0, 1, 2, ..., 9 | 10个 |
| n | 0, 1, 2, ..., n-1 | n个 |

### 访问数组元素

语法格式：

```cpp
数组名[下标]
```

示例：

```cpp
int a[5] = {10, 20, 30, 40, 50};
// a[0] = 10  （第1个元素）
// a[1] = 20  （第2个元素）
// a[2] = 30  （第3个元素）
// a[3] = 40  （第4个元素）
// a[4] = 50  （第5个元素）
```

> **本节小结**：数组下标从0开始是C/C++的重要约定，这与日常习惯（从1开始计数）不同，初学者需要特别注意。记住：下标为 `i` 的元素是第 `i+1` 个元素。

## 8. 数组越界

### 定义

**数组越界**是指访问数组时，下标超出了数组已分配的边界范围。

### 越界的情况

对于长度为 `n` 的数组：

- **下界越界**：下标 < 0（如 `a[-1]`）
- **上界越界**：下标 ≥ n（如 `a[n]`、`a[n+1]`）

### 示例

```cpp
int a[5] = {1, 2, 3, 4, 5};
// 有效下标：0, 1, 2, 3, 4
// 越界访问：
// a[-1]  // 下界越界
// a[5]   // 上界越界
// a[10]  // 上界越界
```

### 越界的危害

- **程序崩溃**：访问非法内存地址
- **数据错误**：读取或修改了其他变量的值
- **安全隐患**：可能被恶意利用（缓冲区溢出攻击）

### 防范措施

1. 使用循环时，确保循环变量范围正确
2. 访问数组前，检查下标是否在有效范围内
3. 使用更安全的容器（如C++的 `std::vector` 和 `at()` 方法）

> **本节小结**：数组越界是编程中常见的错误，可能导致程序崩溃或数据损坏。务必确保访问数组时下标在有效范围内（0 到 长度-1）。

## 9. 数组长度建议

### 实践建议

在定义数组时，可以**适当增大数组长度**，让长度比实际需要的上限值多几个（通常多5或10）。

### 示例

如果实际需要存储最多10个元素：

```cpp
int a[15];  // 定义15个元素，比上限10多5个
```

### 这样做的好处

1. **防止意外越界**：预留缓冲空间，避免因输入超出预期导致越界
2. **便于扩展**：如果后续需求变化，有足够的空间
3. **减少修改**：不需要频繁修改数组大小

### 示意图

```
int a[15]
├─────────────────────────┤
│  实际使用：10个元素      │ 预留：5个元素 │
│  下标 0-9               │ 下标 10-14    │
└─────────────────────────┘
```

### 注意事项

- 预留空间会占用额外内存，但对于小型数组影响不大
- 如果内存受限（如嵌入式系统），需要权衡空间使用

> **本节小结**：适当预留数组空间是一种防御性编程策略，可以避免因边界判断失误导致的越界错误。多预留5-10个元素是常见的做法。

## 10. 修改数组元素

### 语法格式

```cpp
数组名[下标] = 新值;
```

### 示例

```cpp
int a[5] = {1, 2, 3, 4, 5};

a[4] = 10;  // 将第5个元素的值改为10
// 数组变为：{1, 2, 3, 4, 10}

a[0] = 100; // 将第1个元素的值改为100
// 数组变为：{100, 2, 3, 4, 10}
```

### 操作要点

1. 先通过下标定位到要修改的元素
2. 使用赋值运算符 `=` 给元素赋新值
3. 新值的类型应与数组类型兼容

> **本节小结**：修改数组元素通过"数组名[下标] = 新值"的方式实现。这是数组的基本操作之一，可以随时改变数组中任意元素的值。

## 11. 通过cin修改数组元素

### 语法格式

```cpp
cin >> 数组名[下标];
```

这会从键盘读取一个值，并存入指定下标的数组元素中。

### 示例

```cpp
int a[5];

cin >> a[3];  // 从键盘输入一个整数，存入a[3]
```

如果用户输入 `25`，则 `a[3] = 25`。

### 应用场景

- 用户交互式输入数据
- 批量输入多个元素（配合循环使用）

### 批量输入示例

```cpp
int a[5];
for(int i = 0; i < 5; i++) {
    cin >> a[i];  // 依次输入5个元素
}
```

> **本节小结**：使用 `cin` 可以从键盘接收用户输入并存入数组元素。配合循环使用，可以实现批量输入，这是数组输入的常用方式。

## 12. 连续存放的索引计算

### 问题描述

如果从下标 `i` 开始连续存放 `n` 个元素，最后一个元素的下标是多少？

### 计算公式

```
最后元素的下标 = i + n - 1
```

### 推导过程

- 第1个元素的下标：`i`
- 第2个元素的下标：`i + 1`
- 第3个元素的下标：`i + 2`
- ...
- 第n个元素的下标：`i + (n-1) = i + n - 1`

### 示例

从下标 `2` 开始存放 `4` 个元素：
- 最后元素下标 = 2 + 4 - 1 = **5**
- 占用的下标：2, 3, 4, 5

### 示意图

```
数组：[  ][  ][  ][  ][  ][  ][  ]
下标： 0   1   2   3   4   5   6
               ↑           ↑
              i=2      i+n-1=5
           └─── n=4个元素 ───┘
```

### 常见错误

❌ 错误：最后元素下标 = `i + n`（多算了1个）

✅ 正确：最后元素下标 = `i + n - 1`

> **本节小结**：这是一个容易产生"差一错误"（off-by-one error）的地方。记住公式 `i + n - 1`，理解为什么是减1而不是加1，可以避免循环边界错误。

## 13. 数组元素运算

### 核心概念

数组元素可以像普通变量一样**参与四则运算**（加减乘除）。

### 示例

```cpp
int a[5] = {1, 2, 3, 4, 5};

cout << a[2] + a[4];  // 输出：8（因为 a[2]=3, a[4]=5, 3+5=8）
cout << a[1] * a[3];  // 输出：8（因为 a[1]=2, a[3]=4, 2*4=8）
cout << a[4] - a[0];  // 输出：4（因为 a[4]=5, a[0]=1, 5-1=4）
cout << a[4] / a[1];  // 输出：2（因为 a[4]=5, a[1]=2, 5/2=2，整数除法）
```

### 运算规则

- 数组元素在表达式中作为**操作数**使用
- 运算时取出元素的值进行计算
- 运算结果可以输出、赋值给变量、或存入另一个数组元素

### 应用示例

```cpp
int a[5] = {1, 2, 3, 4, 5};
int sum = a[0] + a[1] + a[2] + a[3] + a[4];  // 求和
int avg = sum / 5;  // 求平均值
```

> **本节小结**：数组元素可以参与各种运算，这使得数组非常适合处理批量数据。通过下标访问元素并参与运算，可以实现求和、求平均、查找最值等常见操作。

## 知识框架梳理

### 核心概念总结

| 概念 | 要点 |
|------|------|
| **数组定义** | 存储同一种数据类型的多个数据的集合 |
| **命名规则** | 字母数字下划线、不能数字开头、不能是关键字、区分大小写 |
| **定义语法** | `类型 数组名[长度];` |
| **初始化** | 完全初始化、部分初始化（剩余为0） |
| **特殊初始化** | `{0}` 或 `{}` 全部清零；省略长度自动推断 |
| **下标** | 从0开始，范围 0 到 长度-1 |
| **越界** | 下标超出边界，导致错误 |
| **修改元素** | `数组名[下标] = 新值;` |
| **输入元素** | `cin >> 数组名[下标];` |
| **元素运算** | 可参与四则运算 |

### 语法速查表

| 操作 | 语法 | 示例 |
|------|------|------|
| 定义数组 | `类型 数组名[长度];` | `int a[10];` |
| 定义并初始化 | `类型 数组名[长度] = {值列表};` | `int a[5] = {1,2,3,4,5};` |
| 全部清零 | `类型 数组名[长度] = {0};` | `int a[10] = {0};` |
| 省略长度 | `类型 数组名[] = {值列表};` | `int a[] = {1,2,3};` |
| 访问元素 | `数组名[下标]` | `a[0]`、`a[3]` |
| 修改元素 | `数组名[下标] = 新值;` | `a[2] = 100;` |
| 输入元素 | `cin >> 数组名[下标];` | `cin >> a[0];` |

### 易错点提醒

1. **下标从0开始**
   - ❌ 错误：认为 `a[1]` 是第一个元素
   - ✅ 正确：`a[0]` 是第一个元素

2. **数组越界**
   - ❌ 错误：访问 `a[n]`（长度为n的数组的第n+1个元素）
   - ✅ 正确：最大下标是 `n-1`

3. **长度必须是常量**
   - ❌ 错误：`int n = 5; int a[n];`（标准C++不支持）
   - ✅ 正确：`const int n = 5; int a[n];` 或 `int a[5];`

4. **部分初始化的剩余元素**
   - ✅ 正确：未指定的元素自动初始化为0

5. **连续存放的索引计算**
   - ❌ 错误：最后下标 = `i + n`
   - ✅ 正确：最后下标 = `i + n - 1`

6. **数组不能整体赋值**
   - ❌ 错误：`int a[5]; a = {1,2,3,4,5};`
   - ✅ 正确：只能在定义时初始化，或逐个元素赋值
