# 字符串函数（一）学习笔记

## 1. 拼接与比较

`string` 最讨人喜欢的地方，就是拼接和比较都能像普通数字一样直接用运算符。

### 用 `+` 拼接、用 `+=` 追加

```cpp
string s1 = "aa", s2 = "bb";

cout << s1 + s2;   // aabb，生成新串，s1、s2 都不变
cout << s2 + s1;   // bbaa，顺序决定结果

s1 += s2;          // s1 变成 aabb，原串被修改
s1 += '!';         // 也可以追加单个字符
```

### `append()` 追加

| 用法 | 作用 |
| ---- | ---- |
| `s1.append(n, 'x')` | 在 `s1` 后拼接 `n` 个字符 `x` |
| `s1.append(s2)` | 将字符串 `s2` 拼接在 `s1` 后面 |

```cpp
string s = "ab";
s.append(3, '-');     // ab---
s.append("cd");       // ab---cd
```

- `append` 能一次追加多个相同字符，这是 `+=` 做不到的

### 用关系运算符比较

```cpp
cout << ("abc" == "abc");   // 1，相等
cout << ("abc" == "def");   // 0，不相等

string a = "apple", b = "banana";
if (a < b) cout << "apple 在前";     // 'a' < 'b'
```

- `string` 支持 `==`、`!=`、`<`、`<=`、`>`、`>=`，结果真为 `1`、假为 `0`
- 比较规则是字典序：**逐字符比 ASCII 值，全部相同则更长者更大**

### 易错点

1. **以为 `+` 会修改原串**：`s1 + s2` 只是算出新值，要保存得写 `s1 = s1 + s2;`
2. **把 `+=` 写成 `=+`**：`s =+ "bb"` 是「赋值一个正号表达式」，语义完全不同
3. **`s.append(3, "x")` 用双引号**：第二个参数必须是字符

> **本节小结**：拼接用 `+`（生成新串）或 `+=`、`append`（修改原串），比较直接用 `==`、`<` 等运算符，规则就是字典序。

## 2. 查找 `find`

`find` 用来在字符串中查找某个字符或子串，返回它**第一次出现的下标**。

### 三种常用格式

| 格式 | 找到时返回 |
| ---- | ---------- |
| `字符串名.find('字符')` | 该字符第一次出现的下标 |
| `字符串名.find("子串")` | 子串**首字符**第一次出现的下标 |
| `字符串名.find(要找的内容, 指定位置下标)` | 从指定下标开始往后找，第一次出现的下标 |

### 代码示例

```cpp
string s = "chxcjsxcbjxcdx";
int i = s.find("xc", 4);
cout << i;        // 6
```

`s` 中的 `xc` 分别出现在下标 **2、6、10**：从下标 4 开始找，跳过前面的 `xc`，第一个满足条件的位置是 6。

### 找不到时：`string::npos`

```cpp
if (s.find("zz") == string::npos) {
    cout << "没找到";
}
```

- `string::npos` 表示「不存在的位置」，值通常为 `-1`
- 判断「是否存在」必须和 `npos` 比较，**不要**写 `if (s.find(x) == -1)`

### 找出所有出现位置

```cpp
string s = "chxcjsxcbjxcdx", t = "xc";
int pos = s.find(t);
while (pos != string::npos) {
    cout << pos << " ";          // 2 6 10
    pos = s.find(t, pos + 1);    // 从下一个位置继续找
}
```

- 每次找到后把起点往后挪，才能继续找后面的
- 若写 `pos = s.find(t, pos)`，位置永远不变，会**死循环**

### 易错点

1. **`find` 找不到时直接当下标用**：`s[s.find("zz")]` 会越界崩溃
2. **起点写成 `pos` 导致死循环**：应写 `pos + 1`（或 `pos + t.size()` 表示不重叠）
3. **把返回值直接和 `-1` 比**：用 `string::npos` 更规范

> **本节小结**：`find` 返回第一次出现的下标，第二个参数可以指定起点；找不到返回 `string::npos`，循环找全部位置时起点必须往后推。

## 3. 截取 `substr`

`substr` 从原字符串中**复制出一段**，生成一个新的 `string`，原串不变。

### 语法格式

| 格式 | 作用 |
| ---- | ---- |
| `字符串名.substr(pos, len)` | 截取从下标 `pos` 开始、长度为 `len` 的一段 |
| `字符串名.substr(pos)` | 截取从下标 `pos` 开始到末尾的所有字符 |

```cpp
string s = "hello world";

cout << s.substr(0, 5);    // hello —— 前 5 个字符
cout << s.substr(6);       // world —— 从下标 6 到末尾
cout << s.substr(6, 3);    // wor   —— 从下标 6 开始取 3 个
```

- 第一个参数是**起点下标**，第二个参数是**要取几个字符**
- 第二个参数不是「结束下标」，`substr(2, 3)` 取的是下标 2、3、4 三个字符

### 常见应用

按位置切分：`d.substr(0, 4)` 在 `d = "2026-11-20"` 时得到 `2026`。配合 `find` 还能截取两段之间：`s.substr(p + 1, s.find(';') - p - 1)`。

### 易错点

1. **把第二个参数当成结束下标**：`substr(2, 5)` 是「从 2 开始取 5 个」
2. **`len` 超出剩余长度**：会自动截到末尾，不报错，但结果可能不是你要的
3. **`pos` 超出字符串长度**：会抛异常导致崩溃，调用前先确认 `pos <= s.size()`

> **本节小结**：`substr(pos, len)` 从下标 `pos` 开始取 `len` 个字符，`substr(pos)` 取到末尾；参数是「起点 + 个数」，不是「起点 + 终点」。

## 4. 插入与替换

在指定位置「插进去」用 `insert`，「换掉一段」用 `replace`，「删掉一段」用 `erase`。

### 插入 `insert`

| 用法 | 作用 |
| ---- | ---- |
| `字符串名.insert(pos, n, '字符')` | 在下标 `pos` 处插入 `n` 个相同字符 |
| `字符串名.insert(pos, "字符串")` | 在下标 `pos` 处插入一个字符串 |

```cpp
string s = "helloworld";
s.insert(5, "-");          // hello-world
s.insert(0, ">> ");        // >> hello-world
```

- 插入后，原下标 `pos` 及其后的字符**整体后移**，`pos` 可以等于 `s.size()`

### 替换 `replace`

| 用法 | 作用 |
| ---- | ---- |
| `字符串名.replace(pos, len, "字符串")` | 用字符串替换从 `pos` 开始的 `len` 个字符 |
| `字符串名.replace(pos, len, n, '字符')` | 用 `n` 个字符替换从 `pos` 开始的 `len` 个字符 |

```cpp
string s = "helloworld";
s.replace(0, 5, "HELLO");     // HELLOworld
s.replace(5, 5, " C++");      // HELLO C++
```

- 前两个参数描述「**要换掉的那一段**」：起点 `pos` 与长度 `len`
- 后面的参数是「**换成什么**」，新旧长度不必相等

### 删除 `erase`

| 用法 | 作用 |
| ---- | ---- |
| `字符串名.erase(pos, len)` | 删除从下标 `pos` 开始、个数为 `len` 的字符 |
| `字符串名.erase(pos)` | 删除从下标 `pos` 开始的所有字符 |

```cpp
string s = "hello world";
s.erase(5, 1);     // helloworld
s.erase(5);        // hello
```

### 综合示例：删掉句子里的所有空格

```cpp
string s = "a b c d";
for (int i = 0; i < (int)s.size(); i++) {
    if (s[i] == ' ') { s.erase(i, 1); i--; }   // 删除后字符前移，下标要回退
}
```

`erase` 之后原来下标 `i + 1` 的字符会移到 `i`，不写 `i--` 就会漏删连续的空格。

### 易错点

1. **`replace` 的第二个参数当成「替换后的长度」**：它是「被替换掉的长度」
2. **`insert` / `erase` 后沿用旧的 `size()`**：长度已改变，循环条件要重新判断
3. **`pos` 超范围**：三个函数的 `pos` 都必须 `<= s.size()`
4. **循环删除时下标不调整**：删除后必须 `i--` 或改成反向遍历

> **本节小结**：`insert(pos, …)` 插入、`replace(pos, len, …)` 换掉一段、`erase(pos, len)` 删掉一段；三者都会改变长度，循环中删除后记得调整下标。

## 知识框架梳理

### 核心概念总结

- **拼接**：`+` 生成新串、`+=` 修改原串、`append(n, 'x')` 追加多个相同字符
- **比较**：直接用 `==`、`!=`、`<`、`>` 等，按字典序逐字符比较
- **查找**：`find` 返回第一次出现的下标，找不到返回 `string::npos`
- **截取**：`substr(pos, len)` 起点 + 个数，`substr(pos)` 取到末尾
- **插入替换**：`insert` 插入、`replace` 替换一段、`erase` 删除一段，参数都是「起点 + 长度」

### 语法速查表

| 用途 | 写法 | 示例 |
| ---- | ---- | ---- |
| 拼接（新串） | `s1 + s2` | `"aa" + "bb"` |
| 追加（改原串） | `s += x;` | `s += "bb";` |
| 追加 n 个字符 | `s.append(n, 'x')` | `s.append(3, '-')` |
| 字典序比较 | `s1 < s2` | `"apple" < "banana"` |
| 查找字符 / 子串 | `s.find(x)` | 返回下标 |
| 指定起点查找 | `s.find("xc", 4)` | 从下标 4 开始 |
| 未找到判断 | `s.find(x) == string::npos` | 存在性判断 |
| 截取一段 | `s.substr(pos, len)` | `s.substr(0, 5)` |
| 截取到末尾 | `s.substr(pos)` | `s.substr(6)` |
| 插入 | `s.insert(pos, "str")` | 插入一段文本 |
| 替换一段 | `s.replace(pos, len, "str")` | 换掉 len 个字符 |
| 删除一段 | `s.erase(pos, len)` | 删除 len 个字符 |

### 易错点提醒

1. **`substr` / `replace` 的参数含义**：第二个参数是**长度**，不是结束下标
2. **`find` 结果不判断就当下标用**：找不到是 `npos`，会越界
3. **循环查找起点不推进**：`s.find(t, pos + 1)`，否则死循环
4. **`erase` 后不调整下标**：字符前移，循环里要 `i--`
5. **`append(n, "x")` 用双引号**：第二个参数必须是字符 `'x'`
6. **把 `+` 当成修改原串**：需要保存结果就写 `s = s + t;` 或直接用 `+=`

> **本节小结**：`+`/`+=` 负责拼接、关系运算符负责比较、`find` 负责定位、`substr` 负责截取、`insert`/`replace`/`erase` 负责增删改；记牢「起点 + 长度」这个统一套路，字符串操作就有章可循。
