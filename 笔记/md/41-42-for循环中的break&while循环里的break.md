# break 语句学习笔记

## 1. break 的作用

**break** 是 C++ 的一个跳转关键字，作用是**立即结束当前所在的循环**，程序接着执行循环后面的第一条语句。它与 `if` 搭配使用：`if` 负责"什么时候该走"，`break` 负责"走"。

### 核心概念

- `break` 只能出现在**循环体内**（`for`、`while`、`do-while`）或 `switch` 语句中
- 执行到 `break` 时，循环**立刻停止**，条件判断、步进 `i++` 都不再执行
- 循环之后的代码照常运行，所以准确说法是"结束循环"而不是"结束程序"

### 语法格式

```cpp
for (int i = 1; i <= 10; i++) {
    if (条件) {
        break;        // 立刻跳出这个 for
    }
    // break 之后的循环体代码不再执行
}
// 程序从这里继续
```

`break` 几乎从不单独出现，标准写法是"`if (条件) { break; }`"。没有 `if` 的 `break` 会让循环只跑第一轮就结束，通常不是想要的效果。

### 易错点

1. **`break` 写在 `if` 外面** —— 循环第一轮就结束，等于没循环
2. **以为 `break` 会结束整个程序** —— 它只结束当前这一层循环，`main` 后面的代码继续执行
3. **在循环外用 `break`** —— 编译报错，`break` 不能出现在循环和 `switch` 之外
4. **漏写 `break` 后的分号** —— `break` 是一条语句，必须写 `break;`

> **本节小结**：`break` 的唯一作用是"立刻结束当前循环"，标准用法是 `if (条件) { break; }`，跳出后程序从循环的下一条语句继续执行。

## 2. for 中的 break

### 核心概念

在 `for` 循环里，`break` 一旦执行，剩下的**循环体、步进表达式 `i++`、条件判断**全部被跳过，直接跳到循环之后。

### 代码示例

```cpp
#include <iostream>
using namespace std;

int main()
{
    for (int i = 1; i <= 10; i++) {
        cout << i << endl;
        if (i == 3) {
            break;
        }
    }
    return 0;
}
```

输出 `1`、`2`、`3`，每行一个 —— 第 4 轮根本没有开始。

### 执行过程拆解

| 轮次 | `i` | 输出 | 判断 `i == 3` | 后续 |
| ---- | --- | ---- | ------------- | ---- |
| 1 | 1 | 1 | 假 | 继续，`i` 变 2 |
| 2 | 2 | 2 | 假 | 继续，`i` 变 3 |
| 3 | 3 | 3 | 真 | **break，循环结束** |

注意第 3 轮的 `i++` 没有执行，但这对结果没有影响 —— 因为循环已经结束了。如果 `break` 之后还要用 `i` 的值，它停在触发 `break` 的那一轮。

### 输出位置决定结果

`cout` 在 `if` 之前还是之后，结果完全不同：

```cpp
// 写法 A：先输出再判断 → 输出 1 2 3
cout << i << endl;
if (i == 3) break;

// 写法 B：先判断再输出 → 输出 1 2
if (i == 3) break;
cout << i << endl;
```

### 易错点

1. **把 `break` 写成 `continue`** —— `continue` 只跳过本轮，循环还会继续
2. **`break` 后还写了代码** —— 同一轮里 `break` 之后的语句永远不会执行
3. **以为 `break` 会把 `i` 清零** —— `i` 保持触发时的值
4. **在 `if` 后漏写花括号** —— `if (i == 3) break;` 只带一条语句时可以省，但风格上建议都写

> **本节小结**：`for` 中的 `break` 会跳过剩余循环体、步进与条件判断，直接结束循环；输出语句放在 `break` 之前还是之后，结果会差一个数。

## 3. while 中的 break

### 核心概念

`while` 循环里 `break` 的作用与 `for` 完全一致 —— 立即结束当前循环。但 `while` 常用来写"次数未知"的循环，此时 `break` 往往承担**退出条件的职责**。

### 语法格式：条件写在循环里

```cpp
while (true) {           // 条件恒真，靠 break 退出
    // 读取数据或计算
    if (退出条件) {
        break;
    }
    // 正常处理
}
```

`while (true)` 是**无限循环**（infinite loop）的标准写法，必须有 `break` 兜底，否则程序永远停不下来。

### 代码示例：累加到超过 100 为止

```cpp
#include <iostream>
using namespace std;

int main()
{
    int sum = 0, i = 1;
    while (true) {
        sum += i;
        if (sum > 100) {
            break;         // 超过 100 就停
        }
        i++;
    }
    cout << "加到 " << i << " 时 sum = " << sum << endl;
    return 0;
}
```

输出 `加到 14 时 sum = 105`。

### 代码示例：读到 0 为止

```cpp
int x, sum = 0;
while (cin >> x) {         // 读不到数据时退出
    if (x == 0) break;     // 读到 0 提前结束
    sum += x;
}
```

这里有两个出口：`cin >> x` 失败时循环自然结束，读到哨兵值 `0` 时靠 `break` 提前结束。

### for 与 while 中 break 的对比

| 对比项 | `for` 中的 `break` | `while` 中的 `break` |
| ------ | ------------------ | -------------------- |
| 作用 | 结束当前循环 | 结束当前循环 |
| 跳过的内容 | 剩余循环体 + `i++` + 条件判断 | 剩余循环体 + 条件判断 |
| 常见场景 | 次数已知，中途满足条件就停 | 次数未知，靠 `break` 退出 |
| 风险 | 误写导致提前结束 | 忘记写 `break` 导致死循环 |

### 易错点

1. **`while (true)` 里没有 `break`** —— 死循环，程序卡住不结束
2. **`break` 的条件永远不成立** —— 等价于没有 `break`，同样死循环
3. **变量没在循环内更新** —— `i++` 漏写，`sum` 不再变化，`break` 条件永远为假
4. **把 `while` 的条件和 `break` 条件写重复** —— 逻辑冗余，容易互相矛盾

> **本节小结**：`while` 中的 `break` 与 `for` 中作用相同，但它常被用来给 `while (true)` 这类无限循环提供唯一出口，写完必须确认 `break` 的条件真能成立。

## 4. 提前终止与效率

### 核心概念

**提前终止**（early termination）指在循环还没走完所有轮次时就退出。它不只是写法问题，更是**效率优化**手段：一旦已经知道答案，继续算下去纯属浪费。

### 典型场景：判断素数

判断 `n` 是否为素数，只要找到一个能整除它的数，就可以立刻下结论"不是素数"，后面的除法全都不必做。

```cpp
bool isPrime = true;
for (int i = 2; i < n; i++) {
    if (n % i == 0) {
        isPrime = false;
        break;                 // 找到一个因子就够，立即停
    }
}
```

如果不写 `break`，循环会一直跑到 `i = n - 1`，做了大量无用判断。

### 典型场景：找第一个满足条件的数

```cpp
int ans = -1;
for (int i = 1; i <= n; i++) {
    if (i * i > n) { ans = i; break; }   // 找到第一个就停
}
```

### 效率对比

| 写法 | 循环次数（`n = 1000`，因子为 2 时） | 说明 |
| ---- | ---------------------------------- | ---- |
| 有 `break` | 1 次 | 找到因子立即退出 |
| 无 `break` | 998 次 | 白跑到底，结果相同 |

`break` 不改变结果，只减少无意义的计算量。

有时 `break` 之后还需要知道"是怎么出来的"，这时用一个**标记变量**（flag）记录：进入循环前 `bool found = false;`，找到目标时 `found = true;` 再 `break;`，循环结束后靠 `if (found)` 判断。

### 易错点

1. **以为 `break` 能跳出多层嵌套循环** —— 它只跳出**最内层**一层
2. **在需要统计全部结果时用了 `break`** —— 只统计到第一个就停了
3. **`break` 之后又依赖循环变量的终值** —— 此时 `i` 是触发值，不是终止值
4. **`while (true)` 忘写 `break` 又忘了改条件** —— 程序假死，务必自查

> **本节小结**：提前终止是"已知答案就不再计算"的效率手段，最典型的是素数判断里一旦找到因子就 `break`，但要记住它只跳出最内层一层循环。

## 知识框架梳理

### 核心概念总结

- **作用**：`break` 立即结束当前所在的循环，程序接着执行循环之后的语句
- **搭配**：几乎总是写成 `if (条件) { break; }`
- **跳过的内容**：剩余循环体、步进表达式、条件判断
- **适用范围**：`for`、`while`、`do-while` 循环体内，以及 `switch`
- **只跳一层**：嵌套循环中 `break` 只结束最内层

### 语法速查表

| 用途 | 写法 |
| ---- | ---- |
| 基本跳出 | `break;` |
| 条件跳出 | `if (条件) { break; }` |
| 无限循环骨架 | `while (true) { ...; if (条件) break; }` |
| 记录是否跳出 | `bool found = false; ... found = true; break;` |

### 易错点提醒

1. **写成 `continue`**：`continue` 只跳过本轮，`break` 才结束整个循环
2. **`break` 写在 `if` 外**：循环第一轮就结束
3. **`while (true)` 没出口**：忘记 `break` 或条件永不成立 → 死循环
4. **`break` 后还有代码**：同一轮中 `break` 后面的语句不会执行
5. **误以为能跳出多层**：嵌套循环中只结束最内层

> **本节小结**：`break` 是循环的"紧急出口" —— `if` 给条件、`break` 立刻收工，跳出后只结束当前一层，用好了既能简化逻辑又能提前终止省下大量无用计算。
