# 字符数组学习笔记

## 1. 字符数组的定义

字符数组（character array）是**元素类型为 `char` 的数组**，每一个位置存放一个字符。

### 核心概念

- 数组的每个元素都是一个字符，书写时用**单引号**包裹，如 `'a'`、`'1'`、`' '`
- 字符在内存中按 ASCII 码（American Standard Code for Information Interchange，美国信息交换标准代码）存放，一个字符占 **1 个字节**
- 字符数组是 C++ 中保存字符串最原始的方式：**一串字符 + 结尾的 `\0`**，就是 C 风格字符串（C-style string）

### 语法格式

```cpp
char 数组名[数组长度];
```

| 部分 | 含义 |
| ---- | ---- |
| `char` | 元素类型，表示每个元素是一个字符 |
| 数组名 | 遵循标识符命名规则，如 `s`、`str`、`word` |
| 数组长度 | 最多能放多少个字符，必须是编译时确定的常量 |

### 字符与字符串的区别

| 写法 | 名称 | 引号 | 占用空间 | 说明 |
| ---- | ---- | ---- | -------- | ---- |
| `'a'` | 字符（character） | 单引号 | 1 字节 | 就是一个字符 |
| `"a"` | 字符串（string） | 双引号 | 2 字节 | 字符 `a` 加上结尾的 `\0` |

> **本节小结**：字符数组就是元素类型为 `char` 的数组，一个位置存一个字符；单引号是字符、双引号是字符串，这是后面一切字符串操作的地基。

## 2. 字符数组的初始化

初始化指在**定义数组的同时**给元素赋初值。字符数组有三种常见写法。

### 写法一：逐个字符初始化

```cpp
char a[7] = {'c', 'h', 'a', 'r'};
```

- 只给了 4 个初值，数组长度是 7，属于**部分初始化**
- 剩下的 `a[4]` 到 `a[6]` 会被自动填成 `\0`
- 适合只保存若干个字符、不当作字符串使用的场景

### 写法二：用字符串常量初始化

```cpp
char a[7] = "char";
```

- 双引号中的每个字符依次放入数组，编译器**自动在末尾补一个 `\0`**
- 实际占用 5 个位置：`c`、`h`、`a`、`r`、`\0`，剩余位置仍为 `\0`
- 这种数组可以直接当成字符串整体输出

### 写法三：省略长度

```cpp
char a[] = "char";   // 长度自动确定为 5
```

- 编译器按「字符个数 + 1 个 `\0`」推断长度
- 省略长度时**必须同时初始化**，否则编译器无法确定大小

### 三种写法对比

| 写法 | 示例 | 数组长度 | 是否含 `\0` | 能否整体输出 |
| ---- | ---- | -------- | ----------- | ------------ |
| 逐个字符，未写满 | `char a[7] = {'c','h','a','r'};` | 7 | 剩余位置自动为 `\0` | 可以 |
| 逐个字符，正好写满 | `char a[4] = {'c','h','a','r'};` | 4 | 没有 `\0` | 不可以，会越界 |
| 字符串常量 | `char a[7] = "char";` | 7 | 自动补 1 个 | 可以 |

### 整体输入输出

字符数组名可以直接交给 `cin` 和 `cout`，不需要写循环：

```cpp
char a[7];
cin >> a;    // 从键盘读入一个单词，自动在末尾补 '\0'
cout << a;   // 从开头一直输出到 '\0' 为止
```

- `cin >> a` 遇到**空格、换行**就停止，因此只能读入不含空格的单词
- `cout << a` 输出的是「字符序列」，而不是数组的地址

### 易错点

1. `char a[4] = {'c','h','a','r'};` **没有** `\0`，用 `cout << a` 会一直往后读，输出乱码
2. `char a[4] = "char";` 长度不够（需要 5 个位置），编译报错或行为异常
3. 字符 `'1'` 与数字 `1` 不同：`'1'` 的 ASCII 值是 49，数字 `1` 就是 1
4. 数组**不能整体赋值**：`a = "hi";` 是错的，只能在定义时初始化，或逐个元素赋值

> **本节小结**：字符数组可以用花括号逐个字符初始化，也可以用双引号整体初始化（自动补 `\0`）；不管哪种写法，都要给 `\0` 留出位置。

## 3. 字符串结束符 `\0`

### 核心概念

`\0` 叫**字符串结束符**（null character，空字符），它的 ASCII 值是 **0**，写作 `'\0'`。

它本身不是可见字符，作用只有一个：**告诉程序「字符串到这里结束」**。

### 为什么必须有 `\0`

`cout`、`strlen` 等函数并不知道数组有多长，它们靠**从头扫描、遇到 `\0` 停下**来确定字符串的边界。

```cpp
char a[8] = "char";
// 内存内容： c  h  a  r  \0  \0  \0  \0
// 下标：     0  1  2  3  4   5   6   7
```

- 有效字符串是 `"char"`，长度 4
- 但从下标 4 开始到 7 全是 `\0`，所以输出不会越界

### 长度的设置规则

创建字符数组保存字符串时，**数组长度要比字符串的最大长度多留 1 个位置给 `\0`**。

实际刷题时，一般把长度设成**字符串最大长度 + 5**，多留几个位置更保险：

| 题目规定 | 建议数组长度 | 说明 |
| -------- | ------------ | ---- |
| 长度不超过 10 | 15 | 10 + 5 |
| 长度不超过 100 | 105 | 100 + 5 |
| 长度不超过 1000 | 1005 | 1000 + 5 |

```cpp
// 题目说输入的字符串长度不超过 1000
char s[1005];
```

### 手动补 `\0`

如果用循环一个个往里填字符，必须自己补上结束符：

```cpp
char s[10];
int n = 0;
s[n++] = 'h';
s[n++] = 'i';
s[n] = '\0';   // 手动结束，否则 cout 会读到脏数据
cout << s;     // 输出 hi
```

### 易错点

1. **长度没留够**：`char s[5] = "hello";` 需要 6 个位置，越界
2. **忘记补 `\0`**：用循环填入字符后输出，尾部出现乱码
3. **把 `'\0'` 和 `'0'` 搞混**：`'\0'` 的 ASCII 是 0，`'0'` 的 ASCII 是 48，完全不同
4. **把 `\0` 写成 `\O` 或 `/0`**：`\0` 中间是数字零，不是字母 `O`，反斜杠方向也不能错

> **本节小结**：`\0` 是字符串的「终止信号」，ASCII 值为 0，占一个位置；定义字符数组时长度一定要比最长字符串多留位置，忘了它就是乱码的根源。

## 4. 字符数组的遍历

遍历就是**依次访问数组中的每一个字符**。字符数组有两种常用的遍历方式。

### 方式一：以 `\0` 为结束条件

不知道字符串有多长时，最稳妥的写法是「遇到 `\0` 就停」：

```cpp
char s[105];
cin >> s;

for (int i = 0; s[i] != '\0'; i++) {
    cout << s[i] << " ";
}
```

- 循环条件直接判断当前字符是不是结束符
- 不需要提前知道长度，读入多长就遍历多长
- 条件写 `s[i] != '\0'`，也可以简写成 `s[i]`

### 方式二：按已知长度遍历

如果数组里存的是**固定个数的字符**（不是字符串），就按长度遍历：

```cpp
char a[5] = {'a', 'b', 'c', 'd', 'e'};
for (int i = 0; i < 5; i++) {
    cout << a[i];
}
```

### 遍历能做什么

```cpp
// 1. 逐字符输出，用空格隔开
for (int i = 0; s[i] != '\0'; i++) cout << s[i] << " ";
cout << endl;

// 2. 统计某个字符出现次数
int cnt = 0;
for (int i = 0; s[i] != '\0'; i++) {
    if (s[i] == 'a') cnt++;
}
cout << cnt;
```

### 易错点

1. **循环条件写成 `i <= len`**：会多访问一个位置（正好是 `\0`），数组写满时就越界
2. **在循环体内修改 `s[i]` 后忘记结束符**：把 `\0` 改掉了，后续输出会读到垃圾数据
3. **混用两种方式**：数组里没有 `\0`（逐个字符写满）却用 `s[i] != '\0'` 判断，会越界
4. **长度靠 `strlen` 求**：需要包含 `<cstring>` 头文件，这是下一课的内容

> **本节小结**：遍历字符数组要么「以 `\0` 为界」，要么「按已知长度循环」；日常处理字符串优先用前者，注意循环边界不要碰到结束符之后的位置。

## 知识框架梳理

### 核心概念总结

- **字符数组**：元素类型为 `char` 的数组，一个位置存一个字符，字符按 ASCII 码存放
- **字符与字符串**：`'a'` 是字符（1 字节），`"a"` 是字符串（2 字节，含 `\0`）
- **初始化**：逐个字符用花括号，或直接用双引号，后者自动补 `\0`
- **结束符 `\0`**：ASCII 值为 0，标记字符串结尾，占 1 个位置
- **长度设置**：字符串最大长度 + 5，其中至少 1 个位置留给 `\0`
- **遍历**：以 `\0` 为结束条件，或按已知长度循环

### 语法速查表

| 用途 | 写法 |
| ---- | ---- |
| 定义字符数组 | `char a[105];` |
| 逐个字符初始化 | `char a[7] = {'c','h','a','r'};` |
| 字符串常量初始化 | `char a[7] = "char";` |
| 省略长度初始化 | `char a[] = "char";` |
| 整体读入（不含空格） | `cin >> a;` |
| 整体输出 | `cout << a;` |
| 手动补结束符 | `s[n] = '\0';` |
| 以结束符为条件遍历 | `for (int i = 0; s[i] != '\0'; i++)` |
| 按长度遍历 | `for (int i = 0; i < n; i++)` |

### 易错点提醒

1. **忘留 `\0` 的位置**：`char s[5] = "hello";` 越界，应为 `char s[6];`
2. **写满却不补 `\0`**：`char a[4] = {'c','h','a','r'};` 整体输出必然乱码
3. **`'\0'` 与 `'0'` 混淆**：前者 ASCII 为 0，后者为 48
4. **`cin >> a` 读不到空格后的内容**：需要读整行时用 `cin.getline`，下一课会讲
5. **数组不能整体赋值**：`a = "hi";` 非法，只能在定义时初始化或逐元素赋值
6. **循环边界差一**：以 `\0` 为条件时不要写成 `i <= len`，否则跨过结束符

> **本节小结**：牢记「字符数组 = 一串字符 + 一个 `\0`」，定义时多留位置、遍历时以 `\0` 为界，字符数组就不会出乱子。
