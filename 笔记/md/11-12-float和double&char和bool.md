# 浮点类型与字符类型学习笔记

## 1. 浮点类型 float 与 double

带小数点的数在 C++ 里叫**浮点数**（floating-point number），它有两种基本类型：`float` 和 `double`。

### 核心概念

- `float` 是**单精度**浮点型（single precision），占 4 字节
- `double` 是**双精度**浮点型（double precision），占 8 字节
- 计算机内浮点数的**默认类型是 `double`**：代码里直接写 `2.3333`，编译器就当成 `double`
- 有效位数越多，能准确表示的数就越精细

| 浮点数类型 | 有效位数 |
| ---- | ---- |
| `float` | 约为 7 位 |
| `double` | 约为 15 位（推荐） |

### 代码示例

```cpp
float  f = 3.14159;
double d = 3.141592653589793;

cout << f << endl;    // 3.14159
cout << d << endl;    // 3.14159，默认只显示 6 位有效数字
```

`cout` 默认只显示 6 位有效数字，想看更多位必须借助第 3 节的精度函数。

### 易错点

1. 随便用 `float` —— 它只有约 7 位有效数字，算分数很容易失真
2. 以为 `double` 能存无限精度 —— 它也只有约 15 位
3. 把 `2.3333` 当成 `float` —— 不加后缀的小数字面量默认是 `double`

> **本节小结**：浮点数分 `float`（约 7 位有效数字）和 `double`（约 15 位）两种，默认类型是 `double`，实际编程中优先用 `double`。

## 2. 精度与有效位数

### 核心概念

有效数字指一个数值中包含的用于**精确表达**的数字，即**从该数值最左边的第一个非零数字起，直到末尾的所有数字**：开头用来占位的 `0` **不算**，末尾的 `0` **算**（它表示精度）；只有在有效位数上的数值才能被**准确表示**。

| 数值 | 从哪里开始数 | 有效位数 |
| ---- | ---- | ---- |
| `0.06300` | 从 `6` 开始，数 `6`、`3`、`0`、`0` | 4 位 |
| `1012306` | 从 `1` 开始，数完全部 7 个数字 | 7 位 |

### 代码示例

```cpp
float f = 1.23456789;                        // 只保留约 7 位有效数字
cout << fixed << setprecision(9) << f;       // 1.234567881，后面已经不准
```

### 易错点

1. 把开头的 `0` 也算进去 —— `0.06300` 是 4 位而不是 6 位
2. 忽略末尾的 `0` —— 末尾的 `0` 是有效数字，代表精度
3. 用 `float` 做高精度计算 —— 7 位有效数字很容易不够用

> **本节小结**：有效数字从最左边第一个非零数字数到末尾，开头占位 `0` 不算、末尾 `0` 算。`float` 约 7 位、`double` 约 15 位，超出范围的部分不可靠。

## 3. 保留小数位数

输出小数时常要控制位数，C++ 用 `<iomanip>` 头文件里的**精度函数**（manipulator）实现。

### 核心概念

- 头文件：`#include <iomanip>`，iomanip 是 input/output manipulators 的缩写
- `setprecision(n)` 单独使用时，控制的是**有效数字**位数
- `fixed << setprecision(n)` 组合使用时，控制的是**小数位数**，这是最常用的写法

| 情况 | 处理方式 |
| ---- | ---- |
| 数据长度**不足**保留位数 | 补零填位，如保留 2 位时 `5.0` 输出 `5.00` |
| 数据长度**长于**保留位数 | 多余位数遵照**四舍五入**原则舍去 |

### 代码示例

```cpp
#include <iomanip>          // 精度函数所在头文件

cout << setprecision(3) << 2.3333 << endl;            // 2.33，3 位有效数字
cout << fixed << setprecision(3) << 2.3333 << endl;   // 2.333，3 位小数
cout << fixed << setprecision(2) << 3.14159 << endl;  // 3.14，四舍五入
cout << fixed << setprecision(2) << 5.0 << endl;      // 5.00，补零填位
```

`fixed` 和 `setprecision` 一旦设置，会对**后面所有输出**持续生效，不是只影响紧接着的那一个数。

### 易错点

1. 忘记 `#include <iomanip>` —— `setprecision` 未定义，编译报错
2. 只写 `setprecision(3)` 就以为在控制小数位 —— 它控制的是有效数字
3. 以为设置只影响一个数 —— 实际上会持续生效

> **本节小结**：控制小数位数要写 `fixed << setprecision(n)`，只写 `setprecision(n)` 控制的是有效数字。位数不足补零，位数过多四舍五入，而且设置对后续输出持续生效。

## 4. char 与字符输出

**字符型** `char` 用来存放单个字符，它的字面量有几个显著特点。

### 核心概念

- `char` 的值要包在**成对的英文单引号**里
- 单引号里**只有一个英文字符**，合法的例子：`'A'`、`'a'`、`'@'`、`'1'`
- `char` 占 1 字节，存的是这个字符对应的编码
- 引号必须是英文半角，打成中文全角引号会编译报错

### 代码示例

```cpp
char c1 = 'A', c2 = 'a', c3 = '@', c4 = '1';

cout << c1 << endl;        // A
cout << c2 << endl;        // a
cout << c3 << endl;        // @
cout << c4 << endl;        // 1
cout << c1 << c2 << c3;    // Aa@
```

### 单引号与双引号的区别

`'A'` 是 `char`，单个字符占 1 字节；`"A"` 是字符串（string），末尾还藏着结束符。两者用 `cout` 输出看起来一样，但类型完全不同，`char` 变量只能用单引号赋值。

### 易错点

1. 用双引号给 `char` 赋值 —— `char c = "A";` 编译报错
2. 单引号里塞多个字符 —— `'AB'` 不是合法字符
3. 在单引号里写中文 —— 一个汉字占多个字节，装不进一个 `char`

> **本节小结**：`char` 存单个字符，值要用成对的英文单引号包起来，引号内只能有一个英文字符。双引号包起来的是字符串，不能赋给 `char`。

## 5. bool 与逻辑值

**布尔类型** `bool` 专门表示「真」和「假」这两种状态。

### 核心概念

`bool` 只有两个取值，且 `true`、`false` 是关键字，**不能加引号**：

| 含义 | 关键字 | 输出结果 |
| ---- | ---- | ---- |
| 真 | `true` | `1` |
| 假 | `false` | `0` |

赋值时会自动转换：赋 `0` 得到 `false`，赋**任何非 0 值**都得到 `true`。

### 代码示例

```cpp
bool flag1 = true, flag2 = false;

cout << flag1 << endl;                // 1
cout << flag2 << endl;                // 0
cout << boolalpha << flag1 << endl;   // true，按文字形式输出

bool a = 0, b = 5, c = -3;            // 依次是 false、true、true
```

默认输出 `1` 和 `0`，加上 `boolalpha` 之后才会输出 `true` 和 `false`。

### 易错点

1. 给 `true` 加引号 —— `bool b = "true";` 是错的，它是关键字
2. 以为 `bool` 具体记录了数字 —— 赋非 0 值一律变成 `true`
3. 想输出 `true` 却得到 `1` —— 需要加 `boolalpha`

> **本节小结**：`bool` 只有 `true` 和 `false`，默认输出为 `1` 和 `0`，加 `boolalpha` 才输出文字。赋 `0` 得假，赋任何非 0 值都得真。

## 6. 四种基本类型对比与选用

学完这几种类型，用一张总表把它们串起来。

### 类型对比

| 分类 | 关键字 | 字节 | 示例 | 典型用途 |
| ---- | ---- | ---- | ---- | ---- |
| 整数类型 | `int` | 4 | `100` | 常用整数，10 位以内 |
| 整数类型 | `long long` | 8 | `123456789012345` | 超出 10 位数 |
| 小数类型 | `double` | 8 | `3.14159` | 一般小数计算 |
| 字符类型 | `char` | 1 | `'A'` | 单个字符，加一对英文单引号 |
| 布尔类型 | `bool` | 1 | `true` | `0` 还是 `0`，非 `0` 都是 `1` |

### 选用建议

1. **整数**优先用 `int`，超过 10 位换 `long long`
2. **小数**优先用 `double`，不用 `float`
3. **单个字符**用 `char`，值加单引号
4. **真假状态**用 `bool`，不加引号
5. 拿不准时先想清楚「要存的是整数、小数、字符还是真假」

### 综合输出示例

```cpp
cout << fixed << setprecision(2);
cout << 100 << endl;          // 100
cout << 3.14159 << endl;      // 3.14
cout << 'A' << endl;          // A
cout << true << endl;         // 1
```

### 易错点

1. 用 `int` 存小数 —— 小数部分被直接截掉
2. 用 `char` 存字符串 —— `char` 只能存一个字符
3. 用 `double` 存整数编号 —— 输出会带 `.00`，不合适

> **本节小结**：整数用 `int` / `long long`，小数用 `double`，字符用 `char`（加单引号），真假用 `bool`。选类型的顺序是先判断数据属于哪一类，再看数值范围。

## 知识框架梳理

### 核心概念总结

- **浮点数与有效数字**：`float` 约 7 位、`double` 约 15 位，默认类型是 `double`；有效数字从最左第一个非零数字数到末尾，开头占位 `0` 不算、末尾 `0` 算
- **精度函数**：`fixed << setprecision(n)` 控制小数位，只写 `setprecision(n)` 控制有效数字
- **保留规则**：位数不足补零，位数过多四舍五入，设置持续生效
- **`char`**：存单个字符，用成对英文单引号，单引号内只有一个英文字符
- **`bool`**：只有 `true`（1）和 `false`（0），非 0 赋值都得真
- **类型选用**：整数 `int`/`long long`、小数 `double`、字符 `char`、真假 `bool`

### 语法速查表

| 用途 | 写法 | 示例 |
| ---- | ---- | ---- |
| 定义浮点数 | `double 变量名 = 小数;` | `double pi = 3.14;` |
| 引入精度函数 | `#include <iomanip>` | 放在头文件区 |
| 保留有效数字 | `cout << setprecision(n)` | `setprecision(3) << 2.3333` 得 `2.33` |
| 保留小数位数 | `cout << fixed << setprecision(n)` | 同上得 `2.333` |
| 定义字符 | `char 变量名 = '字符';` | `char c = 'A';` |
| 输出字符 | `cout << 字符变量;` | `cout << c;` 得 `A` |
| 定义布尔 | `bool 变量名 = true;` | `bool ok = true;` |
| 输出布尔文字 | `cout << boolalpha << 变量;` | 得 `true` |

### 易错点提醒

1. **`float` 当默认**：不加后缀的小数字面量是 `double`，`float` 只有约 7 位
2. **有效位数数错**：`0.06300` 是 4 位，开头 `0` 不算、末尾 `0` 算
3. **漏引头文件**：`setprecision` 需要 `#include <iomanip>`
4. **混淆两种精度控制**：`setprecision(n)` 是有效数字，`fixed` 后才是小数位
5. **以为设置只生效一次**：`fixed` 与 `setprecision` 对后续输出持续有效
6. **`char` 引号写错**：`char c = "A";` 编译报错，必须写 `'A'`；`'AB'` 也不是合法字符
7. **`true` 加引号**：`true` / `false` 是关键字，不是字符串
8. **以为 `bool` 能存数**：赋非 0 值一律变成 `true`

> **本节小结**：float/double 管小数、char 管单个字符、bool 管真假；控制小数位数用 fixed + setprecision，其余靠类型区分。
