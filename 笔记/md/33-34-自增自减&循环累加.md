# 自增自减与循环累加学习笔记

## 1. `++` 与 `--`

### 核心概念

**自增**（increment）是把变量的值加 1，**自减**（decrement）是把变量的值减 1。它们和复合赋值运算符 `+=`、`-=` 一样，本质都是「对变量自身做一次运算，再把结果存回自己」。

同一件事在 C++ 里通常有三种写法，效果完全一样：

| 目的 | 写法一 | 写法二 | 写法三 |
| ---- | ------ | ------ | ------ |
| 加 1 | `a = a + 1;` | `a += 1;` | `a++;` |
| 减 1 | `a = a - 1;` | `a -= 1;` | `a--;` |
| 加任意数 | `a = a + 4;` | `a += 4;` | 无简写 |
| 减任意数 | `a = a - 4;` | `a -= 4;` | 无简写 |

规律很清楚：`+=`、`-=` 用来加减**任意数字**，`++`、`--` 只能固定加减 **1**。

### 语法格式

```cpp
a += 1;      // 等价于 a = a + 1
a -= 1;      // 等价于 a = a - 1
a++;         // 后置自增，等价于 a = a + 1
++a;         // 前置自增，等价于 a = a + 1
a--;         // 后置自减，等价于 a = a - 1
--a;         // 前置自减，等价于 a = a - 1
```

类似的复合赋值还有 `*=`、`/=`、`%=`，含义都是「先运算再存回自身」。

### 代码示例

```cpp
int a = 3;
a += 1;
cout << a;      // 输出 4

int h = 5;
h++;            // 也可以写 h += 1; 或 h = h + 1;
cout << h;      // 输出 6

int m = 5;
m--;            // 也可以写 m -= 1; 或 m = m - 1;
cout << m;      // 输出 4
```

### 易错点

1. 只写 `a + 1;` 不是自增，它只是算了一个值然后丢掉，`a` 一点没变
2. `5++`、`(a + b)++` 都是非法写法，`++` 的操作数必须是**变量**
3. `a += 1` 与 `a =+ 1` 完全不同，后者等价于 `a = +1`，会把 `a` 直接赋成 1
4. 复合赋值不要写成 `a =+ 1;`、`a =- 1;`，这是初学者最常见的笔误

> **本节小结**：`++` 和 `--` 是 `+= 1`、`-= 1` 的简写，只能加减 1；要加减其他数字必须用 `+=`、`-=`。

## 2. 前置与后置的区别

### 核心概念

`++` 写在变量前面叫**前置**（prefix），写在后面叫**后置**（postfix）。两者都让变量加 1，区别在**取值的时机**：

- 前置 `++i`：**先加 1，再取用**，用的是加完后的新值
- 后置 `i++`：**先取用，再加 1**，用的是加之前的旧值

### 代码示例

```cpp
int i = 5;
cout << i++ << " ";   // 输出 5，输出之后 i 才变成 6
cout << i << " ";     // 输出 6

int j = 5;
cout << ++j << " ";   // 输出 6，先加再输出
cout << j << " ";     // 输出 6
```

对比表：

| 表达式 | 参与运算的值 | 表达式结束后变量的值 |
| ------ | ------------ | -------------------- |
| `i++`（i 原为 5） | 5 | 6 |
| `++i`（i 原为 5） | 6 | 6 |
| `i--`（i 原为 5） | 5 | 4 |
| `--i`（i 原为 5） | 4 | 4 |

### 单独成句时没有区别

当 `++` 单独作为一个语句、或者只出现在 `for` 的步进位置时，前置和后置的结果**完全一样**：

```cpp
int a = 5;
a++;      // 单独成句，a 变成 6
int b = 5;
++b;      // 同样，b 变成 6

for (int i = 1; i <= 5; i++)    // 与 i++ 还是 ++i 无关
```

### 易错点

1. 只有在「自增结果同时被使用」的场合（如 `cout <<`、赋值、比较）才需要区分前置和后置
2. 同一条表达式里对同一个变量多次自增，例如 `i = i++ + ++i;`，行为未定义，不要写
3. `for` 的步进用 `i++` 或 `++i` 都可以，初学统一写一种即可

> **本节小结**：前置先加后用、后置先用后加；单独成句时两者等价，只有自增的值被立刻拿去参与运算时才需要小心。

## 3. 累加器模式

### 核心概念

**累加**是把一些数字逐个加到同一个变量中，这个变量叫**累加变量**（accumulator）。

累加变量有两条铁律：

1. **初始化为 0**，表示「一个数都还没加」
2. **定义在循环外面**，这样才能在每一轮之间保留上一次的结果

循环结束后，累加变量里存的就是所有数字的**总和**。图示关系是：累加变量 `0` 依次接住 `2、5、8、10、1`，逐个加入后得到总和 `26`。

### 语法格式

```cpp
int sum = 0;              // 第一步：准备累加变量并清零
for (...)
{
    sum = sum + x;        // 第二步：把当前数据加进去
}
cout << sum;              // 第三步：循环结束后输出总和
```

`sum = sum + x;` 可以简写为 `sum += x;`。

### 代码示例

求 1 加到 100：

```cpp
int sum = 0;
for (int i = 1; i <= 100; i = i + 1)
{
    sum += i;
}
cout << sum;      // 输出 5050
```

读入若干个数并累加，做法完全一样，只是把 `sum += i` 换成 `sum += x`。

### 易错点

1. **忘记初始化为 0**：未初始化的变量是随机值，结果必然错误
2. **把 `sum` 定义在循环体内**：每轮都重新创建并清零，最后只剩最后一个数
3. 把累加变量和循环变量混为一谈，用 `i` 去累加，循环次数立刻被破坏

> **本节小结**：累加三件套是「循环外定义并清零 → 循环内 `sum += x` → 循环后输出」，顺序和位置错一个，结果就全错。

## 4. 求和与计数

### 核心概念

循环里最常见的两种统计动作：

| 动作 | 变量名习惯 | 初始值 | 循环内的操作 | 结果含义 |
| ---- | ---------- | ------ | ------------ | -------- |
| 求和 | `sum` | 0 | `sum += x;` | 所有数加起来的总和 |
| 计数 | `cnt`、`d` | 0 | `cnt++;` | 满足条件的个数 |

两者结构完全一样，区别只在循环体里做的是「加上数据」还是「加 1」。

### 代码示例

统计循环执行了多少次：

```cpp
int d = 0;
for (int i = 5; i <= 12; i = i + 1)
{
    d++;
}
cout << d;      // 输出 8
```

循环次数也可以用公式直接算：`循环次数 = 条件数值 - 变量初始值 + 1`。

即 `12 - 5 + 1 = 8`，与程序跑出来的 `d` 一致。这个公式可以用来检验计数结果对不对。

求和与计数一起用，就能求平均值：

```cpp
int sum = 0, cnt = 0;
for (int i = 1; i <= 6; i = i + 1)
{
    int x;
    cin >> x;
    sum += x;      // 求和
    cnt++;         // 计数
}
cout << sum << " " << sum * 1.0 / cnt;   // 总和 与 平均值
```

注意 `sum * 1.0 / cnt`：先乘 `1.0` 把整数变成小数，再做除法，否则会丢失小数部分。

### 易错点

1. 计数器初始值写成 1，结果会比实际多 1
2. 用 `sum += 1` 代替计数虽然结果相同，但语义混乱，计数就该用 `cnt++`
3. 求平均值时直接写 `sum / cnt`，两个整数相除会截断小数
4. `cnt` 为 0 时做除法会出错，求平均前要确认确实读到了数据

> **本节小结**：求和是 `sum += x`，计数是 `cnt++`，两者都从 0 开始、都定义在循环外；计数结果还能用「终点 - 起点 + 1」反过来验算。

## 知识框架梳理

### 核心概念总结

- **自增自减**：`++`、`--` 只能加减 1，`+=`、`-=` 可以加减任意数
- **前置与后置**：`++i` 先加后用，`i++` 先用后加，单独成句时等价
- **累加变量**（accumulator）：初始化为 0，定义在循环外，循环结束后保存总和
- **计数器**（counter）：初始化为 0，用来统计次数或满足条件的个数

### 语法速查表

| 用途 | 写法 |
| ---- | ---- |
| 变量加 1 | `a++;` 或 `a += 1;` 或 `a = a + 1;` |
| 变量减 1 | `a--;` 或 `a -= 1;` 或 `a = a - 1;` |
| 变量加任意数 | `a += 4;` |
| 前置自增 | `++a;`（先加后用） |
| 后置自增 | `a++;`（先用后加） |
| 累加求和 | `int sum = 0;` 配合 `sum += x;` |
| 统计个数 | `int cnt = 0;` 配合 `cnt++;` |
| 求平均值 | `sum * 1.0 / cnt` |
| 推算循环次数 | `终点 - 起点 + 1` |

### 易错点提醒

1. **`a + 1;` 不是自增**：没有赋值回去，变量不变
2. **`a =+ 1;` 是赋值**：等价于 `a = 1`，不是加 1
3. **前置后置别混用**：只有在自增结果被使用时才有差别
4. **累加变量必须清零**：不清零就是从随机值开始加
5. **累加变量定义在循环外**：定义在循环内会被反复清零
6. **整数除法丢小数**：求平均要乘 `1.0` 转成小数
7. **不要在一句里多次自增同一变量**：属于未定义行为

> **本节小结**：`++`、`--` 是循环的「推进器」，累加器和计数器是循环的「收集器」——推进器负责走完每一轮，收集器负责把每一轮的成果留下来。
