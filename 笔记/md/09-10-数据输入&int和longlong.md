# 数据输入与整数类型学习笔记

## 1. `cin` 输入

前面的程序数据都写死在代码里。要让程序真正和人交互，就得能从键盘读取数据，C++ 用 `cin` 完成这件事。

### 核心概念

- `cin` 是标准输入流对象（character input），与 `cout` 一样来自 `<iostream>`
- `>>` 叫**提取运算符**（extraction operator），把键盘输入的数据「送进」右边的变量
- 数据流向与 `cout` 相反：`cout <<` 往外送，`cin >>` 往里收
- `cin` 右边的变量**必须已经定义**，它只负责往里装值，不创建变量

| 项目 | `cout` | `cin` |
| ---- | ---- | ---- |
| 方向 | 程序 → 屏幕 | 键盘 → 程序 |
| 运算符 | `<<` | `>>` |
| 用法 | `cout << 内容;` | `cin >> 变量;` |

### 代码示例

```cpp
#include <iostream>
using namespace std;

int main()
{
    int num;
    cout << "请输入一个整数：";   // 提示语
    cin >> num;                   // 等待用户输入
    cout << "您输入的整数是：" << num << endl;
    return 0;
}
```

### 易错点

1. 运算符方向写反 —— 输入用 `cin >>`，写成 `cin <<` 直接编译报错
2. 变量没定义就输入 —— `cin >> x;` 之前必须有 `int x;`
3. 忘记写提示语 —— 程序会静默地卡住等待输入，使用者不知所措
4. 类型不匹配 —— 给 `int` 变量输入 `3.5`，只读入 `3`，剩下 `.5` 留在缓冲区

> **本节小结**：`cin >> 变量;` 是标准输入写法，`>>` 的箭头指向变量，表示把数据装进去。输入前用 `cout` 给出提示语，变量必须先定义。

## 2. 多变量连续输入

需要读入多个数据时，不必写多条 `cin`，一条语句就能连读。

### 核心概念

- 语法：`cin >> 变量1 >> 变量2 >> 变量3;`
- 多个数据之间用**空格、Tab 或回车**分隔，**不能用逗号**
- 全部输完按一次回车确认
- 拆成多条 `cin` 写效果完全相同，连写只是更简洁

### 代码示例

```cpp
#include <iostream>
using namespace std;

int main()
{
    int a, b;
    cin >> a >> b;      // 输入：3 5
    cout << a + b;      // 8
    return 0;
}
```

`cin >> a >> b;` 与 `cin >> a; cin >> b;` 完全等价。

数据不够时程序停在那里等待继续输入；数据过多时多余部分留在输入缓冲区，可能被下一次 `cin` 读走；类型不符时该变量读取失败，后续读入可能全部出错。

### 易错点

1. 用逗号分隔 —— 输入 `3,5` 时 `b` 读不到期望的值；写成 `cin >> a, b;` 同样无效，`b` 不会被读入
2. 输入顺序搞反 —— `cin >> a >> b;` 先给 `a` 再给 `b`，顺序必须与变量顺序一致
3. 以为要按多次回车 —— 一行内用空格隔开、最后一次回车即可

> **本节小结**：一条 `cin >> a >> b;` 能按顺序连读多个变量，数据之间用空格或换行分隔，绝不能用逗号。数据不够时程序会一直等，调试时容易误判为「卡死」。

## 3. 整型取值范围

计算机用固定长度的二进制存整数，位数有限，能表示的范围也就有限。

### 核心概念

- `int` 占 4 字节 = 32 位，最高位是符号位，剩下 31 位存数值
- `long long` 占 8 字节 = 64 位，范围大得多
- 两者都是**有符号整数**（signed integer），能表示负数
- **溢出**（overflow）：结果超出类型范围时数值翻转，最大值加一变最小值

| 类型 | 字节 | 位数 | 取值范围 | 最多十进制位 |
| ---- | ---- | ---- | ---- | ---- |
| `int` | 4 | 32 | `-2147483648 ~ 2147483647` | 10 位 |
| `long long` | 8 | 64 | `-9223372036854775808 ~ 9223372036854775807` | 19 位 |

`int` 的上限约 21 亿，记成「10 位数以内安全」最实用。

### 代码示例

```cpp
#include <iostream>
#include <climits>              // 提供 INT_MAX
using namespace std;

int main()
{
    cout << INT_MAX << endl;    // 2147483647
    int a = 2147483647;
    cout << a + 1 << endl;      // -2147483648，翻到了最小值
    return 0;
}
```

溢出现象像一个圆环：走到最大值再往前一步，就绕回最小值。

### 易错点

1. 以为 `int` 能存任意大的整数 —— 超过 21 亿就溢出，11 位手机号必须用 `long long`
2. 以为溢出会报错 —— 编译器通常不检查，程序照常运行但结果是错的
3. 忽略中间结果 —— 两个 `int` 相乘，乘法本身已经溢出

> **本节小结**：`int` 是 4 字节 32 位，范围约 ±21 亿，最多安全存 10 位十进制数；`long long` 是 8 字节 64 位，可存 19 位。超范围会静默溢出并翻转，不会报错。

## 4. `int` 与 `long long` 的选择

知道两者的范围后，选哪个就是一道判断题。

| 场景 | 建议类型 | 理由 |
| ---- | ---- | ---- |
| 人数、分数、天数、编号 | `int` | 数值远小于 21 亿 |
| 手机号、身份证号 | `long long` | 超过 10 位 |
| 阶乘、累乘、大数相乘 | `long long` | 中间结果增长极快 |
| 拿不准时 | `long long` | 多占 4 字节，换来安全 |

### 语法格式

```cpp
long long 变量名;                       // 只定义
long long 变量名 = 123456789012345LL;   // 定义并初始化，字面量加 LL 后缀
long long a, b, c;                      // 一次定义多个
```

### 关键示例：溢出发生在运算时

```cpp
int a = 100000;
long long b = 100000;

cout << a * a << endl;       // 1410065408，两个 int 相乘已溢出，结果错误
cout << b * b << endl;       // 10000000000，正确
long long d = 1LL * a * a;   // 正确：先把 a 提升为 long long 再相乘
cout << d << endl;           // 10000000000
```

写成 `long long c = a * a;` 是错误的：**类型提升发生在运算时，而不是赋值时**，右边先按 `int` 算完再转，溢出已经发生，必须让操作数本身是 `long long`。

### 易错点

1. 只改结果变量的类型 —— `long long c = a * a;` 依然溢出
2. 忘记 `LL` 后缀 —— 直接写 20 位的数字字面量，编译器会提示常量过大
3. 以为 `long long` 万能 —— 它也有上限，20 位以上要用高精度算法
4. 输入输出搞特殊 —— `cin` / `cout` 对 `long long` 同样适用，无需额外格式符

> **本节小结**：10 位以内用 `int`，超过 10 位或中间结果可能很大就用 `long long`。最关键的坑是「只改结果变量类型无效」，必须让操作数本身是 `long long`。

## 5. 输入输出综合应用

把输入、运算、输出串起来，就能写出一个完整的小程序。

### 示例：四则运算器

```cpp
#include <iostream>
using namespace std;

int main()
{
    int a, b;
    cin >> a >> b;            // 输入：7 3
    cout << a + b << endl;    // 10
    cout << a - b << endl;    // 4
    cout << a * b << endl;    // 21
    cout << a / b << endl;    // 2，整数除法
    cout << a % b << endl;    // 1，取余
    return 0;
}
```

求平均分时把除数写成小数，才能保留小数部分：

```cpp
int s1, s2, s3;
cin >> s1 >> s2 >> s3;                  // 输入：85 92 78
cout << (s1 + s2 + s3) / 3.0 << endl;   // 85，写 / 3 会被截断
```

### 提示语的取舍

| 场合 | 是否写提示语 |
| ---- | ---- |
| 本地自己练习、调试 | 写，方便知道该输什么 |
| 提交到 OJ 判题系统 | **绝对不写**，多输出一个字符就算答案错误 |

### 易错点

1. 在 OJ 上写 `cout << "请输入："` —— 输出与标准答案不符，直接判错
2. 忘记 `endl` 导致输出挤在一行 —— 要求逐行输出的题目会判错
3. 除数为 0 —— 两数相除前要确认第二个数不为零
4. 平均分用整数除法 —— `(s1+s2+s3)/3` 会截断，要用 `3.0`

> **本节小结**：完整程序的结构是「读入 → 计算 → 输出」。注意三个细节：整数除法会截断、大数要用 `long long`、OJ 上不要写提示语。

## 知识框架梳理

### 核心概念总结

- **`cin` 与 `>>`**：标准输入流对象，`cin >> 变量;` 把键盘数据装进变量，箭头指向变量
- **连续输入**：`cin >> a >> b;` 按顺序读入，用空格或换行分隔
- **整型范围**：`int` 是 4 字节 32 位，最多 10 位十进制数；`long long` 是 8 字节 64 位，最多 19 位
- **溢出**：超出范围后数值翻转且不报错，非常隐蔽
- **类型选择**：10 位以内用 `int`，更大或不确定时用 `long long`
- **提升时机**：转换发生在运算时，`long long c = a * a;` 救不了溢出

### 语法速查表

| 用途 | 写法 | 示例 |
| ---- | ---- | ---- |
| 读入一个变量 | `cin >> 变量;` | `cin >> n;` |
| 连续读入多个 | `cin >> a >> b;` | `cin >> a >> b;` |
| 定义整型 | `int 变量名;` | `int age;` |
| 定义长整型 | `long long 变量名;` | `long long n;` |
| 长整型字面量 | 数字后加 `LL` | `123456789012345LL` |
| 查看 `int` 上限 | `INT_MAX` | 需 `#include <climits>` |
| 提升操作数类型 | `1LL * a * a` | 避免中间结果溢出 |
| 带提示输入 | `cout << "提示"; cin >> n;` | 仅本地练习用 |

### 易错点提醒

1. **方向写反**：输入是 `cin >>`，输出是 `cout <<`
2. **逗号问题**：`cin >> a >> b;` 只认空格和换行；写成 `cin >> a, b;` 时 `b` 根本读不到值
3. **变量未定义就输入**：`cin` 只装值，不创建变量
4. **低估数值量级**：11 位手机号必须用 `long long`
5. **以为溢出会报错**：程序照常运行，结果却是错的
6. **只改结果变量类型**：`long long c = a * a;` 仍溢出，要写 `1LL * a * a`
7. **OJ 上写提示语**：多输出一个字符就判错
8. **平均分整数除法**：`/ 3` 会截断，要写 `/ 3.0`

> **本节小结**：cin 负责把输入读进变量，能存多大的数则取决于类型的位宽——超过 int 上限就换 long long。
