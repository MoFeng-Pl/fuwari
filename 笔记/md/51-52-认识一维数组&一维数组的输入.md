# 一维数组基础学习笔记

## 1. 数组定义

数组（array）是**存储同一种数据类型的多个数据的集合**，三个关键词对应三条性质：

- **同一种类型**：元素类型必须一致，不能混放 `int` 和 `char`
- **多个数据**：一次装很多个值，而不是普通变量那样只装一个
- **集合**：共用同一个名字，内存中**连续存放**，靠下标区分彼此

```cpp
int a[5];   // 能装 5 个整数，名字叫 a
```

有了数组，100 个成绩不必定义 100 个变量。

> **本节小结**：数组是"同类型 + 多个 + 连续存放"的数据集合，用统一名字加下标管理一批数据。

---

## 2. 数组命名规则

数组名是标识符，**和变量命名规则完全一样**，共四条：

1. 只能由**字母、数字、下划线**组成
2. **不能**以数字开头
3. **不能**是 C++ 关键字
4. 严格**区分大小写**

| 数组名 | 合法 | 原因 |
| ------ | ---- | ---- |
| `arr1` | ✅ | 字母开头，含数字 |
| `1arr` | ❌ | 数字开头 |
| `my-array` | ❌ | 含减号 |
| `int` | ❌ | 是关键字 |

> **本节小结**：字母数字下划线、不以数字开头、避开关键字、区分大小写，四句话就是全部规则。

---

## 3. 定义一维数组

语法格式：`类型 数组名[长度];`

- **类型**：元素类型，如 `int`、`char`、`double`
- **数组名**：遵循命名规则的标识符
- **长度**：元素个数，**必须是编译期常量**，可以是字符常量 `'a'`（按 ASCII 码值 97）、整型常量 `10`、常量表达式 `1+5`

```cpp
int  a[10];      // 10 个整数
char str[26];    // 26 个字符
int  b[1 + 5];   // 长度 6
```

易错：`int n = 5; int a[n];` 在标准 C++ 中不合法，长度要用 `const int n = 5;` 或字面量。

> **本节小结**：定义数组要凑齐"类型、名字、长度"三要素，长度必须编译期确定，不能是普通变量。

---

## 4. 一维数组的初始化

初始化是**在定义的同时给元素赋初值**，总原则：`初始化值个数 ≤ 数组长度`。

- **完全初始化**：初始化值个数等于长度，每个元素都有值
- **部分初始化**：初始化值个数小于长度，**剩余元素自动为 0**
- **非法写法**：初始化值个数大于长度，直接编译报错

```cpp
int a[5] = {1, 2, 3, 4, 5};   // 完全初始化
int b[5] = {1, 2, 3};         // b[3]、b[4] 自动为 0
```

> **本节小结**：初始化分完全与部分两种，部分初始化时没写到的元素一律自动补 0，这是清零写法的依据。

---

## 5. 全部初始化为 0

想整体清零，不必写一长串 0，两种简便写法即可：

```cpp
int a[5] = {0};   // 结果 0 0 0 0 0
int x[3] = {};    // 结果 0 0 0
```

- `{0}`：第一个元素显式给 0，其余按"部分初始化补 0"自动为 0，兼容性最好
- `{}`：一个值都不给，所有元素做值初始化，整型即为 0，写法更简洁

> **本节小结**：清零不用数 0 的个数，`{0}` 或 `{}` 一行搞定，原理都是"未写到的元素自动补 0"。

---

## 6. 省略长度的初始化

语法格式：`类型 数组名[] = {值1, 值2, 值3};`

```cpp
int a[] = {1, 2, 3};   // 长度自动确定为 3
```

- 适用：元素个数固定、不想手动数的小数组，如配置表、常量表
- 好处：不会数错个数，改动初始化列表时长度自动跟着变
- 非法：只写 `int a[];` 不初始化，编译器无法确定空间大小

> **本节小结**：`[]` 留空并给初始化列表，长度由编译器数出来；留空就必须给值，两者不能分开。

---

## 7. 数组下标

下标（index）指明"要访问第几个元素"，两条特性：**从 0 开始**（第一个元素下标是 0），**逐一增加**（依次 0、1、2、3…）。

长度为 n 的数组，有效下标是 `0` 到 `n-1`：

| 数组长度 | 有效下标 | 元素个数 |
| -------- | -------- | -------- |
| 5 | 0, 1, 2, 3, 4 | 5 |
| n | 0, 1, …, n-1 | n |

```cpp
int a[5] = {10, 20, 30, 40, 50};
cout << a[0];   // 10，第 1 个
cout << a[4];   // 50，第 5 个
```

> **本节小结**：下标从 0 开始，`a[i]` 是第 `i+1` 个元素，长度 n 的数组最大下标是 n-1。

---

## 8. 数组越界

**数组越界**（out of bounds）是指下标**超出了数组已分配的边界范围**：下标 `< 0` 是下界越界（`a[-1]`），下标 `≥ n` 是上界越界（`a[5]`、`a[10]`）。

```cpp
int a[5] = {1, 2, 3, 4, 5};
// 合法：a[0] ~ a[4]；越界：a[-1]、a[5]
```

- 读到垃圾值，输出莫名其妙的结果
- 改坏相邻变量的内存，错误现场离真正原因很远
- C++ **不检查**下标，越界常常不报错、不崩溃，只是悄悄算错

> **本节小结**：写 `a[n]` 就已经越界，编译器不会拦你，只能在循环边界上自己把关。

---

## 9. 数组长度建议

定义数组时**适当开大一点**，比实际需要的上限多几个，通常多 5 或 10。

```cpp
int a[15];   // 实际最多存 10 个，多留 5 个位置
```

- 输入比预期多几个时不会立刻越界
- 后续需求变多，不用回头改数组长度
- 给插入、删除等操作留出腾挪空间

代价是多占一点内存，小数组可忽略，内存紧张的场景要权衡。

> **本节小结**：长度多开 5 到 10 个，用一点空间换掉一整类越界事故，是低成本的防御性写法。

---

## 10. 修改数组元素

语法格式：`数组名[下标] = 新值;`

```cpp
int a[5] = {1, 2, 3, 4, 5};

a[4] = 10;    // 第 5 个元素改成 10 → {1,2,3,4,10}
a[0] = 100;   // 第 1 个元素改成 100 → {100,2,3,4,10}
```

要点：先用下标**定位**元素，再用 `=` 覆盖旧值，新值类型要与数组类型兼容。注意 `a = 10;` 是给整个数组赋值，数组不能整体赋值。

> **本节小结**：改元素就是"定位 + 赋值"两步，一条语句只改一个元素。

---

## 11. 通过 cin 输入

语法格式：`cin >> 数组名[下标];`，从键盘读一个值直接存进该元素。

```cpp
int a[5];
cin >> a[3];        // 输入 25，则 a[3] = 25

for (int i = 0; i < 5; i++)
{
    cin >> a[i];    // 批量输入 a[0] ~ a[4]
}
```

易错：循环条件写成 `i <= 5` 会读到 `a[5]`，长度 5 的数组条件必须是 `i < 5`。

> **本节小结**：`cin >> a[i];` 是最常用的数组输入方式，循环变量正好当元素下标用。

---

## 12. 数组元素运算

数组元素在表达式里**和普通变量一样**，可以参与四则运算：

```cpp
int a[5] = {1, 2, 3, 4, 5};

cout << a[2] + a[4];   // 3 + 5 = 8
cout << a[4] - a[0];   // 5 - 1 = 4
cout << a[4] / a[1];   // 5 / 2 = 2（整数除法）
```

结果还能存回数组：`a[0] = a[1] + a[2];`。

**连续存放的索引计算**：从下标 `i` 开始连续存放 `n` 个元素，最后一个元素的下标是 `i + n - 1`。推导：第 1 个是 `i`，第 2 个是 `i+1`……第 n 个是 `i+(n-1)`。例：从下标 2 放 4 个元素，占用 `2、3、4、5`，末位 `2+4-1 = 5`。写成 `i + n` 就多算一格，是典型的**差一错误**（off-by-one error）。

> **本节小结**：元素能直接参与运算，所以数组天然适合求和与找最值；连续存放的末位下标记牢 `i + n - 1`。

---

## 知识框架梳理

### 核心概念总结

- **数组**：同类型、多个、连续存放的数据集合，靠下标访问
- **定义**：`类型 数组名[长度];`，长度必须编译期常量
- **初始化**：完全初始化、部分初始化补 0、`{0}` 或 `{}` 清零、`[]` 省略长度
- **下标**：从 0 开始，长度 n 的范围是 `0 ~ n-1`
- **越界**：下标小于 0 或不小于 n，C++ 不检查，后果隐蔽
- **读写**：`a[i] = 值;` 修改，`cin >> a[i];` 输入，`a[i]` 参与运算

### 语法速查表

| 用途 | 写法 |
| ---- | ---- |
| 定义数组 | `int a[10];` |
| 完全初始化 | `int a[5] = {1,2,3,4,5};` |
| 部分初始化 | `int a[5] = {1,2,3};` |
| 全部清零 | `int a[10] = {0};` 或 `int a[10] = {};` |
| 省略长度 | `int a[] = {1,2,3};` |
| 访问元素 | `a[0]`、`a[i]` |
| 修改元素 | `a[2] = 100;` |
| 键盘输入 | `cin >> a[i];` |
| 元素运算 | `a[1] + a[2]` |
| 末位下标 | `i + n - 1` |

### 易错点提醒

1. **下标从 0 开始**：`a[0]` 是第一个元素，不是 `a[1]`
2. **上界是 n-1**：长度 5 的数组写 `a[5]` 就越界
3. **长度不能是变量**：`int n = 5; int a[n];` 不合标准
4. **初始化值不能多于长度**：多了是编译错误，不是截断
5. **省略长度必须初始化**：`int a[];` 非法
6. **数组不能整体赋值**：`a = {1,2,3};` 非法，只能逐元素赋值
7. **循环边界**：遍历长度 n 的数组，条件写 `i < n` 而不是 `i <= n`
8. **连续存放别算错**：末位下标是 `i + n - 1`，不是 `i + n`

> **本节小结**：数组用「类型 名[长度]」定义、下标从 0 数起、访问不能越界，cin 配合循环是它最常见的入口。
