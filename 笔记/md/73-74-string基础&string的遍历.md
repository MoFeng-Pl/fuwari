# string 类型学习笔记

## 1. string 的定义

`string` 是 C++ 标准库提供的**字符串类型**，用它存字符串比字符数组方便得多。

### 核心概念

- `string` 不是关键字，而是标准库 `<string>` 中定义的一个**类**（class）
- 它内部自己管理字符的存储空间，**不需要提前规定长度**，需要多长就自动扩多长
- 字符串的末尾仍然有一个 `\0` 占着一个位置，但 `string` **不把它算进长度**
- 与字符数组相比，`string` 支持整体赋值、整体比较、直接拼接

### 语法格式

```cpp
#include <string>

string 变量名;              // 定义空字符串
```

### 三种常见定义

`string s1;` 是空串（长度为 0）；`string s2 = "abc12";` 用字符串常量初始化；`string s3 = s2;` 用另一个 `string` 复制初始化。

### 与字符数组的对比

| 对比项 | 字符数组 `char s[100]` | `string s` |
| ------ | ---------------------- | ---------- |
| 长度 | 定义时必须写死，够不够要自己算 | 自动伸缩，不用管 |
| 赋值 | 只能用 `strcpy`，不能 `=` | 直接 `s = "hi";` |
| 比较 | 必须用 `strcmp` | 直接用 `==`、`<` 等 |
| 拼接 | 用 `strcat` | 直接用 `+` |
| 求长度 | `strlen(s)` | `s.size()` |
| 头文件 | `<cstring>` | `<string>` |

### 易错点

1. 定义时**不用再写长度**：`string s[100];` 定义的是「100 个 string 的数组」，不是长度为 100 的字符串
2. 忘记 `#include <string>`（用万能头文件 `<bits/stdc++.h>` 也可以）
3. `string` 是小写，写成 `String`、`STRing` 都会报错——C++ 区分大小写

> **本节小结**：`string` 是标准库的字符串类，定义时不用指定长度，支持整体赋值、比较和拼接，是从字符数组升级到现代写法的第一步。

## 2. string 的输入输出

`string` 对象可以直接交给 `cin` 和 `cout`，用法和普通变量一样简单。

### 输出

```cpp
string s = "hello";
cout << s;          // 输出 hello，不是地址
```

和普通变量一样，也可以与其它内容用 `<<` 连续拼接。

### 方式一：`cin >> s`

```cpp
string s;
cin >> s;
```

- **遇到空格、制表符、换行就停止**
- 因此只能读入**一个不含空格的单词**
- 输入 `hello world`，`s` 只会得到 `hello`

### 方式二：`getline(cin, s)`

```cpp
string s;
getline(cin, s);
```

- 读取**一整行**，直到遇到换行符为止（换行符本身不会存进 `s`）
- **可以读取带空格的字符串**，这是它最大的价值
- 输入 `hello world`，`s` 得到完整的 `hello world`

### 易错点：`cin >>` 后接 `getline`

```cpp
int n;
string s;
cin >> n;          // 输入 3 后按回车，换行符留在缓冲区
getline(cin, s);   // 立刻读到那个换行符，s 变成空串！
```

解决办法是先「吃掉」残留的换行：

```cpp
cin >> n;
cin.ignore();      // 丢弃缓冲区里的一个字符（换行符）
getline(cin, s);   // 这次才能正常读到一整行
```

> **本节小结**：`cout << s` 直接输出，`cin >> s` 读到空格为止，`getline(cin, s)` 读一整行且能读空格；`cin >>` 之后再用 `getline` 记得先 `cin.ignore()`。

## 3. 长度 `size()`

`string` 用成员函数 `size()` 求长度，不需要像字符数组那样数到 `\0`。

### 语法格式

```cpp
字符串变量.size()
字符串变量.length()
```

### 两个函数完全等价

```cpp
string s = "abc12";
cout << s.size();     // 5
cout << s.length();   // 5
```

- `size()` 和 `length()` 作用完全相同，选一个用即可，**推荐 `size()`**
- 返回的是**实际字符个数**，不包含结尾的 `\0`
- 空格也算一个字符：`"a b"` 的长度是 3

### 注意事项：返回的是无符号数

`size()` 的返回类型是 `size_t`，一种**无符号整数**（unsigned integer）。这带来一个经典陷阱：

```cpp
string s = "";                 // 空串，size() 为 0
cout << s.size() - 1;          // 不是 -1，而是一个极大的正数

int len = s.size();            // 先赋给 int，之后才能正常做减法
```

### 常见用法

```cpp
cout << s.size() << endl;              // 输出长度
if (s.empty()) cout << "空串";         // 判断空串
```

> **本节小结**：`s.size()` 与 `s.length()` 完全等价，得到不含 `\0` 的字符个数；它返回无符号数，做减法前最好先赋给 `int`。

## 4. string 的遍历方式

遍历 `string` 就是依次访问它的每个字符，最常用的是**下标法**。

### 下标的基本规则

- 下标**从 0 开始**
- 最后一个字符的下标是 **`长度 - 1`**
- 查看某个字符：`字符串变量名[下标]`

```cpp
string s = "hello";
// 下标：0    1    2    3    4
// 字符：h    e    l    l    o
cout << s[0];              // h
cout << s[s.size() - 1];   // o，最后一个字符
```

### 方式一：下标 for 循环

```cpp
string s = "hello";
for (int i = 0; i < (int)s.size(); i++) {
    cout << s[i] << " ";
}
```

- 循环条件是 `i < s.size()`，不能写 `<=`，否则越界
- 把 `s.size()` 强制转成 `int`，可以避免有符号与无符号比较的警告

### 方式二：范围 for 循环

```cpp
string s = "hello";
for (char c : s) {
    cout << c << " ";
}
```

- 语法含义：**依次取出 `s` 中的每个字符，赋给 `c`**
- 更简洁，但拿不到下标；需要下标时仍用方式一

### 遍历时修改字符

```cpp
string s = "hello";
for (int i = 0; i < (int)s.size(); i++) {
    s[i] = toupper(s[i]);   // 通过下标修改，原串真的变了
}
cout << s;                  // HELLO
```

- 用下标可以**读写**字符
- 范围 for 若要修改，必须写成引用：`for (char &c : s)`

### 应用：判断回文串

```cpp
// 判断回文串
bool flag = true;
int len = s.size();
for (int i = 0; i < len / 2; i++) {
    if (s[i] != s[len - 1 - i]) { flag = false; break; }
}
```

### 易错点

1. **循环写成 `i <= s.size()`**：多访问一个位置，越界
2. **空串时访问 `s[0]`**：`string` 不为空才有第 0 个字符，先判断 `s.empty()`
3. **用 `s[i] != '\0'` 作为结束条件**：`string` 的长度以 `size()` 为准，不要套用字符数组的写法
4. **倒序循环写成 `i >= 0` 但 `i` 是无符号数**：`(int)s.size() - 1` 先转 `int`，否则会死循环

> **本节小结**：`string` 的下标从 0 开始、末尾是 `size() - 1`，遍历用 `for (int i = 0; i < s.size(); i++)`；要修改字符必须通过下标或引用，循环边界永远不要写 `<=`。

## 知识框架梳理

### 核心概念总结

- **`string`**：标准库字符串类，长度自动管理，无需预先指定大小
- **定义**：`string s;` 空串，`string s = "abc12";` 带初值
- **输入**：`cin >> s` 读到空格为止；`getline(cin, s)` 读一整行、可含空格
- **输出**：`cout << s` 直接输出整串
- **长度**：`s.size()` 与 `s.length()` 等价，不含 `\0`，返回无符号数
- **下标**：从 0 开始，末尾是 `size() - 1`
- **遍历**：下标 for 循环（可读可写）或范围 for 循环（写法更短）

### 语法速查表

| 用途 | 写法 |
| ---- | ---- |
| 引入头文件 | `#include <string>` |
| 定义空串 | `string s;` |
| 定义并初始化 | `string s = "abc12";` |
| 读一个单词 | `cin >> s;` |
| 读一整行 | `getline(cin, s);` |
| 输出整串 | `cout << s;` |
| 求长度 | `s.size()` / `s.length()` |
| 下标遍历 | `for (int i = 0; i < s.size(); i++)` |
| 范围遍历 | `for (char c : s)` |

### 易错点提醒

1. **`cin >>` 后直接 `getline`**：会读到残留的换行符，必须先 `cin.ignore()`
2. **循环边界用 `<=`**：`i < s.size()` 才是正确上界
3. **`s.size()` 做减法**：无符号数下溢，先赋给 `int`
4. **把 `string` 当字符数组用**：不需要 `strlen`、`strcpy`、`strcmp`，也不要用 `'\0'` 判断结尾
5. **范围 for 想改字符却没用引用**：应写 `for (char &c : s)`
6. **空串直接取 `s[0]`**：越界，先判断是否为空

> **本节小结**：`string` 用起来比字符数组省心——不用管长度、能直接输入输出、`size()` 取长度、下标遍历从 0 到 `size() - 1`；只要避开无符号下溢和 `cin` 与 `getline` 的缓冲区问题即可。
