# 枚举算法学习笔记

## 1. 枚举思想

### 核心概念

**枚举算法**（enumeration，也叫穷举法）：**通过列举所有可能的解，来找到满足条件的答案**。

它的思路非常朴素——把所有候选答案一个一个试过去，符合条件就留下，不符合就跳过。就像一串钥匙挨个试开门：不知道哪把能开，但**全部试完就一定知道答案**。

枚举能用的三个前提：

- **答案的范围是有限的**，能一个一个数出来
- **有一个明确的判断条件**，能判断某个候选解"行不行"
- **列举不重不漏**，每个候选解恰好被检查一次

### 语法格式

```cpp
for (枚举变量从下界; 枚举变量 <= 上界; 枚举变量++)
{
    if (满足条件)
    {
        记录或输出这个解;
    }
}
```

### 代码示例

```cpp
#include <iostream>
using namespace std;

int main()
{
    // 枚举 1 到 20 中所有的偶数
    for (int i = 1; i <= 20; i++)
    {
        if (i % 2 == 0)          // 判断条件
        {
            cout << i << " ";
        }
    }
    return 0;
}
```

### 易错点

1. **循环边界写错** —— 边界少 1 会漏解，多 1 会多出不合法的候选
2. **忘记判断条件** —— 把"所有数"都当成答案输出
3. **认为枚举一定慢** —— 范围小时枚举最快、最不容易写错
4. **枚举变量重名** —— 嵌套枚举时内外层变量名必须不同

> **本节小结**：枚举就是"把所有可能的答案挨个试一遍，用条件筛选出正确的那些"，前提是范围有限、条件明确、列举不重不漏。

## 2. 枚举范围的确定

### 核心概念

枚举范围是这类题目的关键：**范围小了会漏解，范围大了会白跑甚至超时**。

确定范围的办法是**从题目条件里反推**，而不是凭感觉写一个大数：

| 题目特征 | 合理范围 |
| -------- | -------- |
| 三位数 | `100 ~ 999` |
| 四位数 | `1000 ~ 9999` |
| 两位数之和 | 每个数 `10 ~ 99` |
| 100 元买 100 只鸡 | 公鸡 `0 ~ 20`，母鸡 `0 ~ 33` |
| 求 n 的因数 | `1 ~ n`（可优化到 `sqrt(n)`） |

范围确定后，还要注意**边界能否取到**：用 `<=` 还是 `<` 取决于题目是否包含端点。

### 代码示例：三位数中找各位数字之和为 15 的数

```cpp
#include <iostream>
using namespace std;

int main()
{
    for (int n = 100; n <= 999; n++)       // 三位数的完整范围
    {
        int a = n / 100;                   // 百位
        int b = n / 10 % 10;               // 十位
        int c = n % 10;                    // 个位
        if (a + b + c == 15)
        {
            cout << n << " ";
        }
    }
    return 0;
}
```

### 易错点

1. **把三位数写成 `0 ~ 999`** —— 0 到 99 不是三位数，属于无效范围
2. **上界写成 `< 999`** —— 漏掉了 999 这个合法候选
3. **范围太大导致超时** —— 能推出更紧的界就一定要用
4. **数位分离时用 `n / 10` 取十位** —— 应该是 `n / 10 % 10`，否则会把高位也算进来

> **本节小结**：枚举范围要从题目的条件里推算，既不能漏掉合法解，也不要无谓地放大；范围确定后还要确认端点是 `<=` 还是 `<`。

## 3. 枚举结合判断

### 核心概念

枚举的完整套路是**三层结构**：

1. **枚举**：`for` 循环把所有候选解走一遍
2. **判断**：`if` 检查当前候选是否满足条件
3. **处理**：满足就输出、计数或记录

判断里常常要用**数位分离**把每一位拆出来：四位数 `x` 的千位是 `x / 1000`，百位是 `x / 100 % 10`，十位是 `x / 10 % 10`，个位是 `x % 10`。

### 代码示例：玫瑰花数

**玫瑰花数**（四位自幂数）：一个四位数，**每个数位上的数字的 4 次方相加，等于这个数本身**，即 `a⁴ + b⁴ + c⁴ + d⁴ = abcd`。

```cpp
#include <iostream>
using namespace std;

int main()
{
    for (int n = 1000; n <= 9999; n++)     // 枚举所有四位数
    {
        int a = n / 1000;                  // 千位
        int b = n / 100 % 10;              // 百位
        int c = n / 10 % 10;               // 十位
        int d = n % 10;                    // 个位
        if (a * a * a * a + b * b * b * b
            + c * c * c * c + d * d * d * d == n)
        {
            cout << n << " ";
        }
    }
    return 0;
}
```

运行结果是 `1634 8208 9474`。

### 易错点

1. **数位分离公式写错** —— 十位是 `n / 10 % 10`，少写 `% 10` 就取错了位
2. **次方写成 `a * 4`** —— 4 次方是 `a` 自乘 4 次，不是乘 4
3. **判断写成 `=`** —— 条件里必须是 `==`
4. **范围写成 `0 ~ 9999`** —— 会把 1、2、3 位数也算进来，而题目只要四位数
5. **`int` 溢出** —— 4 次方最大 9⁴ = 6561，四个相加不超过 26244，`int` 够用；但位数更多时要考虑 `long long`

> **本节小结**：枚举的骨架是"循环列举 + `if` 判断 + 输出或计数"，配合数位分离就能解决按位取幂、按位求和这一类问题。

## 4. 枚举的应用

### 核心概念

枚举是很多经典问题的通用解法，常见的三类应用：

- **枚举 + 计数**：统计满足条件的解有几个
- **枚举 + 最值**：在满足条件的解里找最大或最小
- **枚举 + 组合**：多个变量一起枚举，如百钱百鸡

范围大时可以**剪枝**（pruning）：用已知条件把不可能的情况提前排掉，例如由"总只数 100"直接算出小鸡数量，省掉一层循环。

### 代码示例：百钱百鸡

公鸡 5 钱一只、母鸡 3 钱一只、小鸡 3 只 1 钱，用 100 钱买 100 只鸡，问各买多少。

```cpp
#include <iostream>
using namespace std;

int main()
{
    for (int g = 0; g <= 20; g++)            // 公鸡最多 20 只
    {
        for (int m = 0; m <= 33; m++)        // 母鸡最多 33 只
        {
            int c = 100 - g - m;             // 小鸡由总数直接推出
            if (c >= 0 && c % 3 == 0
                && 5 * g + 3 * m + c / 3 == 100)
            {
                cout << "公鸡 " << g << " 母鸡 " << m
                     << " 小鸡 " << c << endl;
            }
        }
    }
    return 0;
}
```

两层循环本来要跑一万次，靠"总数推出小鸡"和"范围上界"两个剪枝，只跑几百次。

### 易错点

1. **上界凭感觉写 100** —— 公鸡 5 钱一只，最多 20 只，写 100 是白跑
2. **小鸡数量也写一层循环** —— 三个变量只需两层循环，第三个由总数算出
3. **漏掉 `c % 3 == 0`** —— 小鸡必须整只买，不能买半只
4. **`c >= 0` 忘了判断** —— 公鸡母鸡太多时小鸡会变成负数
5. **`c / 3` 用整数除法却忘了校验整除** —— 不整时会悄悄少算钱

> **本节小结**：枚举应用的关键是"范围要准、判断要全、能剪枝就剪枝"；多变量枚举时先用已知条件推出一个变量，就能把一层循环省掉。

## 知识框架梳理

### 核心概念总结

- **枚举**：列举所有可能的解，用条件筛选出正确答案
- **三前提**：范围有限、条件明确、列举不重不漏
- **三层结构**：`for` 枚举 → `if` 判断 → 输出或计数
- **范围**：从题目条件反推，端点是 `<=` 还是 `<` 要看清
- **数位分离**：`n / 1000`、`n / 100 % 10`、`n / 10 % 10`、`n % 10`
- **剪枝**：用已知条件排掉不可能的候选，减少循环次数
- **典型题型**：玫瑰花数、百钱百鸡、水仙花数、完全数

### 语法速查表

| 用途 | 写法 |
| ---- | ---- |
| 枚举区间 | `for (int i = l; i <= r; i++)` |
| 条件筛选 | `if (满足条件) { ... }` |
| 计数 | `cnt++;` |
| 千位 | `n / 1000` |
| 百位 | `n / 100 % 10` |
| 十位 | `n / 10 % 10` |
| 个位 | `n % 10` |
| 4 次方 | `a * a * a * a` |
| 双层枚举 | `for (g...) for (m...)` |

### 易错点提醒

1. 范围漏一端：三位数要写 `100 ~ 999`，不是 `0 ~ 999`
2. 边界写 `<` 会漏掉最大那个候选
3. 条件判断用 `==`，`=` 是赋值
4. 数位分离少写 `% 10` 会取错位
5. n 次方是自乘 n 次，不是乘 n
6. 多变量枚举时，能由总数推出的变量不要再开循环
7. 剪枝前先想清楚哪些条件能提前排除
8. 结果很大时注意 `int` 是否够用，必要时换 `long long`
9. 枚举不重不漏，每个候选只检查一次，别重复输出
10. 范围特别大时要想别的算法，硬枚举会超时

> **本节小结**：枚举就是「把所有可能都试一遍、逐个判断」，范围要卡准，范围错了结果一定错。
