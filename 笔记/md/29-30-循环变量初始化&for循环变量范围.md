# 循环变量初始化与范围学习笔记

## 1. 循环变量的起点

### 核心概念

**初值**（initial value）决定循环从哪个数开始，它写在 `for` 圆括号的第一个位置。

实际书写中只有两种起点，分别对应两种习惯：

- **从 1 开始**：符合人的计数习惯，用于「第几次」「1 到 n」这类问题
- **从 0 开始**：符合数组下标习惯，用于「第 0 个元素」「0 到 n-1」这类问题

起点不是随便挑的，它必须和后面的条件一起看。

### 代码示例

从 1 开始，输出 1 到 n：

```cpp
int n;
cin >> n;
for (int i = 1; i <= n; i = i + 1)
{
    cout << i << " ";
}
```

从 0 开始，输出 0 到 n-1（共 n 个数）：

```cpp
int n;
cin >> n;
for (int i = 0; i < n; i = i + 1)
{
    cout << i << " ";
}
```

### 起点与条件的搭配

| 起点 | 想要的输出 | 应写的条件 | 元素个数 |
| ---- | ---------- | ---------- | -------- |
| 1 | 1、2、……、n | `i <= n` | n 个 |
| 1 | 1、2、……、n-1 | `i < n` | n-1 个 |
| 0 | 0、1、……、n-1 | `i < n` | n 个 |
| 0 | 0、1、……、n | `i <= n` | n+1 个 |

### 易错点

1. 起点从 1 改成 0，条件却没跟着改成 `< n`，结果会多循环一次
2. 起点写成 `int i`（没有赋值），循环变量的值是不确定的随机数，循环次数完全失控
3. 同一条 `for` 里重复定义循环变量，例如循环外已有 `int i`，括号里又写 `int i = 1`

> **本节小结**：起点选 1 还是选 0，取决于问题习惯和是否与下标对齐；真正决定次数的是起点和条件这一对搭档，必须一起改。

## 2. 循环变量的作用域

### 核心概念

**作用域**（scope）是一个变量能够被使用的代码范围。用 `for (int i = 1; ...)` 这种写法时，`i` 的作用域被限制在 `for` 语句内部，循环结束后它就不存在了。

这条规则的好处是不会污染外面的变量名，代价是循环结束后拿不到 `i` 的值。

### 代码示例

错误示范：循环外还想用 `i`

```cpp
for (int i = 1; i <= 5; i = i + 1)
{
    cout << i << " ";
}
cout << i;   // 编译报错：i 未声明
```

正确示范一：把变量的定义提到循环外

```cpp
int i;
for (i = 1; i <= 5; i = i + 1)
{
    cout << i << " ";
}
cout << i;   // 输出 6，循环结束后 i 仍可使用
```

正确示范二：另设一个变量记录需要保留的结果

```cpp
int last = 0;
for (int i = 1; i <= 5; i = i + 1)
{
    last = i;
}
cout << last;   // 输出 5
```

### 易错点

1. 在循环外直接使用 `for` 括号里定义的 `i`，编译报 `not declared`
2. 内外层循环使用同名变量（**遮蔽** shadowing），内层变量会盖住外层，逻辑极容易出错
3. 想保留循环结束时的值，就必须把变量定义在循环外面

> **本节小结**：`for (int i ...)` 里的 `i` 只在循环内有效；需要在循环外使用，就把定义搬到循环之前。

## 3. 循环次数推算

### 核心概念

循环次数不需要真的跑一遍才知道，可以直接算。当步进为 1 且条件形如 `i <= 终点` 时，公式是 `循环次数 = 终点 - 起点 + 1`；如果步进不是 1，则用 `循环次数 = (终点 - 起点) / 步进 + 1`。

### 代码示例与对照

| 循环写法 | 推算过程 | 循环次数 |
| -------- | -------- | -------- |
| `for (int i = 1; i <= 10; i++)` | 10 - 1 + 1 | 10 |
| `for (int i = 0; i < 10; i++)` | 9 - 0 + 1 | 10 |
| `for (int i = 5; i <= 12; i++)` | 12 - 5 + 1 | 8 |
| `for (int i = 1; i <= 9; i += 2)` | (9 - 1) / 2 + 1 | 5 |
| `for (int i = 10; i >= 1; i--)` | 10 - 1 + 1 | 10 |

```cpp
// 验证第 3 行：循环体执行 8 次
int d = 0;
for (int i = 5; i <= 12; i = i + 1)
{
    d = d + 1;
}
cout << d;   // 输出 8
```

### 易错点

1. **差一错误**（off-by-one error）：把 `i <= n` 算成 n-1 次，或把 `i < n` 算成 n 次
2. 条件里写的是 `<`，终点实际取不到，公式里的「终点」应换成 `n-1`
3. 递减循环照搬加法公式，方向反了而次数算错

> **本节小结**：次数 = 终点 - 起点 + 1（步进为 1 时），先把这个数算清楚，再回头检查条件符不符合预期。

## 4. 循环范围控制

### 核心概念

**循环范围**指循环变量实际取到的那些值。控制范围的手段就是条件运算符的选择，核心只有一条分界线：**终点的那个数算不算在范围里**。

| 描述 | 输出 | 循环条件 |
| ---- | ---- | -------- |
| 包括 n | 1、2、3……n | `i <= n` |
| 不包括 n | 1、2、3……n-1 | `i < n` |

`<=` 表示「包含右端点」，`<` 表示「不包含右端点」，这是 C++ 里表达区间的通用方式。

### 代码示例

```cpp
int n = 5;

// 包含 n：1 2 3 4 5
for (int i = 1; i <= n; i = i + 1)
{
    cout << i << " ";
}

// 不包含 n：1 2 3 4
for (int i = 1; i < n; i = i + 1)
{
    cout << i << " ";
}
```

按区间写法记忆：

| 数学区间 | 含义 | C++ 循环条件 |
| -------- | ---- | ------------ |
| [1, n] | 1 到 n，含两端 | `i = 1; i <= n` |
| [1, n) | 1 到 n-1 | `i = 1; i < n` |
| [0, n) | 0 到 n-1，共 n 个 | `i = 0; i < n` |
| (0, n] | 1 到 n | `i = 1; i <= n` |

### 易错点

1. 输入 n 个数求和，循环写成 `i <= n` 且起点为 0，实际读了 n+1 次
2. 输出「1 到 n 之间所有整数」写成 `i < n`，n 被漏掉
3. 范围一改，循环次数的推算也要跟着改，不能只改一处

> **本节小结**：`<= n` 包含 n，`< n` 不包含 n；写循环前先把区间用数学符号写清楚，再翻译成条件，能避开绝大多数边界错误。

## 知识框架梳理

### 核心概念总结

- **初值**（initial value）：循环的起点，1 贴合计数习惯，0 贴合下标习惯
- **作用域**（scope）：`for (int i ...)` 中的 `i` 仅在循环内有效
- **循环次数**：步进为 1 时等于「终点 - 起点 + 1」
- **循环范围**：由条件运算符的 `<=` 与 `<` 决定是否包含右端点

### 语法速查表

| 用途 | 写法 |
| ---- | ---- |
| 从 1 开始到 n | `for (int i = 1; i <= n; i++)` |
| 从 0 开始到 n-1 | `for (int i = 0; i < n; i++)` |
| 不含右端点 | `for (int i = 1; i < n; i++)` |
| 在循环外使用循环变量 | `int i; for (i = 1; i <= n; i++)` |
| 步进为 2 | `for (int i = 1; i <= 9; i += 2)` |
| 递减 | `for (int i = n; i >= 1; i--)` |

### 易错点提醒

1. **起点改了条件没改**：起点 0 配 `<= n` 会多一次
2. **作用域越界**：循环外使用 `for` 内定义的 `i` 会编译报错
3. **差一错误**：`i <= n` 是 n 次，`i < n` 是 n-1 次
4. **公式套错**：递减循环不能直接套用加法公式
5. **内外同名**：嵌套循环尽量用 `i`、`j`、`k` 区分，避免遮蔽
6. **未初始化**：只写 `int i;` 不赋值就开始循环，次数不可控

> **本节小结**：循环变量的起点、作用域和范围是一条链上的三环——起点定习惯、作用域定可见性、条件定边界，三者对齐才能写出次数正确的循环。
