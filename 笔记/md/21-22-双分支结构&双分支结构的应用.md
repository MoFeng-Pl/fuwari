# 双分支结构与应用学习笔记

## 1. if-else 语法

### 核心概念

单分支结构在条件不成立时什么也不做。如果希望"条件成立做 A，条件不成立做 B"，就需要**双分支结构**（two-branch structure）：用 `else` 把另一条路也写出来。

- `if` 管"条件成立"的那条路
- `else` 管"条件不成立"的那条路，`else` 的意思是"否则"
- 两条路**必有一条被执行**，不会都没走，也不会都走

### 语法格式

```cpp
if (条件表达式)
{
    语句1;
}
else
{
    语句2;
}
```

- `if` 分支和 `else` 分支各用一对大括号包住语句体
- `else` 后面**不加圆括号、也不写条件**，因为它默认就是"除上述条件外的所有情况"
- `else` 前面那个 `}` 之后**不加分号**，`else` 与 `}` 之间也不能插别的语句
- `else` 总是与它前面**最近的那个 `if`** 配对

### 代码示例：判断是否及格

```cpp
#include <iostream>
using namespace std;

int main()
{
    int score;
    cin >> score;

    if (score >= 60)
    {
        cout << "及格" << endl;
    }
    else
    {
        cout << "不及格" << endl;
    }

    return 0;
}
```

输入 `75` 输出 `及格`，输入 `40` 输出 `不及格`。**任何输入都会有输出**，这正是双分支与单分支最大的区别。

### 与单分支的对比

| 对比项 | 单分支结构 | 双分支结构 |
| ------ | ---------- | ---------- |
| 关键字 | 只有 `if` | `if` + `else` |
| 分支数量 | 1 条路 | 2 条路 |
| 条件不成立时 | 什么也不做 | 执行 `else` 里的语句 |
| 是否一定有输出 | 不一定 | 两分支覆盖全部情况，必走其一 |

### 易错点

1. `else (x == 0)` —— `else` 后面不能带条件，多条件要用 `else if`
2. `else;` —— `else` 不是语句，后面加分号会直接编译报错
3. 写成 `Else`、`ELSE` —— C++ 区分大小写，只有小写 `else` 有效
4. 在 `}` 和 `else` 之间插了一句 `cout` —— `else` 找不到配对的 `if`，编译失败

> **本节小结**：`if {...} else {...}` 用 `else` 补出"否则"的那条路，`else` 不带条件、不加分号、紧跟在 `}` 后面。

## 2. 执行逻辑与分支选择

### 核心概念

双分支结构是严格的**二选一**：

- 条件表达式**成立** → 执行语句 1，**不执行**语句 2
- 条件表达式**不成立** → 执行语句 2，**不执行**语句 1

### 执行情况对照表

| 条件表达式 | 语句 1 | 语句 2 |
| ---------- | ------ | ------ |
| 成立（真） | **执行** | 跳过 |
| 不成立（假） | 跳过 | **执行** |

### 执行流程拆解

1. 先计算条件表达式的值
2. 值为真 → 进入 `if` 分支执行语句 1，执行完**直接跳出整个 if-else 结构**
3. 值为假 → 跳过 `if` 分支，转去执行 `else` 里的语句 2
4. 无论走哪条路，执行完都在 `else` 的 `}` 之后**汇合**，继续执行后面的代码

```
            ┌── 条件成立 ──→ 执行语句1 ──┐
判断条件 ───┤                            ├──→ 汇合，继续往下
            └── 条件不成立 → 执行语句2 ──┘
```

### 代码示例：输出两个数中的较大值

```cpp
int a, b;
cin >> a >> b;

if (a > b)
{
    cout << a << endl;
}
else
{
    cout << b << endl;
}
```

输入 `8 3` 输出 `8`；输入 `2 9` 输出 `9`。两条 `cout` 只会执行其中一条。

### 易错点

1. **以为两个分支都会执行** —— 分支是"互斥"的，走了一条就跳过另一条
2. **在 `if` 分支里写了 `return 0;`** —— 程序直接结束，`else` 永远不会被执行，容易误判为逻辑错误
3. **把 `else` 当成"条件再次判断"** —— `else` 不判断任何东西，它就是"剩下的一切"

> **本节小结**：双分支的执行逻辑是"条件真走 if、条件假走 else"，两条路互斥且必走其一，执行完在结构后面汇合。

## 3. 应用：二选一判断

### 核心概念

凡是题面出现"如果是……否则……""输出其中一种结果""两种情况选一个"的描述，基本都是双分支结构的应用。

### 解题三步

1. 找出题目里的**两个互斥结果**
2. 把"条件成立时的结果"写进 `if`，把"剩下的情况"写进 `else`
3. 检查有没有**第三种可能**，若有则说明该用多分支而不是双分支

### 代码示例：判断奇偶

```cpp
#include <iostream>
using namespace std;

int main()
{
    int n;
    cin >> n;

    if (n % 2 == 0)
    {
        cout << "偶数" << endl;
    }
    else
    {
        cout << "奇数" << endl;
    }

    return 0;
}
```

### 代码示例：判断闰年

```cpp
int y;
cin >> y;

if ((y % 4 == 0 && y % 100 != 0) || y % 400 == 0)
{
    cout << "是闰年" << endl;
}
else
{
    cout << "不是闰年" << endl;
}
```

闰年的条件本身很复杂，但结果只有"是"和"不是"两种，所以仍然是标准的双分支。

### 常见二选一场景

| 场景 | `if` 条件 | 成立时输出 | `else` 输出 |
| ---- | --------- | ---------- | ----------- |
| 是否及格 | `score >= 60` | 及格 | 不及格 |
| 奇偶判断 | `n % 2 == 0` | 偶数 | 奇数 |
| 正负判断 | `n >= 0` | 非负数 | 负数 |
| 两数较大值 | `a > b` | a | b |
| 能否整除 | `n % 3 == 0` | 能 | 不能 |

### 用条件运算符简化

当两个分支都只是"输出一个值"时，可以用**条件运算符**（ternary operator，也叫三目运算符）压成一行：

```cpp
// 等价于上面的 if-else
cout << (a > b ? a : b) << endl;
```

格式为 `条件 ? 成立时的值 : 不成立时的值`。它适合短表达式，逻辑一复杂就应该改回 `if-else`。

### 易错点

1. **两个分支都写了输出** —— 忘记 `else` 的互斥性，导致逻辑重复
2. **在 `else` 里再套一个 `if` 判断同一个条件** —— 说明条件没想清楚
3. **条件不互斥却硬用双分支** —— 比如成绩分"优秀/及格/不及格"三档，双分支只能表达两档

> **本节小结**：二选一判断的套路是"找出两个互斥结果 → 一个进 if 一个进 else → 确认没有第三种情况"，简单输出还可以用三目运算符压缩成一行。

## 知识框架梳理

### 核心概念总结

- **双分支结构**：用 `if` 和 `else` 表达"两条路选一条"
- **`else`**：表示"否则"，不带条件、不加分号，与最近的 `if` 配对
- **互斥执行**：条件真走 `if`，条件假走 `else`，永远不会都执行
- **全覆盖**：两分支合起来覆盖所有情况，因此一定会有输出

### 语法速查表

| 用途 | 写法 |
| ---- | ---- |
| 双分支基本格式 | `if (条件) { 语句1; } else { 语句2; }` |
| 输出两数较大值 | `if (a > b) { ... } else { ... }` |
| 判断奇偶 | `if (n % 2 == 0)` |
| 判断能否被 3 整除 | `if (n % 3 == 0)` |
| 三目运算符 | `条件 ? 值1 : 值2` |
| `else` 的配对 | 与上方最近的 `if` 配对 |

### 易错点提醒

1. `else` 后面加了条件或圆括号，语法错误
2. `else` 后面加了分号，编译不通过
3. 在 `}` 与 `else` 之间插入语句，`else` 失去配对
4. 认为两个分支都会执行，重复输出
5. 三种以上情况硬用双分支，应改用 `else if` 多分支
6. 条件写反，把"及格"写成 `score < 60`，两个分支的结果整体互换
7. 在 `if` 分支里提前 `return`，导致 `else` 成为死代码

> **本节小结**：双分支结构把"做与不做"升级为"二选一"，记住 `else` 不带条件、两分支互斥且全覆盖，二选一类的题目就能直接套用。
