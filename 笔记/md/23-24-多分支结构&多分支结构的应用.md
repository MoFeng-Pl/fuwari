# 多分支结构与应用学习笔记

## 1. if-else if-else 语法

### 核心概念

现实生活中常常要从**三种以上**的情况里挑一种：成绩分等级、温度分档、票价分段。只靠 `if` 和 `else` 只能表达"两种情况"，这时就要用**多分支结构**（multi-branch structure）。

它的做法是在 `else` 后面继续写 `if`，形成 `else if`，像接力一样一个条件接一个条件地判断下去。

### 语法格式

```cpp
if (条件表达式1) {
    语句1;
}
else if (条件表达式2) {
    语句2;
}
else if (条件表达式3) {
    语句3;
}
else {
    语句4;
}
```

- `else if` 是"**否则，如果**"的意思，中间有一个空格，两词都是小写
- `else if` 可以有**任意多个**，视情况数量而定
- 最后的 `else` 表示"前面所有条件都不成立时"的**兜底分支**，可以省略
- 每个分支的语句体都要用大括号包好，`}` 之后不加分号
- 只有第一个 `if` 前面没有 `else`，其余每个 `else if` 都必须紧跟着上一个 `}`

### 结构拆解

| 组成部分 | 作用 | 能否省略 |
| -------- | ---- | -------- |
| `if` | 第一个条件入口 | 不能 |
| `else if` | 后续条件，可有多个 | 只有一种情况时可省 |
| `else` | 兜底分支 | 可以，但建议保留 |
| `{}` 语句体 | 条件成立时执行的动作 | 多语句时不可省 |

### 代码示例：成绩等级

```cpp
#include <iostream>
using namespace std;

int main()
{
    int score;
    cin >> score;

    if (score >= 90) {
        cout << "A" << endl;
    }
    else if (score >= 80) {
        cout << "B" << endl;
    }
    else if (score >= 70) {
        cout << "C" << endl;
    }
    else if (score >= 60) {
        cout << "D" << endl;
    }
    else {
        cout << "E" << endl;
    }

    return 0;
}
```

输入 `85` 输出 `B`；输入 `59` 输出 `E`；输入 `100` 输出 `A`。

### 易错点

1. 写成 `elseif` 或 `else If` —— 必须是 `else if` 两个词加一个空格
2. 每个 `else if` 后面都加了分号 —— `else if (条件);` 会让语句体变成空语句
3. 用多个独立的 `if` 冒充多分支 —— 两者执行效果不同，见下一节
4. 漏掉最后的 `else` 兜底 —— 所有条件都不成立时程序什么都不输出，容易在 OJ 上判"答案错误"

> **本节小结**：多分支结构就是 `if` 后面接若干个 `else if`，最后用 `else` 兜底，用来在三种以上情况中挑一种执行。

## 2. 多分支的执行顺序

### 核心概念

多分支是**从上到下、依次判断、命中即停**：

1. 先判断条件表达式 1
2. 不成立才继续判断条件表达式 2
3. 一旦某个条件成立，就执行对应语句体，然后**跳出整个多分支结构**，后面的条件**根本不再判断**
4. 所有条件都不成立时，才执行最后的 `else`

### 执行情况对照表

| 判断过程 | 结果 |
| -------- | ---- |
| 条件 1 成立 | 执行语句 1，后面全部跳过 |
| 条件 1 假、条件 2 成立 | 执行语句 2，后面全部跳过 |
| 条件 1、2 假、条件 3 成立 | 执行语句 3，`else` 跳过 |
| 全部条件都假 | 执行 `else` 里的语句 4 |

**无论有多少个分支，最终最多只执行其中一个。**

### 条件顺序决定结果

因为"命中即停"，条件的**书写顺序非常关键**。成绩等级里必须**从高到低**写：

```cpp
// 正确：从高分往低分判断
if (score >= 90)      cout << "A";
else if (score >= 80) cout << "B";
else if (score >= 60) cout << "D";
else                  cout << "E";
```

```cpp
// 错误：条件顺序反了，"A" 永远输出不到
if (score >= 60)      cout << "D";
else if (score >= 90) cout << "A";   // 永远轮不到
else                  cout << "E";
```

输入 `95` 时，第一行 `score >= 60` 已经成立，于是直接输出 `D` 并跳出，`score >= 90` 这条分支成了**死代码**（dead code）。

### 多分支与多个独立 if 的区别

```cpp
// 多分支：最多执行一个
if (n > 0)  cout << "正";
else if (n > 5) cout << "很大";

// 多个独立 if：每个都判断一次，可能都执行
if (n > 0)  cout << "正";
if (n > 5)  cout << "很大";
```

`n = 10` 时：多分支只输出 `正`，独立 `if` 两句话都输出。

### 易错点

1. **条件顺序从小写到大** —— 小条件先命中，大条件永远不执行
2. **把互斥关系写成包含关系** —— 如 `score >= 60` 与 `score >= 90`，前者包含了后者
3. **以为会依次判断所有条件** —— 命中一个就退出，后面的条件不会被计算

> **本节小结**：多分支从上到下依次判断，命中即停，最多只执行一个分支；因此条件必须按"从特殊到一般"的顺序排列。

## 3. 应用：多条件分类

### 核心概念

多分支最典型的应用是**分段分类**：把一个连续的数值区间切成若干段，每段对应一种处理。

### 解题五步

1. 列出所有**互不重叠**的区间
2. 确定区间的**边界值**，注意 `>` 与 `>=` 的区别
3. 决定**判断顺序**：从特殊到一般，或从小到大
4. 把每个区间写成一条 `else if`
5. 用 `else` 兜底处理剩余情况

### 代码示例：分段计费

某停车场按小时收费：不足 2 小时收 5 元，满 2 小时但不足 5 小时收 10 元，5 小时及以上收 20 元。

```cpp
#include <iostream>
using namespace std;

int main()
{
    int h;
    cin >> h;

    if (h < 2) {
        cout << 5 << endl;
    }
    else if (h < 5) {
        cout << 10 << endl;
    }
    else {
        cout << 20 << endl;
    }

    return 0;
}
```

`else if (h < 5)` 看似只判断了一个上界，其实隐含了 `h >= 2` —— 因为能走到这一行，说明上一行的 `h < 2` 已经不成立了。

### 代码示例：判断数的正负与零

```cpp
int n;
cin >> n;

if (n > 0) { cout << "正数" << endl; }
else if (n < 0) { cout << "负数" << endl; }
else { cout << "零" << endl; }
```

这里有三种情况，最后用 `else` 直接兜住"既不是正也不是负"的零，不必再写一次 `n == 0`。

### 区间与分支的对应关系

| 区间 | 分支写法 | 说明 |
| ---- | -------- | ---- |
| h < 2 | `if (h < 2)` | 第一个条件必须最严格 |
| 2 ≤ h < 5 | `else if (h < 5)` | 下界由前一个条件保证 |
| h ≥ 5 | `else` | 剩余情况全归兜底分支 |

### 易错点

1. **区间边界重复或断裂** —— `h <= 2` 与 `h < 5` 中 2 被算两次，或 `h < 2` 与 `h > 5` 中间漏掉 5
2. **边界该用 `>=` 却写成 `>`** —— 分类题最容易丢分的地方
3. **忘了写 `else` 兜底** —— 输入超出预期时什么都不输出
4. **把多分支写成多个 `if`** —— 一个数可能被同时归入两类，输出多行

> **本节小结**：多条件分类的关键是先把区间列清楚、再按从特殊到一般的顺序写条件，最后用 `else` 兜底，让每种输入都有且只有一个归属。

## 知识框架梳理

### 核心概念总结

- **多分支结构**：`if` + 若干 `else if` + 可选 `else`，用于三种以上情况的分类
- **`else if`**：意为"否则，如果"，可以出现任意多次
- **命中即停**：条件成立就执行对应语句体，随后跳出整条多分支
- **兜底 `else`**：前面条件全部不成立时执行，负责覆盖剩余情况

### 语法速查表

| 用途 | 写法 |
| ---- | ---- |
| 多分支骨架 | `if (c1) {} else if (c2) {} else {}` |
| 追加条件 | `else if (条件表达式) { 语句; }` |
| 兜底分支 | `else { 语句; }` |
| 成绩等级 | `if (score >= 90) ... else if (score >= 80) ...` |
| 正负零判断 | `if (n > 0) ... else if (n < 0) ... else ...` |
| 分段计费 | `if (h < 2) ... else if (h < 5) ... else ...` |

### 易错点提醒

1. 条件顺序从小写到大，大条件变成永远执行不到的死代码
2. 区间边界重叠或留缝，某些输入被归入两类或无人接管
3. 把多分支拆成多个独立 `if`，导致同时输出多行
4. 省略最后的 `else`，边界外的输入没有任何输出
5. `elseif` 连写、`else if` 中间漏空格，编译报错
6. `else if (条件);` 多写分号，语句体变空语句
7. `>` 与 `>=` 用混，边界值归属错误

> **本节小结**：多分支结构是分类问题的通用工具，写对它只需记住两句话——条件从特殊到一般排列，区间不重不漏且用 `else` 兜底。
