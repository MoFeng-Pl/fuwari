# 一维数组删除学习笔记

## 1. 尾部删除

删掉最后一个元素最简单：**把有效长度减 1** 即可。

### 语法格式

```cpp
n--;              // 有效长度减 1
```

```cpp
int a[10] = {65, 66, 67, 68};
int n = 4;               // 有效内容是前 4 个

n--;                     // 有效长度变成 3
// 有效内容：{65, 66, 67}
```

### 逻辑删除 vs 物理清除

- **逻辑删除**：只改 `n`，`a[3]` 里的 68 还留在内存里，但已不属于有效数据
- **物理清除**（可选）：`a[n - 1] = 0;` 顺便把残留值抹掉

### 前提

`n` 必须大于 0，空数组不能再删，否则会减成负数，后续遍历条件失效。

> **本节小结**：尾部删除只是"长度减一"，数组容量不变，被删位置的值仍残留但不参与后续处理。

## 2. 指定位置删除

删除下标 x 处的元素，含义是：**让 x 后面的所有元素依次左移一位，把空洞填上**。

### 两个步骤

```cpp
// 下标  0  1  2  3  4
// 原数组 65 66 67 68 69，删除 x = 2 的 67
// 第 1 步：找到要删除的元素（下标 x）
// 第 2 步：把后面的元素依次向左移 1 位
// 结果   65 66 68 69
```

### 完整代码

```cpp
int a[10] = {65, 66, 67, 68, 69};
int n = 5;
int x = 2;

for (int i = x; i < n - 1; i++)
{
    a[i] = a[i + 1];      // 后面的元素往前补
}
n--;                       // 有效长度减一
// 有效内容：{65, 66, 68, 69}
```

### 易错点

只写 `a[x] = 0;` 不算删除，那是"把元素改成 0"，长度和元素顺序都没变。

> **本节小结**：指定位置删除 = 找位置 + 后面元素依次前移 + 长度减一，三步都要做。

---

## 3. 前移补位

前移是删除的核心循环，**必须从左往右**遍历。

### 两种等价写法

```cpp
// 写法一：把左侧下标看作 i，从左往右
for (int i = x; i <= n - 2; i++)
{
    a[i] = a[i + 1];
}

// 写法二：把右侧下标看作 i，从左往右
for (int i = x + 1; i <= n - 1; i++)
{
    a[i - 1] = a[i];
}
```

以 `x = 4`、`n = 11` 为例，两种写法展开后完全一致：

```cpp
// 写法一 (i = 4..9)
a[4]=a[5]; a[5]=a[6]; a[6]=a[7]; a[7]=a[8]; a[8]=a[9]; a[9]=a[10];

// 写法二 (i = 5..10)
a[4]=a[5]; a[5]=a[6]; a[6]=a[7]; a[7]=a[8]; a[8]=a[9]; a[9]=a[10];
```

### 为什么必须从左往右

| 遍历方向 | 过程 | 结果 |
| -------- | ---- | ---- |
| 从左往右 `i++` | 先补 `a[x]`，再把 `a[x+1]` 往前搬 | 正确 |
| 从右往左 `i--` | `a[n-1]` 先覆盖 `a[n-2]`，后面全乱 | 错误 |

前移是"把右边的值写到左边"，源格必须还没被覆盖，所以要先把最左边的空洞填掉。

### 循环边界

- 写法一：`i` 从 `x` 到 `n-2`，`i+1` 最大取到 `n-1`，不越界
- 写法二：`i` 从 `x+1` 到 `n-1`，`i-1` 最小取到 `x`，不漏格
- 若写成 `i <= n-1`（写法一），最后一次会读 `a[n]`，越界

> **本节小结**：前移补位从左往右，两种循环写法只是"以左格还是右格为 i"，展开后完全等价。

## 4. 长度维护

删除改变的是**有效长度**，数组容量始终不变。

### 容量与长度

| 名称 | 含义 | 删除时如何变化 |
| ---- | ---- | -------------- |
| 容量（capacity） | 方括号里的数字 | 不变 |
| 有效长度（effective length） | 实际有用元素个数 | 每删一个减 1 |

### 删除后的维护清单

```cpp
if (n > 0 && x >= 0 && x < n)          // 1. 位置合法、数组非空
{
    for (int i = x; i < n - 1; i++) { a[i] = a[i + 1]; }   // 2. 前移补位
    n--;                                // 3. 长度减一
}
```

### 三点注意

1. `x` 的合法范围是 `0 ~ n-1`，`x == n` 处没有元素可删
2. `n--` 之后，`a[n]` 那个"多出来"的旧值仍在内存里，遍历时不能再算进去
3. 删完若还要遍历输出，上界必须用新的 `n`，用旧的会多打印一个残留值

```cpp
for (int i = 0; i < n; i++) { cout << a[i] << " "; }   // 上界用 n，不是容量
```

### 易错点

前移做完了却忘了 `n--`，最后一个元素会被重复输出一次，这是删除题最常见的错误。

> **本节小结**：删除的完整流程是"判合法 → 前移补位 → `n--`"，容量不变、长度减一，遍历上界必须跟着用新长度。

## 知识框架梳理

### 核心概念总结

- **尾部删除**：`n--;`，可再抹掉残留值 `a[n-1] = 0;`
- **指定位置删除**：找到下标 x，后面元素依次左移一位，再 `n--`
- **前移补位**：`for (int i = x; i < n-1; i++) a[i] = a[i+1];` 必须从左往右
- **长度维护**：容量固定，有效长度每删一次减 1，遍历上界用新长度

### 语法速查表

| 用途 | 写法 |
| ---- | ---- |
| 尾部删除 | `n--;` |
| 清除残留值 | `a[n-1] = 0;` |
| 前移补位（左格视角） | `for (int i = x; i < n-1; i++) a[i] = a[i+1];` |
| 前移补位（右格视角） | `for (int i = x+1; i < n; i++) a[i-1] = a[i];` |
| 长度减一 | `n--;` |
| 位置合法检查 | `if (x >= 0 && x < n)` |
| 删除后遍历 | `for (int i = 0; i < n; i++)` |

### 易错点提醒

1. **把置零当删除**：`a[x] = 0;` 只改值，元素个数没变
2. **前移用逆序**：从右往左搬会连锁覆盖，必须 `i++`
3. **循环边界多走一格**：`i <= n-1` 会读 `a[n]`，越界
4. **忘记 `n--`**：最后一个元素会被重复输出
5. **`x` 超范围**：合法范围是 `0 ~ n-1`，`x == n` 无元素可删
6. **空数组还删**：`n` 减成负数，循环条件全部失效
7. **用容量当遍历上界**：把残留的旧值一并打印出来
8. **两种写法混着写**：统一用左格视角或右格视角，避免边界推理混乱

> **本节小结**：删除是插入的逆操作：从被删位置往后依次前移覆盖，长度减一，末尾那位留作无效数据即可。
