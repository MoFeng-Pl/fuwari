# continue 语句学习笔记

## 1. continue 的作用

**continue** 是 C++ 的另一个循环跳转关键字，作用是**跳过本轮循环剩下的语句，直接进入下一轮**。它与 `break` 长得很像，但结局完全不同：`break` 是"这一圈我不转了"，`continue` 是"这一圈跳过，下一圈继续"。

### 核心概念

- `continue` **只能用在循环中** —— 写在循环外面会直接编译报错
- 它不结束循环，只结束**当前这一轮**
- 跳到哪儿取决于循环种类：`for` 跳到步进表达式，`while` 跳回条件判断
- 通常与 `if` 搭配，用来"过滤掉不需要处理的情况"

### 语法格式

```cpp
for (int i = 1; i <= 10; i++) {
    if (条件) {
        continue;      // 跳过本轮剩下的语句
    }
    // 条件不成立时才会执行到这里
}
```

### 与 if 的等价写法

`continue` 往往可以用"条件取反 + 包一层 `if`"来替代，两者结果相同：

```cpp
// 写法 A：用 continue 提前跳过
for (int i = 1; i <= 10; i++) {
    if (i % 3 == 0) continue;
    cout << i << " ";
}

// 写法 B：条件取反，不用 continue
for (int i = 1; i <= 10; i++) {
    if (i % 3 != 0) {
        cout << i << " ";
    }
}
```

两种写法都输出 `1 2 4 5 7 8 10`。当循环体很长、需要跳过的条件很多时，写法 A 更清晰。

### 易错点

1. **在循环外用 `continue`** —— 编译错误，`continue` 只能出现在循环体内
2. **把 `continue` 当成"退出循环"** —— 它只跳过本轮，循环次数不变
3. **`continue` 后面还写了语句** —— 那些语句在本轮永远不会执行
4. **`if` 后漏花括号** —— `if (条件) continue;` 只带一条语句，但建议统一加 `{}`

> **本节小结**：`continue` 的作用是"跳过本轮、进入下一轮"，只能写在循环里，常与 `if` 搭配做过滤，也可以用"条件取反 + `if`"等价替代。

## 2. for 中 continue 的跳转位置

### 核心概念

在 `for (初值; 条件; 步进)` 中执行 `continue`，程序会**跳过循环体剩余部分**，然后照常执行**步进表达式**（如 `i++`），再判断条件进入下一轮。

也就是说：`for` 里的 `continue` **不会**造成死循环，因为 `i++` 一定会被执行。

### 执行流程

顺序是：`i = 1` → 判断 `i <= 10` → 执行循环体 → 遇到 `continue` → **执行 `i++`（步进）** → 回到条件判断 → 进入下一轮。

### 代码示例：跳过 3 的倍数

```cpp
#include <iostream>
using namespace std;

int main()
{
    for (int i = 1; i <= 10; i++) {
        if (i % 3 == 0) {
            continue;              // 3、6、9 被跳过
        }
        cout << i << " ";
    }
    cout << endl;
    return 0;
}
```

输出 `1 2 4 5 7 8 10`。

### 输出位置决定结果

`continue` 之前的语句照常执行，之后的语句被跳过：

```cpp
for (int i = 1; i <= 5; i++) {
    cout << "处理" << i << endl;   // continue 之前，一定执行
    if (i == 3) continue;
    cout << "保存" << i << endl;   // continue 之后，i=3 时被跳过
}
```

当 `i = 3` 时只打印"处理3"，不打印"保存3"。

### 易错点

1. **以为 `continue` 会跳过 `i++`** —— `for` 的步进属于循环机制，`continue` 跳不过去
2. **把该放前面的语句放到 `continue` 后面** —— 那些语句会被整轮跳过
3. **在 `continue` 之后又写了 `i++`** —— 与 `for` 的步进重复，`i` 每次加 2
4. **以为 `continue` 能跳出循环** —— 那需要 `break`

> **本节小结**：`for` 中的 `continue` 跳到"步进 → 条件判断"，`i++` 不会被跳过，所以不会死循环；把必须执行的语句写在 `continue` 之前即可。

## 3. while 中 continue 的陷阱

### 核心概念

`while` 没有"步进表达式"这个自动环节，循环变量的更新必须**自己写在循环体里**。于是在 `while` 里写 `continue` 就藏着一个经典陷阱：

> `continue` 会跳回条件判断，如果 `i++` 正好写在 `continue` 之后，它就被跳过了 —— **循环变量永远不变，条件永远成立，形成死循环**（infinite loop）。

### 错误示例：死循环

```cpp
int i = 1;
while (i <= 10) {
    if (i % 3 == 0) {
        continue;      // ❌ i++ 在下面，被跳过
    }
    cout << i << " ";
    i++;               // i 为 3 的倍数时永远执行不到
}
```

当 `i` 变成 3 时，`continue` 让程序直接回到 `i <= 10` 的判断，`i` 仍是 3，于是无限重复，什么也不输出。

### 正确写法一：先自增再 continue

```cpp
int i = 1;
while (i <= 10) {
    if (i % 3 == 0) {
        i++;           // ✅ 先更新循环变量
        continue;
    }
    cout << i << " ";
    i++;
}
```

### 正确写法二：干脆改用 for

`for` 的步进由语法保证，不会因为 `continue` 被跳过，所以凡是"计数型循环"都优先用 `for`：

```cpp
for (int i = 1; i <= 10; i++) {
    if (i % 3 == 0) continue;   // 安全，i++ 照常执行
    cout << i << " ";
}
```

### 易错点

1. **`i++` 写在 `continue` 之后** —— 死循环，程序卡住不结束
2. **用 `while` 写计数循环** —— 建议改用 `for`，从语法上避免这个坑
3. **死循环时不加输出** —— 屏幕毫无反应，很容易误以为程序没运行
4. **`do-while` 中同样有这个问题** —— `continue` 会跳到条件判断，同样要保证变量已更新

> **本节小结**：`while` 中的 `continue` 会跳回条件判断，凡是写在它后面的变量更新都会被跳过 —— 解决方法是先自增再 `continue`，或者直接改用 `for`。

## 4. break 与 continue 对比

### 核心概念

| 关键字 | 作用 | 循环是否继续 | 本轮剩余语句 |
| ------ | ---- | ------------ | ------------ |
| `continue` | 跳过本轮 | **继续**下一轮 | 不执行 |
| `break` | 结束循环 | **不再继续** | 不执行 |

一句话记：**`continue` 是"这一轮不算"，`break` 是"到此为止"**。

### 代码对照

```cpp
// continue：输出 1 2 4 5（跳过 3，但继续后面的 4、5）
for (int i = 1; i <= 5; i++) {
    if (i == 3) continue;
    cout << i << " ";
}

// break：输出 1 2（到 3 就整个结束）
for (int i = 1; i <= 5; i++) {
    if (i == 3) break;
    cout << i << " ";
}
```

### 使用场景

| 场景 | 该用哪个 | 理由 |
| ---- | -------- | ---- |
| 过滤掉不符合条件的数据 | `continue` | 其余数据仍要处理 |
| 找到答案就收工 | `break` | 后面的不用再算 |
| 统计 1~100 中所有偶数 | `continue` 或 `if` | 全部数据都要看一遍 |
| 判断素数找到因子 | `break` | 已能确定结果 |

### 易错点

1. **该用 `continue` 时用了 `break`** —— 少处理了后面所有数据
2. **该用 `break` 时用了 `continue`** —— 白白多跑很多轮，甚至死循环
3. **两者混用后逻辑混乱** —— 同一循环里同时出现时要逐行核对流程
4. **嵌套循环里搞错作用范围** —— 两者都只作用于**最内层**循环

> **本节小结**：`continue` 跳过本轮继续下一轮，`break` 直接结束整个循环 —— 需要"过滤"用 `continue`，需要"找到就停"用 `break`，两者都只影响最内层循环。

## 知识框架梳理

### 核心概念总结

- **`continue` 的作用**：跳过本轮剩余语句，直接进入下一轮
- **使用范围**：只能写在循环体内，写在外面编译报错
- **`for` 中的跳转**：跳到步进表达式再判断条件，`i++` 不会被跳过
- **`while` 中的跳转**：跳回条件判断，变量更新写在后面就会死循环
- **与 `break` 的分工**：过滤用 `continue`，提前收工用 `break`
- **等价写法**：`if (a) continue;` 可改写为 `if (!a) { ... }`

### 语法速查表

| 用途 | 写法 |
| ---- | ---- |
| 跳过本轮 | `continue;` |
| 条件跳过 | `if (条件) { continue; }` |
| `for` 中安全使用 | `for (...) { if (条件) continue; ... }` |
| `while` 中安全使用 | `while (...) { i++; if (条件) continue; ... }` |
| 结束整个循环 | `break;` |
| 过滤数据 | `if (不满足) continue;` |
| 找到即停 | `if (满足) break;` |

### 易错点提醒

1. **循环外用 `continue`**：编译错误，它只能出现在循环里
2. **以为 `continue` 会结束循环**：它只跳过本轮，次数不变
3. **`continue` 后还有代码**：本轮那些语句不会执行
4. **`while` 里 `i++` 写在 `continue` 后**：典型死循环陷阱
5. **`for` 里重复写 `i++`**：与步进叠加，每次都加 2
6. **过滤与收工混用**：该 `continue` 的写成 `break` 会漏数据
7. **嵌套中的作用范围**：两者都只结束最内层循环

> **本节小结**：`continue` 只跳过本轮、`break` 直接结束循环，记住"`for` 里安全、`while` 里要先自增"就能避开这个关键字最常见的坑。
