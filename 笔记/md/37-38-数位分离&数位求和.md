# 数位分离与数位求和学习笔记

## 1. 数位分离（`% 10` 与 `/ 10`）

**数位分离**（digit separation）指把一个整数的每一位数字单独取出来，是"把数学问题翻译成程序"的典型场景。C++ 提供两个天然好用的工具：`%` 取余（modulo）取个位，`/` 整除（integer division）去个位。

```cpp
61 % 10  → 1      // 取个位
61 / 10  → 6      // 去个位
123 / 10 → 12     // 去个位
```

`61 = 6 × 10 + 1`，除以 10 剩下的余数 1 正是最低位；`/` 做整除会丢掉小数部分，个位就被砍掉了。注意 `61 / 10` 得 6 而不是 6.1，**两个整数相除结果仍是整数**。

### 两条必须记住的规律

当 `a`、`b` 都是正整数且 `a < b` 时：`a % b` 得到 `a`（如 `5 % 10 = 5`、`4 % 7 = 4`），`a / b` 得到 `0`（如 `5 / 10 = 0`、`4 / 7 = 0`）。

这两条规律决定循环边界：当剩下的数已小于 10，`n % 10` 就是它本身，`n / 10` 直接变成 0，循环正好在这里停。

### 语法格式

```cpp
int ge = n % 10;   // 先取出个位数字
n = n / 10;        // 再去掉个位
```

两句必须**按这个顺序**执行。若先 `/ 10` 再 `% 10`，取到的是十位而不是个位。

### 代码示例

```cpp
int n = 1234;
int ge   = n % 10;          // 4
int shi  = n / 10 % 10;     // 3
int bai  = n / 100 % 10;    // 2
int qian = n / 1000;        // 1
```

规律是"先整除到这一位，再取余"。不知道输入几位时，用 `while` 反复"取个位、去个位"，直到 `n` 变成 0：

```cpp
while (n > 0) {
    int d = n % 10;   // 取出当前个位
    // 在这里处理 d
    n = n / 10;       // 去掉这一位
}
```

### 易错点

1. 把 `/` 写成 `/ 10.0` —— 浮点除法不丢个位，`123 / 10.0` 得到 12.3
2. 两句顺序颠倒 —— 必须先 `% 10` 取位，再 `/ 10` 去位
3. 忘记 `n` 已被修改 —— 循环后 `n` 变成 0，还要用原数须先备份 `int t = n;`
4. 循环条件写 `n >= 0` —— `n` 为 0 时还会多进一次，应写 `n > 0`

> **本节小结**：数位分离只有两个动作 —— `% 10` 取个位、`/ 10` 去个位，按顺序重复执行就能从低位到高位逐位取出所有数字。

## 2. 逆序输出数字

**逆序**（reverse order）指把数字各位从后往前重新排列，如 `1234` 逆序为 `4321`。数位分离天然是**从低位到高位**进行的，所以每取出一位就立刻输出，结果正好是逆序，不需要数组或字符串。

### 语法格式

```cpp
while (n > 0) {
    cout << n % 10;   // 先输出个位
    n = n / 10;       // 再去掉个位
}
```

### 代码示例：逆序输出

```cpp
int n;
cin >> n;              // 输入 1234
while (n > 0) {
    cout << n % 10;    // 依次输出 4 3 2 1
    n = n / 10;
}
```

输入 `1234` 输出 `4321`。

### 逆序成"一个数"

若题目要求逆序后仍是整数（存进变量），需要一个**累加器**（accumulator）把每一位接到新数末尾：

```cpp
int rev = 0;
while (n > 0) {
    rev = rev * 10 + n % 10;   // 已拼好的部分左移一位，再补新位
    n = n / 10;
}
```

以 `n = 123` 追踪：第 1 轮 `rev = 0×10+3 = 3`，`n = 12`；第 2 轮 `rev = 3×10+2 = 32`，`n = 1`；第 3 轮 `rev = 32×10+1 = 321`，`n = 0`。

正序输出则不同：需先逆序存起来，或借助数组、字符串，不能边分离边打印。

### 易错点

1. `rev` 没初始化为 0 —— 局部变量不初始化是随机值，结果完全错乱
2. 写成 `rev = rev + n % 10` —— 少了乘 10 就没有"左移补位"效果
3. 末尾有 0 时以为出错 —— `1200` 逆序成数是 `21`，0 不占位属正常现象
4. 输入 0 时什么都不输出 —— 需要输出 `0` 时要单独特判

> **本节小结**：逆序输出和数位分离是同一件事的两种用法 —— 边分离边打印得到逆序串，用 `rev = rev * 10 + n % 10` 累积则得到逆序数。

## 3. 数位求和

**数位求和**（digit sum）指把整数各位上的数字相加，如 `1234` 的数位和是 `1 + 2 + 3 + 4 = 10`。它和普通求和无本质区别，只是"被加的数"来自数位分离。

### 语法格式

```cpp
int sum = 0;                 // 求和器必须清零
while (n > 0) {
    sum = sum + n % 10;      // 累加当前个位
    n = n / 10;
}
```

### 代码示例

```cpp
int n;
cin >> n;              // 输入 1234

int sum = 0;
while (n > 0) {
    sum += n % 10;     // 等价于 sum = sum + n % 10;
    n /= 10;           // 等价于 n = n / 10;
}
cout << sum << endl;   // 输出 10
```

以 `1234` 追踪：`sum` 依次为 4、7、9、10，`n` 依次为 123、12、1、0。

### 三种写法对比

| 写法 | 代码 | 说明 |
| ---- | ---- | ---- |
| 完整写法 | `sum = sum + n % 10;` | 语义最清楚，推荐初学 |
| 复合赋值 | `sum += n % 10;` | 更简洁，效果相同 |
| 错误写法 | `sum = n % 10;` | 每次都覆盖，最后只剩个位 |

水仙花数需要**数位立方和**，只需换掉累加的那一项：`sum += (n % 10) * (n % 10) * (n % 10);`

### 易错点

1. 忘记 `sum = 0` —— 求和器不清零，垃圾值会混进结果
2. `sum` 定义在循环内部 —— 每轮都重新定义，最终只剩最后一位
3. 大数溢出 —— `int` 上限约 21 亿，超大整数求数位和要用 `long long`
4. 负数输入 —— 负数取余结果为负，`-123` 会算出 `-6`，需先取绝对值

> **本节小结**：数位求和 = 数位分离 + 累加器，循环里一句 `sum += n % 10`、一句 `n /= 10`，四行代码就能解决。

## 4. 数位统计

**数位统计**（digit counting）指在分离数位的过程中统计符合某条件的位数，常见三种：统计**位数**、统计某个**特定数字**出现的次数、统计满足条件的数位个数。

### 代码示例：统计位数

```cpp
int cnt = 0;               // 计数器（counter）
while (n > 0) {
    cnt++;                 // 每分离出一位就记一次
    n = n / 10;
}
```

输入 `1234` 得 `cnt = 4`，输入 `7` 得 `cnt = 1`。

### 代码示例：统计特定数字

```cpp
int cnt = 0;
while (n > 0) {
    if (n % 10 == 3) {     // 只统计数字 3
        cnt++;
    }
    n = n / 10;
}
```

输入 `1335` 输出 `2`。把判断换成 `n % 10 % 2 == 0` 就是统计偶数位个数。

### 一次循环同时求多个量

实际题目往往要求多个结果，放在同一循环里完成即可，不必重复分离：

```cpp
int sum = 0, cnt = 0, maxd = 0;
while (n > 0) {
    int d = n % 10;
    sum += d;                  // 数位和
    cnt++;                     // 位数
    if (d > maxd) maxd = d;    // 最大数位
    n /= 10;
}
```

输入 `5826` 得：位数 4、数位和 21、最大数位 8。注意**求和器**与**计数器**的区别：`sum += x` 加的是"值"，`cnt++` 加的是"1"，两者初值都是 0 但用途不同。

### 易错点

1. `cnt` 与 `sum` 混用 —— 位数用 `cnt++`，数位和用 `sum += d`
2. 忽略 `n` 为 0 的情况 —— `0` 本身是一位数，若题目包含 0 需特判
3. 多个统计分写在不同循环 —— 第二次循环时 `n` 已是 0，什么也统计不到
4. 忘记 `n /= 10` —— 循环永不结束，形成死循环（infinite loop）

> **本节小结**：数位统计就是在数位分离的循环里加上 `if` 判断和计数器 —— 一个循环、一次分离，可同时算出位数、数位和、最值等多种结果。

## 知识框架梳理

### 核心概念总结

- **数位分离**：`% 10` 取个位，`/ 10` 去个位，两句按顺序循环执行
- **两条规律**：正整数 `a < b` 时，`a % b = a`、`a / b = 0`
- **逆序输出**：边分离边打印即逆序；`rev = rev * 10 + n % 10` 累积得逆序数
- **数位求和**：循环内 `sum += n % 10`
- **数位统计**：循环内加 `if` 判断，配合计数器 `cnt++`
- **循环骨架**：`while (n > 0) { ...; n /= 10; }`，`n` 必然收敛到 0

### 语法速查表

| 用途 | 写法 | 示例 |
| ---- | ---- | ---- |
| 取个位 | `n % 10` | `1234 % 10 = 4` |
| 去个位 | `n / 10` | `1234 / 10 = 123` |
| 取十位 | `n / 10 % 10` | `1234 / 10 % 10 = 3` |
| 取百位 | `n / 100 % 10` | `1234 / 100 % 10 = 2` |
| 数位求和 | `sum += n % 10` | `1234` → 10 |
| 位数累加 | `cnt++` | 统计共有几位 |
| 逆序成数 | `rev = rev * 10 + n % 10` | `123` → 321 |
| 分离循环 | `while (n > 0) { ...; n /= 10; }` | 通用模板 |

### 易错点提醒

1. **顺序错**：必须先 `% 10` 再 `/ 10`，反了就取错位
2. **初始化漏**：`sum`、`cnt`、`rev` 都必须先赋 0
3. **原始数据被破坏**：循环结束时 `n` 已是 0，后面要用原数须提前备份
4. **`a / b` 当小数用**：两个整数相除仍是整数，`5 / 10` 得 0 不是 0.5
5. **浮点混入**：写 `n / 10.0` 会得到小数，破坏整数分离
6. **循环条件写 `>= 0`**：`n` 为 0 时仍会进入循环，应写 `> 0`
7. **末尾 0 的逆序**：`1200` 逆序成数是 `21`，属正常现象

> **本节小结**：整篇归结为一个模板 —— `while (n > 0) { 取出 n % 10；处理；n /= 10; }`，把"处理"换成输出、累加或判断，就能解决逆序、求和、统计三大类问题。
