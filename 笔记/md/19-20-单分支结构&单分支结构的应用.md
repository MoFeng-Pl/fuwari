# 单分支结构与应用学习笔记

## 1. if 语句基本语法

让程序根据条件决定"做还是不做"的语句叫**分支结构**（branch structure），也叫**选择结构**。只有一个分支的结构叫**单分支结构**。

### 核心概念

- **条件表达式**（condition expression）：写在 `if` 后面的圆括号里，结果只有"成立"和"不成立"两种
- **语句体**：条件成立时才会执行的那一段代码
- 条件不成立时，程序**整段跳过**语句体，继续往下执行

### 语法格式

```cpp
if (条件表达式)
{
    语句1;
    语句2;
    // ...
}
```

- `if` 是 C++ 关键字（keyword），必须全小写
- 圆括号 `()` 包住条件，**不能省略**
- 大括号 `{}` 包住语句体，必须成对出现
- `if (...)` 这一行末尾**不加分号**，分号只加在语句体内部每条语句的结尾

### 代码示例

```cpp
#include <iostream>
using namespace std;

int main()
{
    int score;
    cin >> score;

    if (score >= 60)
    {
        cout << "及格" << endl;
    }

    cout << "程序结束" << endl;
    return 0;
}
```

输入 `75`，控制台先输出 `及格`，再输出 `程序结束`；输入 `40`，只输出 `程序结束` —— 语句体被整段跳过。

### 易错点

1. `if (score >= 60);` —— 圆括号后多写一个分号，等于语句体变成"空语句"，后面的大括号成了无关代码块
2. 大括号只写一半 —— 建议先写一对 `{}`，再往中间填语句
3. 写成 `If`、`IF` —— C++ **区分大小写**，只有小写 `if` 有效

> **本节小结**：`if (条件) { 语句体 }` 是单分支结构的固定写法，圆括号不能省、大括号要成对、`if` 行末不加分号。

## 2. 判断条件的写法

### 核心概念

条件表达式一般由**关系运算符**（relational operator）和**逻辑运算符**（logical operator）组合而成，计算结果是**逻辑值**（boolean value）：成立为真（true），不成立为假（false）。

### 常用关系运算符

| 运算符 | 含义 | 示例 | 什么时候成立 |
| ------ | ---- | ---- | ------------ |
| `>` | 大于 | `a > b` | a 比 b 大 |
| `<` | 小于 | `a < b` | a 比 b 小 |
| `>=` | 大于等于 | `a >= b` | a 不小于 b |
| `<=` | 小于等于 | `a <= b` | a 不大于 b |
| `==` | 等于 | `a == b` | 两者相等 |
| `!=` | 不等于 | `a != b` | 两者不相等 |

### 三类常见条件

```cpp
// 1. 比较大小
if (a > b) { cout << "a 更大"; }

// 2. 判断奇偶：除以 2 的余数是否为 1
if (n % 2 == 1) { cout << "奇数"; }

// 3. 判断整除：余数是否为 0
if (n % 3 == 0) { cout << "能被 3 整除"; }

// 4. 组合条件：两个条件同时成立
if (a > 0 && a < 100) { cout << "a 在 0 到 100 之间"; }
```

### 真假的判定规则

C++ 不要求条件必须是"逻辑值"，任何数值都能当条件：

- 值为 **0** → 视为**假**（false）
- 值为**非 0** → 视为**真**（true）

所以 `if (1)` 永远成立，`if (0)` 永远不成立；`a > b` 成立时得到 `1`，不成立时得到 `0`。

### 易错点

1. **`==` 写成 `=`**：`if (a = 5)` 是赋值，把 5 塞进 a 再拿 5 判断真假，条件永远成立
2. **浮点数不要直接用 `==`**：`0.1 + 0.2 == 0.3` 因精度误差可能不成立，应改判两者差值足够小
3. **条件里重复写"是否成立"**：`if (a > b == true)` 多余且易错，直接写 `if (a > b)`

> **本节小结**：判断条件用关系运算符比较、用逻辑运算符组合，0 为假非 0 为真；最容易踩的坑是把 `==` 写成 `=`。

## 3. 单分支的特殊结构

### 核心概念

当 `if` 的语句体**只有一条语句**时，大括号可以省略，这就是单分支结构的**特殊格式**（省略形式）。

### 语法格式

```cpp
if (条件表达式)
    语句;
```

只有这一行语句受 `if` 控制，前面的缩进（indentation）用来提示"这条语句属于 if"。

### 两种格式对比

| 对比项 | 标准格式 | 特殊格式 |
| ------ | -------- | -------- |
| 大括号 | 必须有 | 单条语句时可省略 |
| 可容纳语句数 | 任意多条 | 只有一条 |
| 可读性 | 好 | 尚可，但容易被看错 |
| 推荐度 | 推荐 | 仅用于极短语句 |

### 代码示例

```cpp
int a = 10;

// 标准格式
if (a > 5)
{
    cout << "大于 5" << endl;
}

// 特殊格式：只有一条语句，省略大括号
if (a > 5)
    cout << "大于 5" << endl;

// 省略大括号后又补了第二条语句 —— 第二条不受 if 控制
if (a > 5)
    cout << "大于 5" << endl;
cout << "这句话一定会输出" << endl;
```

### 易错点

1. 省略大括号后**只能管一条语句**，从第二条起就不再受条件控制
2. 缩进只是给人看的，编译器**不认缩进** —— 靠缩进"假装"包含多条语句完全无效
3. 后期维护时往单语句分支里加代码，忘记补回大括号，是最常见的隐蔽 bug

> **本节小结**：单条语句时大括号可省，但一旦要写第二条语句就必须补回大括号，否则只有第一条受条件控制。

## 4. 应用：单条件判断

### 核心概念

单分支结构最典型的用途是：**满足条件就做某件事，不满足就什么也不做**。

### 解题四步

1. 读入数据
2. 写出判断条件
3. 在语句体里写"条件成立时要执行的动作"
4. 输出结果

### 代码示例：判断能否被 3 整除

```cpp
#include <iostream>
using namespace std;

int main()
{
    int n;
    cin >> n;

    if (n % 3 == 0)
    {
        cout << "yes" << endl;
    }

    return 0;
}
```

输入 `12` 输出 `yes`；输入 `7` 不输出任何内容，程序安静结束。

### 常见应用场景

| 场景 | 条件写法 |
| ---- | -------- |
| 判断及格 | `score >= 60` |
| 判断偶数 | `n % 2 == 0` |
| 判断正数 | `n > 0` |
| 判断区间 | `n >= 1 && n <= 100` |
| 判断能否被 3 整除 | `n % 3 == 0` |

### 易错点

1. **条件写反** —— 想判断"及格"却写成 `score < 60`
2. **把"没有输出"当成程序出错** —— 单分支本来就可能什么都不做
3. **语句体有多条语句却漏掉大括号** —— 只有第一条会被条件控制

> **本节小结**：单条件判断的套路是"读入 → 写条件 → 写动作 → 输出"，条件成立才执行语句体，不成立就静默跳过。

## 知识框架梳理

### 核心概念总结

- **分支结构**：根据条件的真假决定是否执行某段代码
- **单分支结构**：只有一个 `if`，条件成立执行、不成立跳过
- **条件表达式**：由关系运算符或逻辑运算符组成，0 为假、非 0 为真
- **语句体**：受 `if` 控制的代码，用 `{}` 括起来

### 语法速查表

| 用途 | 写法 |
| ---- | ---- |
| 标准单分支 | `if (条件) { 语句; }` |
| 省略大括号 | `if (条件) 语句;` |
| 大于 / 小于 | `a > b`、`a < b` |
| 大于等于 / 小于等于 | `a >= b`、`a <= b` |
| 等于 / 不等于 | `a == b`、`a != b` |
| 判断偶数 | `n % 2 == 0` |
| 判断整除 | `n % 3 == 0` |
| 区间判断 | `n >= 1 && n <= 100` |

### 易错点提醒

1. `if (条件)` 后面多写一个分号，语句体变成空语句
2. `==` 写成 `=`，条件恒成立且悄悄改掉了变量的值
3. 省略大括号后写了多条语句，只有第一条受控
4. 以为缩进能决定作用范围，编译器只认大括号
5. 关键字、`cout`、`endl` 全部小写，写成 `If` 直接编译报错
6. 条件里画蛇添足写 `== true`，`if (a > b == true)` 容易引发优先级错误

> **本节小结**：单分支结构是分支家族的起点，掌握"条件怎么写、语句体怎么括、真假怎么判"这三条，就能覆盖所有单条件判断题。
