# while 循环学习笔记

## 1. while 语法

### 核心概念

`while` 是 C++ 的另一种循环语句。它只有一个条件表达式，**条件成立就执行循环体，执行完再回来判断**，如此反复，直到条件不成立为止。

和 `for` 相比，`while` 把「初值」和「步进」都交给了程序员自己安排，圆括号里只留条件，所以结构更自由，但对写法正确性的要求也更高。

### 语法格式

```cpp
while (条件表达式)
{
    循环体;
}
```

- **条件表达式**：一个关系表达式或逻辑表达式，为真时进入循环体
- **循环体**（loop body）：花括号里被重复执行的语句
- 圆括号后**不要**加分号，`while (...);` 会变成空循环体
- 循环体超过一条语句时必须加花括号

### 执行流程

计算条件 → 为真则执行一次循环体 → 回到条件重新判断 → 为假则跳出循环。`while` 是**先判断、后执行**，所以循环体有可能一次都不执行。

### 代码示例

```cpp
int i = 1;
while (i <= 5)
{
    cout << i << " ";
    i = i + 1;
}
cout << "结束";
```

输出 `1 2 3 4 5 结束`。如果一开始条件就不成立（例如把初值写成 `int i = 10;`），循环体一次也不执行，直接输出 `结束`。

### 易错点

1. 循环体里忘记更新变量，条件永远为真，变成死循环
2. 圆括号后面多写分号，循环体变成空语句，看起来「什么都没发生」
3. 忘了给循环变量赋初值就写 `while (i <= 5)`，次数无法控制

> **本节小结**：`while` 只保留条件，先判断后执行，循环体可能一次都不跑；初值和步进要自己写在循环外面和循环体里面。

## 2. while 与 for 的转换

### 核心概念

`for` 和 `while` 能够表达完全相同的循环逻辑，只是三要素摆放的位置不同。`for` 把三要素挤在一行里，`while` 把它们拆开写。

| 要素 | 在 for 中的位置 | 在 while 中的位置 |
| ---- | --------------- | ----------------- |
| 初值 | 圆括号第一段 | 循环**之前**单独写 |
| 条件 | 圆括号第二段 | 圆括号里 |
| 步进 | 圆括号第三段 | 循环体**末尾** |
| 循环体 | 花括号内 | 花括号内 |

### 代码示例

同一段逻辑的两种写法，输出都是 `1 2 3 4 5`：

```cpp
// for 版本
for (int i = 1; i <= 5; i = i + 1)
{
    cout << i << " ";
}
```

```cpp
// while 版本
int i = 1;
while (i <= 5)
{
    cout << i << " ";
    i = i + 1;
}
```

把 `for` 改写成 `while` 只需三步：初值提到循环前、条件留在括号里、步进搬到循环体最后。

### 选择建议

| 场景 | 推荐写法 | 原因 |
| ---- | -------- | ---- |
| 循环次数已知 | `for` | 三要素集中，次数一眼可见 |
| 循环次数未知 | `while` | 只需写清「什么时候继续」 |
| 需要遍历区间 | `for` | 初值与边界表达清晰 |
| 依赖输入或状态变化 | `while` | 条件可以随时变化 |

### 易错点

1. 从 `for` 改 `while` 时漏搬步进，直接变成死循环
2. `for` 里的 `int i` 出了循环就失效，改 `while` 时把 `int i = 1;` 写在循环前面即可
3. 两种写法混着用没关系，但同一个循环不要又写 `for` 又在里面手动改三要素

> **本节小结**：`for` 和 `while` 可以互相改写，口诀是「初值提前、条件留括号、步进放末尾」；次数确定用 `for`，次数不定用 `while`。

## 3. 未知次数的循环

### 核心概念

有些问题事先无法知道要循环多少次，只能用「什么时候停止」来描述，这正是 `while` 的主场。

常见的三类未知次数场景：

| 场景 | 停止条件 | 写法 |
| ---- | -------- | ---- |
| 数据读到结束 | 读不到数据 | `while (cin >> x)` |
| 遇到特殊值 | 读到 0 或 -1 | `while (x != 0)` |
| 数字被拆完 | 数字变成 0 | `while (n > 0)` |

### 代码示例

一、一直读到输入结束，边读边累加：

```cpp
int x;
int sum = 0;
while (cin >> x)
{
    sum += x;
}
cout << sum;
```

二、把数字一位一位拆开（数位分离）：

```cpp
int n = 12345;
while (n > 0)
{
    cout << n % 10 << " ";   // 取出最后一位
    n = n / 10;              // 去掉最后一位
}
```

输出 `5 4 3 2 1`。循环次数等于数字的位数，事先并不知道。

### 易错点

1. `while (cin >> x)` 的循环体里不要再写一次 `cin >> x`，会一次读走两个数据
2. 以特殊值结束时，循环体末尾必须再读一次，否则条件永远不变
3. 数位分离的循环体里漏写 `n = n / 10;`，`n` 永远不变，死循环
4. 本地运行时需要按 `Ctrl + Z`（Windows）或 `Ctrl + D`（Linux）结束输入，否则会一直等待

> **本节小结**：次数未知时，把注意力放在「什么条件下继续、什么条件下停止」上，`while` 会替你一直跑到条件不成立。

## 4. 死循环与退出条件

### 核心概念

**死循环**（infinite loop，也叫无限循环）是条件永远为真、循环永不结束的状态。它有时是错误，有时是刻意设计。

判断一个 `while` 会不会变成死循环，只看一件事：**循环体里有没有让条件最终变成假的动作**。这个动作就是**退出条件**（exit condition）。

### 常见的死循环原因

| 原因 | 示例 | 后果 |
| ---- | ---- | ---- |
| 忘记更新变量 | `while (i <= 5) { cout << i; }` | i 永远是 1 |
| 更新方向反了 | `while (i <= 5) { i--; }` | i 越来越小 |
| 更新语句写在 `continue` 之后 | 被跳过，变量不变 | 永远停在同一个值 |
| 条件表达式恒为真 | `while (1)` | 只能靠 `break` 退出 |

### 代码示例

漏写步进的错误写法：

```cpp
int i = 1;
while (i <= 5)
{
    cout << i << " ";     // 漏了 i = i + 1，程序卡死
}
```

在 `cout` 之后补上 `i = i + 1;` 就是正确写法，正是第 1 节里那个循环。

有意为之的无限循环，用 `break` 控制出口：

```cpp
int x;
while (true)
{
    cin >> x;
    if (x == 0)
    {
        break;            // 读到 0 立即跳出循环
    }
    cout << x << " ";
}
```

循环条件写成常量 `1` 或 `true` 时，循环体里必须有 `break`，否则程序真的停不下来。

### 易错点

1. `while (i <= 5)` 里只输出 `i` 不修改 `i`，是最典型的死循环
2. 把步进写成 `i + 1;`（不赋值），循环变量不变
3. `while (cin >> x)` 之后又用 `while (true)` 忘了 `break`，输入结束也退不出去
4. 死循环时程序界面看起来「卡住不动」，其实还在跑，需要手动终止

> **本节小结**：每个 `while` 都要能回答「循环体里哪一句会让条件最终变假」；答不上来的循环就是死循环，有意写无限循环时必须配 `break`。

## 知识框架梳理

### 核心概念总结

- **while**：先判断后执行的循环，圆括号里只有条件，循环体可能一次都不执行
- **三要素搬家**：`for` → `while` 时，初值提前、条件留括号、步进放末尾
- **未知次数的循环**：`while (cin >> x)`、`while (x != 0)`、`while (n > 0)` 是三种常用形态
- **死循环**（infinite loop）：条件恒为真；退出条件（exit condition）必须写在循环体里

### 语法速查表

| 用途 | 写法 |
| ---- | ---- |
| while 基本结构 | `while (条件) { 循环体 }` |
| 计数循环 | `int i = 1; while (i <= n) { ...; i++; }` |
| 读到输入结束 | `while (cin >> x) { ... }` |
| 遇到 0 停止 | `while (x != 0) { ...; cin >> x; }` |
| 数位分离 | `while (n > 0) { ...; n /= 10; }` |
| 无限循环 | `while (true) { ...; if (...) break; }` |
| 提前跳出 | `break;` |
| 跳过本轮 | `continue;` |

### 易错点提醒

1. **漏写步进**：`while` 不会自动推进变量，必须手写
2. **圆括号后加分号**：`while (...);` 是空循环体
3. **先判断后执行**：条件一开始为假时，循环体一次也不执行
4. **`for` 改 `while` 漏搬初值**：循环变量没定义或用错旧值
5. **特殊值结束要重读**：循环体末尾必须有下一次 `cin`
6. **`continue` 跳过更新**：步进写在 `continue` 之前才安全
7. **无限循环必须有 `break`**：否则程序无法正常结束

> **本节小结**：`while` 的全部要点可以压缩成两句——「条件写清、变量要动」；条件负责决定跑多久，变量的变化负责让条件最终失效。
