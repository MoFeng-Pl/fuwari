# 关系运算符与应用学习笔记

## 1. 认识关系运算符

**关系运算符**（relational operator）用来比较两个值的大小或是否相等，是"判断"在代码里的写法，结果只有"成立"和"不成立"两种。

### 核心概念

| 含义 | 大于 | 大于或等于 | 小于 | 小于或等于 | 等于 | 不等于 |
| ---- | ---- | ---- | ---- | ---- | ---- | ---- |
| 符号 | `>` | `>=` | `<` | `<=` | `==` | `!=` |

`>=` 和 `<=` 的含义是：**只要满足其中一个条件，表达式就成立**。所以 `10 >= 10` 成立——虽然不大于，但等于；而 `10 > 10` 要求严格大于，不成立。

### 代码示例

```cpp
#include <iostream>
using namespace std;
int main()
{
    cout << (10 > 3) << "\n";     // 1，成立
    cout << (10 >= 10) << "\n";   // 1，等于也算成立
    cout << (10 > 10) << "\n";    // 0，不成立
    return 0;
}
```

### 易错点

1. 把"等于"写成 `=`——单个等号是**赋值**，`a = 5` 是把 5 存进 `a`
2. 把"不等于"写成 `<>`——C++ 里是 `!=`
3. 符号中间加空格或写反顺序（`> =`、`=>`）——编译都不通过

> **本节小结**：关系运算符共六个 `> >= < <= == !=`，用来比较两个操作数；`>=`、`<=` 只要"大于"或"等于"成立其一就算成立，`==` 判断相等、`!=` 判断不等，千万别和赋值号 `=` 混用。

## 2. 关系表达式的值（逻辑值）

关系表达式算出来的不是普通数字，而是**布尔值**（boolean，逻辑值）：成立得 `1`，不成立得 `0`。

### 核心概念

| 结果值 | 中文 | 英文 | 含义 |
| ---- | ---- | ---- | ---- |
| `1` | 真 | true | 关系成立 |
| `0` | 假 | false | 关系不成立 |

输出关系表达式时**必须加上括号**：`cout << (23 < 24);`。因为 `<<` 的优先级比关系运算符高，写成 `cout << 23 < 24` 会先把 `cout << 23` 算完（输出 23），再去比较，结果完全不对。

### 代码示例

```cpp
#include <iostream>
using namespace std;
int main()
{
    cout << (23 < 24) << "\n";   // 1，成立
    cout << (1 > 2) << "\n";     // 0，不成立
    int r = (5 < 3);             // 结果存进 int，r 是 0
    return 0;
}
```

### 易错点

1. 输出时漏括号——最常见的报错来源
2. 以为结果是"成立/不成立"几个字——屏幕上只有 `1` 或 `0`
3. 以为 `0` 是"没有值"——`0` 是有效结果，代表假

> **本节小结**：关系表达式的值只有 `1`（真 / true / 成立）和 `0`（假 / false / 不成立），输出时一定要用括号把整个表达式括起来，否则会因优先级问题先输出左操作数。

## 3. 比大小

**字符类型参与关系运算时，用对应的 ASCII 码值进行比较**，所以字符比较、字符与数字比较，本质上都是整数比较。

### 核心概念

| 字符 | `'0'` 到 `'9'` | `'A'` 到 `'Z'` | `'a'` 到 `'z'` |
| ---- | ---- | ---- | ---- |
| ASCII 码值 | 48 到 57 | 65 到 90 | 97 到 122 |

课件给的两个例子：`60 < 'A'` 成立，因为 `'A'` 是 65；`'0' > 1` 成立，因为 `'0'` 是 48。可见字符 `'0'` 并不等于数字 0。

### 代码示例

```cpp
#include <iostream>
using namespace std;
int main()
{
    cout << (60 < 'A') << "\n";    // 1，'A' 是 65
    cout << ('0' > 1) << "\n";     // 1，'0' 是 48
    cout << ('a' > 'A') << "\n";   // 1，97 > 65
    return 0;
}
```

### 易错点

1. 以为 `'0'` 和 `0` 相等——`'0'` 是 48
2. 以为大写字母比小写字母大——反了，大写 65 起、小写 97 起
3. 用双引号写字符——`"a" > "b"` 比较的不是字符

> **本节小结**：字符参与关系运算时自动换成 ASCII 码值再比，因此 `60 < 'A'`、`'0' > 1` 都成立；记住三段区间 48~57、65~90、97~122，字符之间的大小关系就一目了然。

## 4. 负数取余

关系运算符常和取余 `%` 搭配，带负号的取余要按两步算：**第 1 步去掉负号进行计算，第 2 步结果有无负号看被除数**。被除数有负号，结果就有负号；被除数没有负号，结果也没有负号——**结果符号只跟被除数走，与除数无关**。

| 表达式 | 第 1 步 | 第 2 步 | 结果 |
| ---- | ---- | ---- | ---- |
| `10 % 3` | 10 ÷ 3 余 1 | 被除数无负号 | `1` |
| `-10 % 3` | 10 ÷ 3 余 1 | 被除数有负号 | `-1` |
| `10 % -3` | 10 ÷ 3 余 1 | 被除数无负号 | `1` |

### 代码示例

```cpp
#include <iostream>
using namespace std;
int main()
{
    cout << 10 % 3 << "\n";     // 1
    cout << -10 % 3 << "\n";    // -1
    cout << 10 % -3 << "\n";    // 1
    cout << (-9 % 3 == 0);      // 1，能被 3 整除
    return 0;
}
```

### 易错点

1. 以为 `10 % -3` 是 `-1`——结果符号只看被除数，是 `1`
2. 把 `%` 当"除以"——`10 % 3` 得余数 1，不是 3
3. 除数为 0——`10 % 0` 运行崩溃（`RE`）

> **本节小结**：负数取余分两步——先去掉负号算出数值，再由**被除数**的符号决定结果符号；因此 `-10 % 3` 是 `-1`，而 `10 % -3` 仍是 `1`。

---

## 5. 判断奇偶

取余运算最典型的应用就是判断整数的奇偶。

### 核心概念

**是 2 的倍数的数叫作偶数**（even number），**0 也是偶数**；**不是 2 的倍数的数叫作奇数**（odd number）。课件用一条链展示 `n % 2 == 0` 的走向：结果为 `1` 时表达式成立、余数是 0、`n` 是偶数；结果为 `0` 时表达式不成立、余数不是 0、`n` 是奇数。

| `n % 2` 的结果 | 说明 | 结论 |
| ---- | ---- | ---- |
| `0` | 余数是 0，能被 2 整除 | `n` 是偶数 |
| `1` | 余数不是 0，不能被 2 整除 | `n` 是奇数 |

### 代码示例

```cpp
#include <iostream>
using namespace std;
int main()
{
    int n = 7;
    cout << (n % 2 == 0) << "\n";   // 0，不成立，是奇数
    cout << (n % 2 != 0) << "\n";   // 1，成立，是奇数
    int m = 8;
    cout << (m % 2 == 0);           // 1，是偶数
    return 0;
}
```

### 易错点

1. 把 `0` 当奇数——0 能被 2 整除，是偶数
2. 用 `n % 2 == 1` 判断负数奇数——`-7 % 2` 得 `-1`，条件不成立，应写 `n % 2 != 0`
3. 写成 `n % 2 = 0`——单等号是赋值，必须用 `==`

> **本节小结**：偶数就是 2 的倍数（含 0），奇数是其补集；判断时对 2 取余，`n % 2 == 0` 成立为偶数、不成立为奇数，负数场景建议用 `n % 2 != 0` 判奇数。

## 6. 判断整除

**`x` 能否被 `a` 整除，就是 `x` 对 `a` 取余，看余数是否为 0**——奇偶判断正是它取 `a = 2` 时的特例。

### 核心概念

| `x % a` 的结果 | `x % a == 0` | 结论 |
| ---- | ---- | ---- |
| `0` | 结果 `1`，成立 | `x` 能被 `a` 整除 |
| 非 `0` | 结果 `0`，不成立 | `x` 不能被 `a` 整除 |

### 代码示例

```cpp
#include <iostream>
using namespace std;
int main()
{
    int x = 12, a = 4;
    cout << (x % a == 0) << "\n";     // 1，12 能被 4 整除
    cout << (15 % 4 == 0) << "\n";    // 0，不能整除
    cout << (7 % 7 == 0) << "\n";     // 1，能被自己整除
    return 0;
}
```

需要"同时被多个数整除"时，用 `&&` 连接两个条件，例如 `x % 2 == 0 && x % 3 == 0`。

### 易错点

1. 用 `x / a == 0` 判断整除——除法的结果不是余数
2. 用 `x % a == 1` 当整除条件——只有余数为 0 才叫整除
3. 判断"同时被多个数整除"时用 `||`——必须用 `&&`

> **本节小结**：判断 `x` 能否被 `a` 整除，就看 `x % a` 是否为 0，写成 `x % a == 0`；奇偶判断是它在 `a = 2` 时的特例，多个数同时整除则用 `&&` 连起来。

## 知识框架梳理

### 核心概念总结

- **六个关系运算符**：`> >= < <= == !=`，结果是布尔值
- **逻辑值**：成立得 `1`（真 / true），不成立得 `0`（假 / false）
- **字符比较**：换成 ASCII 码值再比，数字 48~57 < 大写 65~90 < 小写 97~122
- **负数取余**：先去掉负号算数值，结果符号看**被除数**
- **判奇偶 / 判整除**：`n % 2 == 0`、`x % a == 0`，成立即为真

### 语法速查表

| 用途 | 写法 | 示例结果 |
| ---- | ---- | ---- |
| 大于 | `>` | `10 > 3` → `1` |
| 大于或等于 | `>=` | `10 >= 10` → `1` |
| 小于 | `<` | `3 < 10` → `1` |
| 等于 | `==` | `5 == 5` → `1` |
| 不等于 | `!=` | `5 != 5` → `0` |
| 输出关系结果 | `cout << (表达式);` | `cout << (23 < 24);` |
| 判断偶数 | `n % 2 == 0` | `8 % 2 == 0` → `1` |
| 判断整除 | `x % a == 0` | `12 % 4 == 0` → `1` |

### 易错点提醒

1. **`=` 与 `==`**——单等号赋值，双等号才比较
2. **`>=` 与 `>`**——`>=` 包含等于，`10 >= 10` 成立而 `10 > 10` 不成立
3. **输出漏括号**——`cout << (a < b);`，不加括号会先输出左操作数
4. **`'0'` 不是 `0`**——字符 `'0'` 的码值是 48
5. **大小写顺序**——数字字符 < 大写字母 < 小写字母
6. **负数取余符号**——看被除数，`-10 % 3` 是 `-1`，`10 % -3` 是 `1`
7. **0 是偶数**——能被 2 整除，不要判成奇数；判整除只能比余数 0
