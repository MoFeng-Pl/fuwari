# OJ 系统与 ASCII 码学习笔记

## 1. OJ 系统与判题流程

**OJ**（Online Judge，在线评测系统）是提交代码、自动判分的平台。它不看代码写了什么，只看程序在给定输入下输出什么。

### 核心概念

- **题目**：给出背景、输入格式、输出格式和若干组样例
- **样例**（sample）：题面公开的示范数据，用来自测，**不是全部测试数据**
- **控制台**：显示输入的窗口叫**输入区**，显示结果的叫**输出区**

### 样例测试三步操作

| 步骤 | 操作 | 课件的实际结果 |
| ---- | ---- | ---- |
| 01 | 打开控制台，出现输入区和输出区 | 控制台按钮在编辑器右侧 |
| 02 | 在输入区输入**单个样例**的输入内容 | 输入 `10` |
| 03 | 点击「运行」查看输出区的结果 | 输出 `10`，显示「编译成功」，并给出耗时 27ms、内存 1.4297M |

### 代码示例

```cpp
#include <iostream>
using namespace std;
int main()
{
    int n;
    cin >> n;
    cout << n;
    return 0;
}
```

### 易错点

1. 输入区敲了数字却忘了点「运行」——程序根本没执行
2. 把答案写死，如 `cout << 10;`——样例过了，换组数据立刻 `WA`
3. 以为样例对就是全对——样例只是题面公开的少量数据

> **本节小结**：本地自测按「开控制台 → 填输入 → 点运行」三步走，提交后由服务器编译、逐组运行、逐字符比对，全部测试点通过才是 `AC`。

## 2. OJ 常见易错点

初学阶段丢分，多数不是算法不会，而是格式和细节出错。OJ 的比对是**逐字符**的：答案一样但多一个空格、少一个换行，都可能判 `PE` 或 `WA`。

### 常见错误对照

| 错误 | 错误写法 | 正确写法 | 后果 |
| ---- | ---- | ---- | ---- |
| 多输出提示语 | `cout << "请输入：";` | 直接读入 | `WA` |
| 多输出解释文字 | `cout << "答案是" << s;` | `cout << s;` | `WA` |
| 数字间少空格 | `cout << a << b;` | `cout << a << " " << b;` | `PE` |
| 行末多空格 | `cout << a << " ";` | 行末不加空格 | `PE` |

### 输入与规模类错误

1. **读入顺序写反**：题面先给 `n` 再给 `m`，代码却先读 `m`
2. **多读一次**：`while (cin >> x)` 循环体内又读一次，会跳过数据
3. **类型不匹配**：答案可能超出 `int` 范围时仍用 `int`，溢出后变负
4. **数组开太小**：题面写 `n ≤ 1000`，数组只开 `a[100]`，循环次数也不能照抄样例

### 易错点

1. 调试用的 `cout << "调试中"` 忘了删——交上去必 `WA`
2. 大批量输出用 `endl` 逐行刷新——可能 `TLE`，优先用 `\n`
3. 多组数据时累加变量忘了清零——第二组结果被污染

> **本节小结**：OJ 比对细到每个字符，多余的提示语、缺失的空格、写死的样例答案都会判错；提交前核对输入顺序、数据规模和输出格式。

## 3. 复杂输入输出格式

真实题目很少只给一组数据，常见三种输入形态。

### 三种形态

| 形态 | 题面常见表述 | 读法 |
| ---- | ---- | ---- |
| 单组 | 输入一行，两个整数 | `cin >> a >> b;` |
| 给定组数 | 第一行一个整数 `T`，表示数据组数 | `cin >> T; while (T--)` |
| 读到结束 | 输入包含多组数据，读到文件末尾 | `while (cin >> n)` |

组数不定时靠 **EOF**（End Of File，文件结束）判断：`cin >> n` 读到末尾返回假，循环自动退出。

### 代码示例

```cpp
int T;
cin >> T;
while (T--)          // 循环 T 次，每次处理一组
{
    int a, b;
    cin >> a >> b;
    cout << a + b << "\n";
}
```

### 输出格式要求

1. **同一行多个结果**用空格分隔：`cout << a << " " << b << "\n";`
2. **每组结果占一行**：循环体内每条输出都以 `\n` 结尾
3. **行末不留空格**：空格只在两数之间加；小数按题意保留位数

### 易错点

1. `while (cin >> n)` 中把读入写进循环体——会跳过一半数据
2. 用 `T--` 却又在循环体内改动 `T`
3. 多组数据时累加变量没在每组开头清零
4. 行末多打一个空格——严格比对的 OJ 会判 `PE`

> **本节小结**：复杂输入先判断「有几组、怎么知道结束」，再选单次读、`while(T--)` 或 `while(cin >> n)`；输出则严格照题意控制空格与换行。

## 4. ASCII 码基础

计算机内部只能存数字，字符必须先**编码**成整数，这套编码就是 **ASCII 码**（American Standard Code for Information Interchange，美国信息交换标准代码）。每个字符对应一个 0~127 的整数，即它的 ASCII 码值。

### 大小规则与常用码值

比较两个字符，比的就是它们的 ASCII 码值，大小顺序是：**数字字符 < 大写字母 < 小写字母**。

| 字符 | 空格 | `'0'` | `'A'` | `'a'` |
| ---- | ---- | ---- | ---- | ---- |
| ASCII 码 | 32 | 48 | 65 | 97 |

由此推出三段连续区间：`'0'`~`'9'` 是 48~57，`'A'`~`'Z'` 是 65~90，`'a'`~`'z'` 是 97~122。同一字母大小写的码值之差固定是 **32**：`'a' - 'A' == 32`。

### 代码示例

```cpp
#include <iostream>
using namespace std;
int main()
{
    cout << 'A' - 0 << "\n";    // 65
    cout << 'a' - 0 << "\n";    // 97
    return 0;
}
```

### 易错点

1. 把字符 `'0'` 与数字 `0` 混为一谈——`'0'` 的码值是 48
2. 字符常量用双引号——`"A"` 是字符串，`'A'` 才是字符
3. 记混大小顺序——是**数字 < 大写 < 小写**，不是大写最小

> **本节小结**：记住空格 32、`'0'` 48、`'A'` 65、`'a'` 97 四个锚点，配合「数字 < 大写 < 小写」和大小写差 32 的规律，就能推出全部常用码值。

## 5. 计算 ASCII 码

`char` 本质上存的就是一个整数（码值）。字符参与算术运算时，C++ 先取出码值再按整数规则计算，结果为 `int`。

### 语法格式

课件的口诀是：**快速输出某个字符的 ASCII 码值——字符 - 0**，即 `cout << 字符 - 0;`。

### 代码示例

```cpp
#include <iostream>
using namespace std;
int main()
{
    cout << 'A' - 0;       // 输出 65
    return 0;
}
```

把 `'A'` 换成任意字符都能拿到码值：`'a' - 0` 得 97、`'0' - 0` 得 48、`'Z' - 0` 得 90。既然 `'0'` 的码值是 48，「数字字符 ↔ 数字」就用固定偏移换算：`ch - '0'` 把字符转成数字，`num + '0'` 把数字转回字符。

```cpp
char ch = '7';
int num = ch - '0';        // 55 - 48 = 7，字符转数字
char back = num + '0';     // 7 + 48 = '7'，数字转字符
```

### 易错点

1. 写成 `'A' - '0'`——得到 17，不是 65
2. 结果赋给 `char`——会变回字符，输出字母本身而非数字
3. 用双引号写 `"A" - 0`——字符串不能这样参与运算

> **本节小结**：`字符 - 0` 就能打印 ASCII 码值，因为字符参与运算时自动取码值；再结合 `- '0'` 与 `+ '0'`，就能在数字与数字字符之间自由转换。

## 6. 大小写字母转换

同一字母的大写与小写码值**正好相差 32**，且小写更大：小写 `- 32` 变大写，大写 `+ 32` 变小写。对非字母字符做这个运算只会得到**无意义的符号**，所以转换前要先用 `c >= 'a' && c <= 'z'` 判断类型。

### 语法格式

小写变大写是 `字符 - 32`（97 → 65），大写变小写是 `字符 + 32`（65 → 97）。

### 代码示例

```cpp
#include <iostream>
using namespace std;
int main()
{
    char ch = 'a' - 32;
    cout << ch << "\n";    // 97 - 32 = 65，输出 A
    char ch2 = 'A' + 32;
    cout << ch2;           // 65 + 32 = 97，输出 a
    return 0;
}
```

### 易错点

1. 方向搞反——小写变大写是**减** 32，不是加
2. 记成 26——差值固定是 32，因为大写与小写之间隔着 6 个符号
3. 结果赋给 `int` 再输出——会打印 65 而不是 `A`

> **本节小结**：大小写互为「加减 32」的关系，`- 32` 变大写、`+ 32` 变小写；实际使用时先用范围判断确认是字母，再做转换。

## 知识框架梳理

### 核心概念总结

- **OJ 流程**：开控制台 → 填样例 → 点运行 → 看结果；提交后编译、运行、逐字符比对，判定有 `AC`、`WA`、`PE`、`TLE`、`RE`、`CE`
- **输入形态**：单组、给定组数 `while (T--)`、读到结束 `while (cin >> n)`
- **ASCII 码**：空格 32、`'0'` 48、`'A'` 65、`'a'` 97；数字 < 大写 < 小写
- **取码值**：`字符 - 0`；**大小写转换**：小写 `- 32`，大写 `+ 32`

### 语法速查表

| 用途 | 写法 |
| ---- | ---- |
| 读取指定组数 | `cin >> T; while (T--) { ... }` |
| 读到输入结束 | `while (cin >> n) { ... }` |
| 同行空格分隔 | `cout << a << " " << b << "\n";` |
| 取字符 ASCII 码值 | `cout << 'A' - 0;` |
| 数字字符转数字 | `ch - '0'` |
| 数字转数字字符 | `num + '0'` |
| 小写转大写 | `ch - 32` |
| 大写转小写 | `ch + 32` |

### 易错点提醒

1. **样例不等于全部数据**——写死答案必 `WA`
2. **输出不带提示语**——`"请输入"`、`"答案是"` 一律不能出现
3. **字符与数字别混**——`'0'` 是 48，`0` 是 0
4. **码值口诀别记反**——空格 32 < `'0'` 48 < `'A'` 65 < `'a'` 97
5. **转换方向别记反**——小写更大，变大写要减 32
