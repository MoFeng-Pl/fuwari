# 逻辑运算符与应用学习笔记

## 1. 逻辑与 `&&`

**逻辑运算符**（logical operator）用来把多个条件组合成一个条件，成员是逻辑与 `&&`、逻辑或 `||`、逻辑非 `!`。

### 核心概念

程序会根据操作数所代表的**布尔值**（boolean，逻辑值）进行逻辑运算。布尔值只有 `0` 和 `1`，其它类型的数据转成布尔类型时遵循同一条规则：**非 0 就是 1，0 还是 0**。所以 `3`、`-1`、`'a'` 都算真，只有 `0` 算假。

### 语法格式

符号 `&&`（两个 `&`，写一个就成按位与）；按键 `Shift` + `7`；夹在两个操作数中间，是**双目运算符**。

```cpp
操作数1 && 操作数2
```

### 运算规则与真值表

**同真则真，有假则假**——两个操作数都为真，结果才为真，其他情况都是假。

| 操作数1 | 操作数2 | 结果 | 说明 |
| ---- | ---- | ---- | ---- |
| 1 | 1 | `1` | 两个都真，才真 |
| 1 | 0 | `0` | 有一个假，就假 |
| 0 | 1 | `0` | 有一个假，就假 |
| 0 | 0 | `0` | 两个都假，更假 |

### 代码示例

```cpp
#include <iostream>
using namespace std;
int main()
{
    cout << (1 && 1) << "\n";           // 1
    cout << (1 && 0) << "\n";           // 0
    cout << (5 > 3 && 2 > 1) << "\n";   // 1，两个条件都成立
    return 0;
}
```

### 易错点

1. 只写一个 `&`——那是**按位与**，运算结果完全不同
2. 忘记加括号——`cout << 1 && 1` 会先输出 `1` 再去算 `&&`
3. 以为 `3 && 2` 得 3 或 2——逻辑运算只给 `1` 或 `0`

> **本节小结**：`&&` 表示"并且"，规则是"同真则真、有假则假"，只有两边都真结果才为 1；参与运算的数据先按"非 0 即真、0 即假"折算成布尔值再判断。

## 2. 逻辑或 `||`

### 核心概念

逻辑或表示"或者"：两个条件里有一个成立就够。

### 语法格式

符号 `||`（两条竖线，写一个就成按位或）；按键 `Shift` + `\`；夹在两个操作数中间，是双目运算符。

```cpp
操作数1 || 操作数2
```

### 运算规则

**同假则假，有真则真**——只要有一个操作数为真，结果就为真，其它情况都是假。

| 操作数1 | 操作数2 | 结果 | 说明 |
| ---- | ---- | ---- | ---- |
| 1 | 1 | `1` | 有真就真 |
| 1 | 0 | `1` | 有真就真 |
| 0 | 1 | `1` | 有真就真 |
| 0 | 0 | `0` | 两个都假才假 |

四行里只有最后一行是 `0`，正好和 `&&` 互补。

### 代码示例

```cpp
#include <iostream>
using namespace std;
int main()
{
    cout << (1 || 0) << "\n";           // 1
    cout << (0 || 0) << "\n";           // 0
    cout << (5 > 10 || 3 < 4) << "\n";  // 1，一个成立就够
    return 0;
}
```

### 易错点

1. 只写一个 `|`——那是**按位或**，不是逻辑或
2. 把 `||` 写成 `//`——那变成注释，后面的代码全被吞掉
3. 记反规则——`||` 是"有真则真"，不是"有假则假"

> **本节小结**：`||` 表示"或者"，规则是"同假则假、有真则真"，只要有一个操作数为真结果就是 1；它的真值表与 `&&` 恰好互补，记住"只有一行是 0"就不会记混。

## 3. 逻辑非 `!`

### 核心概念

逻辑非是**取反**：真变假、假变真。它只需要一个操作数，是三个逻辑运算符中唯一的**单目运算符**。

### 语法格式

符号 `!`，必须是**英文半角符号**（中文叹号 `！` 会编译报错）；按键 `Shift` + `1`；写在操作数**前面**，规则是**非真为假，非假为真**。

```cpp
!操作数
```

课件展示的控制台结果正是：`!0` 得 `1`，`!1` 得 `0`。

### 代码示例

```cpp
#include <iostream>
using namespace std;
int main()
{
    cout << !0 << "\n";        // 1
    cout << !1 << "\n";        // 0
    cout << !(5 > 3) << "\n";  // 0，真取反为假
    cout << !(5 < 3) << "\n";  // 1，假取反为真
    return 0;
}
```

`!` 可以连用，两次取反回到原真假，但结果仍是逻辑值：`!!5` 得 `1`，`!!0` 得 `0`——不是 5。

### 易错点

1. 用中文叹号 `！`——中文标点不是运算符，编译直接失败
2. 把 `!` 写在操作数后面——必须写在前面
3. 以为 `!5` 得到 `-5`——逻辑非只给 `0`，不是相反数

> **本节小结**：`!` 是唯一的单目逻辑运算符，写在操作数前面，规则是"非真为假、非假为真"，`!0` 得 1、`!1` 得 0；它取的是逻辑上的反，不是数值上的相反数。

## 4. 组合条件与短路求值

一个条件里通常同时出现算术、关系、逻辑运算符，谁先算由优先级决定。课件把优先级画成一条从上到下的箭头，**从高到低**共五层：

| 优先级 | 运算符类别 | 说明 |
| ---- | ---- | ---- |
| 1（最高） | 括号 `()` | 括号里的先算 |
| 2 | 逻辑非 `!` | 优于所有算术与关系运算 |
| 3 | 算术运算符 | 先乘除取余 `* / %`，后加减 `+ -` |
| 4 | 关系运算符 | 先看大小 `> >= < <=`，后看相等 `== !=` |
| 5（最低） | 逻辑运算符 | 先逻辑与 `&&`，后逻辑或 `||` |

三条记忆要点：括号永远最优先；`!` 比算术还高；`&&` 比 `||` 高，所以 `a || b && c` 等于 `a || (b && c)`。

判断 `x` 在 60 到 99 之间，**必须**写成两个条件用 `&&` 连接：`x >= 60 && x < 100`。写成 `60 <= x < 100` 会先算 `60 <= x` 得到 `0` 或 `1`，再拿它和 100 比，结果**永远为真**。

### 短路求值

**短路求值**（short-circuit evaluation）指结果已确定时不再计算右边：`&&` 左边为假，整体必假，**右边不执行**；`||` 左边为真，整体必真，**右边不执行**。

```cpp
int a = 0;
cout << (0 && (a = 5)) << "\n";   // 输出 0，右边没执行
cout << (1 || (a = 7)) << "\n";   // 输出 1，右边没执行
cout << a << "\n";                // 仍是 0
```

利用短路可以写出"先判断、再使用"的安全写法：`if (a != 0 && 10 / a > 2)`，`a` 为 0 时右边不执行，避免除以 0。

### 易错点

1. 连写成 `60 <= x < 100`——必须拆成两个条件配 `&&`
2. 以为 `a || b && c` 从左到右算——`&&` 优先级更高
3. 在 `&&` 右侧写有副作用的表达式——可能因短路而不执行

> **本节小结**：优先级从高到低是「括号 → `!` → 算术 → 关系 → 逻辑（`&&` 先于 `||`）」；区间判断必须拆成两个条件用 `&&` 连接，而短路特性会让左边已能确定结果时右边不再执行。

## 5. 逻辑运算符的应用

把关系运算符和逻辑运算符组合起来，才能表达真实题目里的复杂条件：要"都满足"用 `&&`，要"满足一个"用 `||`，要"反过来"用 `!`。

判断闰年的规则是"能被 4 整除且不能被 100 整除，或者能被 400 整除"：

```cpp
int y = 2024;
cout << (y % 4 == 0 && y % 100 != 0 || y % 400 == 0) << "\n";   // 1
```

按优先级 `&&` 先于 `||`，等价于 `(y%4==0 && y%100!=0) || (y%400==0)`，正好符合题意。区间与字符判断同理：`s >= 60 && s < 100` 判断及格区间，`c >= 'A' && c <= 'Z'` 判断大写字母。

### 常见条件模式

| 需求 | 写法 |
| ---- | ---- |
| 同时满足两个条件 | `a && b` |
| 至少满足一个 | `a \|\| b` |
| 都不满足 | `!a && !b` |
| 在闭区间 `[L, R]` 内 | `x >= L && x <= R` |
| 在区间外 | `x < L \|\| x > R` |
| 是字母（大写或小写） | `(c >= 'A' && c <= 'Z') \|\| (c >= 'a' && c <= 'z')` |

### 易错点

1. 把"同时满足"写成 `||`——条件直接放宽，逻辑全错
2. 区间判断少写一半——只写 `x >= 60` 就当成"及格且不满分"
3. 该加括号却靠优先级——`(c >= 'A' && c <= 'Z') || (...)` 的分组括号不能省

> **本节小结**：复杂条件靠"要同时 → `&&`、要其一 → `||`、要相反 → `!`"三招拼出来；区间要用两个关系表达式加 `&&`，多个区间之一则给每段单独加括号再用 `||` 串联。

## 知识框架梳理

### 核心概念总结

- **布尔转换**：非 0 就是 1（真），0 还是 0（假）
- **`&&` 逻辑与**：双目，同真则真、有假则假，只有 `1 && 1` 得 `1`
- **`||` 逻辑或**：双目，同假则假、有真则真，只有 `0 || 0` 得 `0`
- **`!` 逻辑非**：单目，非真为假、非假为真，`!0` 得 1、`!1` 得 0
- **优先级**：括号 → `!` → 算术 → 关系 → 逻辑（`&&` 先于 `||`）
- **短路求值**：`&&` 左边假则右边不算，`||` 左边真则右边不算

### 语法速查表

| 用途 | 写法 | 示例结果 |
| ---- | ---- | ---- |
| 逻辑与 | `操作数1 && 操作数2` | `1 && 1` → `1` |
| 逻辑或 | `操作数1 \|\| 操作数2` | `0 \|\| 0` → `0` |
| 逻辑非 | `!操作数` | `!1` → `0` |
| 按键 | `&&` 是 `Shift+7`，`\|\|` 是 `Shift+\`，`!` 是 `Shift+1` | — |
| 同时满足 | `条件1 && 条件2` | `x >= 60 && x < 100` |
| 满足其一 | `条件1 \|\| 条件2` | `x < 0 \|\| x > 100` |
| 取反 | `!(条件)` | `!(5 > 3)` → `0` |
| 闰年判断 | `y%4==0 && y%100!=0 \|\| y%400==0` | `2024` → `1` |

### 易错点提醒

1. **一个符号当两个用**——`&` 是按位与、`|` 是按位或，逻辑运算必须写 `&&`、`||`
2. **中文标点**——`！`、`｜` 都不是运算符，必须用英文半角
3. **规则记反**——`&&` 是"同真才真"，`||` 是"同假才假"
4. **`!` 的位置与结果**——写在操作数前面，`!5` 是 `0` 而不是 `-5`
5. **区间不能连写**——`60 <= x < 100` 恒为真，必须 `x >= 60 && x < 100`
6. **优先级别猜**——`!` 高于算术，`&&` 高于 `||`，拿不准就加括号
7. **短路会跳过赋值**——依赖右侧副作用时先想清楚左边是否为假（或真）
