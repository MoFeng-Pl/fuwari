# 字符函数与字符数组函数学习笔记

## 1. `<cctype>` 字符函数

`<cctype>` 是 C++ 中专门处理**单个字符**的头文件，里面提供了一批「判断」和「转换」函数。

### 核心概念

- 这些函数都接收**一个字符**（或字符的 ASCII 值）作为参数
- 判断类函数返回**整数**：条件成立返回非 0（真），不成立返回 0（假）
- 因此可以直接把函数调用写进 `if` 的条件里

### 常用函数一览

| 函数 | 作用 | 成立示例 |
| ---- | ---- | -------- |
| `isalpha(c)` | 判断是否为字母 | `'a'`、`'Z'` |
| `isdigit(c)` | 判断是否为数字字符 | `'0'`、`'9'` |
| `isalnum(c)` | 判断是否为字母或数字 | `'a'`、`'7'` |
| `islower(c)` | 判断是否为小写字母 | `'a'` |
| `isupper(c)` | 判断是否为大写字母 | `'A'` |
| `isspace(c)` | 判断是否为空白字符 | 空格、`\t`、`\n` |
| `ispunct(c)` | 判断是否为标点符号 | `','`、`'!'` |

### 语法格式

```cpp
#include <cctype>

if (isalpha(ch)) { ... }     // 是字母就进入分支
if (!isdigit(ch)) { ... }    // 不是数字字符就进入分支
```

### 万能头文件

同时要用多个库时，可以只写 `#include <bits/stdc++.h>`：它**包含绝大多数标准库**，刷题很方便；缺点是编译变慢，部分平台不保证支持。

### 易错点

1. `isdigit('3')` 为真，`isdigit(3)` 结果不确定——参数应是**字符**而不是数字
2. 判断函数返回的是「非 0 / 0」，不要写成 `if (isalpha(ch) == 1)`，不同编译器返回的具体非 0 值可能不同
3. 忘记 `#include <cctype>`，编译报「找不到标识符」

> **本节小结**：`<cctype>` 里的 `isalpha`、`isdigit`、`isspace` 等函数用来判断单个字符的类型，返回「非 0 为真、0 为假」，可以直接当作 `if` 的条件。

## 2. 字符判断与转换

判断函数解决「这个字符是什么」，转换函数解决「把这个字符变成另一个」。

### 大小写转换函数

| 函数 | 作用 | 示例 | 结果 |
| ---- | ---- | ---- | ---- |
| `toupper(c)` | 小写字母 → 大写字母 | `toupper('a')` | `'A'` |
| `tolower(c)` | 大写字母 → 小写字母 | `tolower('A')` | `'a'` |

- 头文件同样是 `<cctype>`
- **对其他字符不做任何改变**：`toupper('1')` 仍是 `'1'`，`toupper(' ')` 仍是 `' '`
- 函数**返回**转换后的字符，原变量不会自动改变，要写 `ch = toupper(ch);`

### 代码示例：统一转大写

```cpp
#include <bits/stdc++.h>
using namespace std;

int main()
{
    char s[105];
    cin >> s;

    for (int i = 0; s[i] != '\0'; i++) {
        s[i] = toupper(s[i]);   // 必须重新赋值
    }
    cout << s;
    return 0;
}
```

输入 `Hello`，输出 `HELLO`。

### 易错点

1. **忘记重新赋值**：`toupper(s[i]);` 只是调用了一次，数组内容没变
2. **以为 `toupper` 会改原字符**：它只是**返回**新字符，是「值传递」
3. **把 `'a'` 写成 `"a"`**：双引号是字符串，不能传给字符函数

> **本节小结**：判断用 `isalpha`、`isdigit`，转换用 `toupper`、`tolower`；转换函数只返回结果，必须写 `ch = toupper(ch);` 才能生效。

## 3. `strlen` / `strcpy` / `strcmp`

这三个函数来自头文件 `<cstring>`，专门处理**字符数组形式的字符串**。

### `strlen`：求字符串长度

```cpp
#include <cstring>
int len = strlen(s);
```

- 返回字符串的**实际字符个数**，**不包含**结尾的 `\0`
- 与 `sizeof(s)` 完全不同：`sizeof` 得到的是数组总长度
- 底层实现就是「从开头数到 `\0` 为止」

| 表达式 | 值 | 含义 |
| ------ | -- | ---- |
| `strlen(s)`，`s` 为 `"char"` | 4 | 有效字符个数 |
| `sizeof(s)`，`s` 定义为 `char s[10]` | 10 | 数组占用的总字节数 |

### `strcpy`：复制字符串

```cpp
strcpy(b, a);   // 把 a 复制到 b
```

- 参数顺序：**目标数组在前，源数组在后**，即「把右边的复制到左边」
- 会连同 `\0` 一起复制
- 目标数组必须**足够大**，否则越界
- 不能写成 `b = a;`，数组名不能整体赋值

```cpp
char a[10] = "cat";
char b[10];
strcpy(b, a);   // b 变成 "cat"
```

### `strcmp`：比较字符串

```cpp
int r = strcmp(s1, s2);
```

返回值含义：

| 返回值 `r` | 含义 |
| ---------- | ---- |
| 等于 0 | `s1` 与 `s2` 完全相同 |
| 小于 0 | `s1` 在字典序中小于 `s2` |
| 大于 0 | `s1` 在字典序中大于 `s2` |

**字典序（lexicographic order）规则**：

1. 从第一个字符开始，逐个按 **ASCII 值**比较，值小的排在前面
2. 一旦某个位置分出大小，后面的字符不再看
3. 如果所有对应位置都相等，则**更长**的字符串更大

```cpp
// cat < cow      —— 第 2 个字符 a(97) < o(111)
// read < reader  —— 前 4 个相同，"read" 更短，所以更小
```

### 补充：`strcat` 追加字符串

`strcat(s1, s2);` 从 `s1` 的 `\0` 位置开始，把 `s2` 接上去，`s1` 必须留够两段字符串的总长度。

### 易错点

1. **`strcpy` 参数写反**：`strcpy(a, b)` 是把 `b` 复制给 `a`，别搞错方向
2. **用 `==` 比较字符数组**：`if (s1 == s2)` 比较的是地址，永远不为真，必须用 `strcmp`
3. **用 `strlen` 当循环上界时重复调用**：`for (i = 0; i < strlen(s); i++)` 每次都重新数一遍，建议先存进变量
4. **忘记 `#include <cstring>`**

> **本节小结**：`strlen` 数字符（不含 `\0`）、`strcpy(目标, 源)` 复制、`strcmp` 按字典序比较（0 相等、负数小于、正数大于），这三个函数是字符数组的「基本操作三件套」。

## 4. 字符数组函数的应用

把输入、遍历、判断、比较组合起来，就能解决常见的字符串题目。

### 读入带空格的字符串

`cin >> s` 遇到空格就停，读整行要用 `cin.getline`：

```cpp
cin.getline(字符数组名, 最大读取字符数);
```

```cpp
char s[105];
cin.getline(s, 100);   // 最多读 99 个字符，剩下的位置留给 '\0'
```

- 第二个参数是**缓冲区大小**，函数最多读取「该数值 - 1」个字符，最后自动补 `\0`
- 空格会被当作普通字符读进来，直到遇到换行

### 例 1：判断回文串

回文串（palindrome）指正着读和反着读都一样的字符串。

```cpp
// 假设 s 是已经用 cin.getline 读入的字符数组
int len = strlen(s);
bool flag = true;
for (int i = 0; i < len / 2; i++) {
    if (s[i] != s[len - 1 - i]) {
        flag = false;
        break;
    }
}
if (flag) cout << "yes";
else      cout << "no";
```

- 只需比较前一半和后一半，循环到 `len / 2` 即可
- 镜像位置的下标是 `len - 1 - i`，这是最容易写错的地方

### 易错点

1. **`cin.getline` 的第二个参数写成数组长度**：实际只能读 `长度 - 1` 个字符
2. **前面用过 `cin >>` 再 `cin.getline`**：缓冲区里残留的换行会被立刻读走，得到空串，需要额外处理
3. **回文比较写成 `s[i] != s[len - i]`**：下标差 1，正确的是 `len - 1 - i`

> **本节小结**：`cin.getline` 负责读整行，`strlen` 提供长度、`strcmp` 提供大小关系；把遍历与 `<cctype>` 的判断转换组合起来，就能完成统计、回文、字典序比较等常见字符串题。

## 知识框架梳理

### 核心概念总结

- **`<cctype>` 判断函数**：`isalpha`、`isdigit`、`isalnum`、`islower`、`isupper`、`isspace`，返回非 0 为真
- **大小写转换**：`toupper`、`tolower`，只返回结果，需重新赋值
- **`<cstring>` 三件套**：`strlen` 求长度、`strcpy` 复制、`strcmp` 比较
- **字典序**：逐字符比 ASCII 值，全部相同则更长者更大
- **整行读入**：`cin.getline(数组名, 最大读取字符数)`
- **万能头文件**：`#include <bits/stdc++.h>` 一次引入常用库

### 语法速查表

| 用途 | 写法 |
| ---- | ---- |
| 判断字母 | `isalpha(ch)` |
| 判断数字字符 | `isdigit(ch)` |
| 判断空白字符 | `isspace(ch)` |
| 转大写 | `ch = toupper(ch);` |
| 转小写 | `ch = tolower(ch);` |
| 求字符串长度 | `strlen(s)` |
| 复制字符串 | `strcpy(目标, 源);` |
| 比较字符串 | `strcmp(s1, s2)` |
| 追加字符串 | `strcat(s1, s2);` |
| 读入整行 | `cin.getline(s, 100);` |
| 万能头文件 | `#include <bits/stdc++.h>` |

### 易错点提醒

1. **比较字符数组用 `==`**：比较的是首地址，必须用 `strcmp`
2. **`strcmp` 的返回值直接当布尔用**：`if (strcmp(a, b))` 在「不相等」时为真，容易反逻辑，建议显式写 `== 0`
3. **`strcpy` 参数方向**：目标在左、源在右；且目标数组要足够大
4. **转换函数忘记赋值**：`toupper(ch);` 不会改变 `ch`
5. **`strlen` 与 `sizeof` 混用**：前者是有效字符数，后者是数组总字节数
6. **`cin.getline` 参数**：第二个参数是缓冲区大小，实际读入 `大小 - 1` 个字符
7. **`isdigit(3)` 与 `isdigit('3')` 不同**：参数必须是字符

> **本节小结**：判断转换靠 `<cctype>`，长度复制比较靠 `<cstring>`；记住 `strcmp` 的返回值含义和 `strcpy` 的参数方向，再配合 `cin.getline` 读整行，字符数组题目就能稳稳拿下。
