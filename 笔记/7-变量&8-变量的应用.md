# 7-变量&8-变量的应用

## 变量

### 变量的概念

变量是程序中用于存储和操作数据的基本单元，它像一个小盒子，具有以下特点：

1. **存储功能**：变量可以存放不同类型的数据，如整数、小数、字符等
2. **标识性**：每个变量都有一个唯一的名称（变量名），用于在程序中识别和访问
3. **可变性**：变量中存储的值可以在程序运行过程中被修改
4. **类型约束**：变量在声明时需要指定数据类型，决定了它可以存储的数据范围和操作方式

变量的基本组成包括：
- **变量名**：用于标识变量的名称
- **变量值**：变量中存储的具体数据内容

例如：
```
+------------+
|     I      |  <-- 变量名
+------------+
|     20     |  <-- 变量值
+------------+
```

### 变量的命名规则

在C++中，变量名的命名必须遵守以下规则：

1. **字符组成**：变量名可以包含字母（a-z, A-Z）、数字（0-9）和下划线（_）
2. **开头字符**：变量名必须以字母或下划线开头，不能以数字开头
3. **大小写敏感**：变量名区分大小写，如`age`和`Age`是不同的变量
4. **关键字限制**：**变量名不能使用C++关键字**，如`int`、`double`、`return`等
5. **长度限制**：变量名长度没有严格限制，但应保持合理长度以提高可读性

变量命名的最佳实践：
- **见名知意**：使用有意义的名称，如`age`表示年龄，`score`表示分数
- **驼峰命名法**：对于多个单词组成的变量名，使用驼峰命名法，如`studentName`、`totalScore`
- **避免下划线开头**：除非有特殊需求，否则尽量避免使用下划线开头的变量名
- **简洁明了**：在保持清晰的前提下，尽量使用简洁的变量名

### 变量定义

#### 变量定义的语法格式

在C++中，变量定义的基本语法格式为：
```cpp
数据类型 变量名;
```

例如：
```cpp
int age;      // 定义一个名为age的整型变量
double score;  // 定义一个名为score的双精度浮点型变量
```

#### 变量的初始化

变量可以在定义的同时进行初始化（赋予初始值），语法格式为：
```cpp
数据类型 变量名 = 初始值;
```

例如：
```cpp
int age = 20;          // 定义并初始化整型变量age为20
double score = 95.5;    // 定义并初始化双精度浮点型变量score为95.5
```

#### 关键字在变量定义中的应用

在C++中，有一些关键字在变量定义中具有特殊作用：

**数据类型关键字**：如`int`、`double`、`char`、`bool`等，用于指定变量的数据类型

#### 不同场景下的变量定义方法

1. **单个变量定义**：一次定义一个变量
   ```cpp
   int num;
   ```

2. **多个同类型变量定义**：一次定义多个相同类型的变量，用逗号分隔
   ```cpp
   int num1, num2, num3;
   ```

3. **定义并初始化多个变量**：
   ```cpp
   int num1 = 10, num2 = 20, num3 = 30;
   ```

4. **在表达式中定义变量**：
   ```cpp
   int sum = num1 + num2;  // 定义sum变量并将num1和num2的和赋值给它
   ```

#### 关键字的注意事项

- **不可作为变量名**：C++关键字是语言的保留字，不能用作变量名
- **区分关键字和标识符**：确保变量名不会与任何C++关键字冲突
- **常用关键字示例**：`int`、`double`、`if`、`else`、`for`、`while`、`return`等

例如，在C++基本框架中，`return`是关键字，不能用作变量名：
```cpp
#include <iostream>  // 头文件
using namespace std;  // 命名空间

int main()
{
    return 0;  // return是关键字，表示函数的返回值
}
```

## 变量的应用

### 变量赋值

变量赋值是将数据存储到变量中的过程，在C++中主要有两种赋值方法：

#### 1. 先定义后赋值（分开写）

这种方法先声明变量的类型和名称，然后再为变量赋具体的值。

**语法格式**：
```cpp
数据类型 变量名1, 变量名2, 变量名3;
变量名1 = 值1;
变量名2 = 值2;
变量名3 = 值3;
```

### 变量赋值

变量赋值是将数据存储到变量中的过程，在C++中主要有两种赋值方法：

#### 1. 先定义后赋值（分开写）

这种方法先声明变量的类型和名称，然后再为变量赋具体的值。

**语法格式**：
```cpp
数据类型 变量名1, 变量名2, 变量名3;
变量名1 = 值1;
变量名2 = 值2;
变量名3 = 值3;
```

**示例代码**：
```cpp
// 先定义三个浮点型变量
float l, w, h;
// 然后分别为变量赋值
l = 20.0;
w = 15.0;
h = 2.2;
```

#### 2. 定义和赋值一起写

这种方法在声明变量的同时直接为变量赋初始值，使代码更加简洁。

**语法格式**：
```cpp
数据类型 变量名1 = 值1, 变量名2 = 值2, 变量名3 = 值3;
```

**示例代码**：
```cpp
// 定义变量的同时为其赋值
float l = 20.0, w = 15.0, h = 2.2;
```

### 值的改变

变量的值可以在程序运行过程中被修改，主要有以下三种改变方式：

#### 1. 直接改值

直接为变量赋予一个新的具体值。

**示例代码**：
```cpp
#include <iostream>  //头文件
using namespace std;  //命名空间

int main()  //主函数
{
    float l, w, h;  //定义变量
    l = 20.0;  //直接为变量l赋值
    w = 15.0;  //直接为变量w赋值
    h = 2.2;   //直接为变量h赋值
    cout << l * w * h;  //输出计算结果
    return 0;
}
```

#### 2. 重新赋值

为已经赋值的变量再次赋予一个新的值。

**示例代码**：
```cpp
#include <iostream>  //头文件
using namespace std;  //命名空间

int main()  //主函数
{
    int a = 1;  //定义并初始化变量a为1
    a = 5;      //重新赋值，将变量a的值改为5
    cout << a;  //输出结果：5
    return 0;
}
```

#### 3. 计算后赋值

通过计算表达式得到一个新的值，然后将该值赋给变量。

**示例代码**：
```cpp
#include <iostream>  //头文件
using namespace std;  //命名空间
int main()  //主函数
{
    int a = 1;    //定义并初始化变量a为1
    a = a + 10;   //计算表达式a + 10的结果，然后赋值给变量a
    cout << a;    //输出结果：11
    return 0;
}
```

**说明**：计算后赋值是一种常用的变量值改变方式，它允许我们基于变量的当前值进行计算，然后更新变量的值。这种方式在循环、累加、累乘等操作中非常常见。
